* 维护操作
:PROPERTIES:
:CUSTOM_ID: maintenance
:END:

在 Emacs 中将光标置于代码块内按 =C-c C-c= 即可执行（执行前会有确认提示），执行结果将输出到 =#+RESULTS:= 。完整的系统 reconfigure 涉及 sudo 权限，不在 Babel 块中执行，修改后请在终端执行 =blue rebuild= 。

括号平衡检查（快速定位出错的代码块）：

#+begin_src sh :dir .. :results output
blue check
#+end_src

构建验证（tangle + =guix system build --dry-run= ，仅做语法与依赖验证，不写入系统）：

#+begin_src sh :dir .. :results output
blue --dry-run rebuild
#+end_src

仅执行 tangle（刷新 =tmp/= 下的全部代码生成物）：

#+begin_src sh :dir .. :results output
blue build
#+end_src

* 配置文件骨架
:PROPERTIES:
:CUSTOM_ID: main-skeleton
:END:

Org Noweb 语法通过 =<<ref>>= 引用各 =#+NAME:= 代码块并组装输出。=skeletons= 字段具备替换语义而非默认追加，因此需合并 =(default-skeletons)= 以保留系统默认骨架文件。

本代码块是整个系统的总装配表：按清晰的分区顺序组合顶层定义、Home 环境与 System 声明。

* 系统配置

系统层仅承载 *底层引导与核心硬件基础设施* ，保持最小化依赖。用户态应用与桌面工具统一由 Home 层管理。

** FileSystems
:PROPERTIES:
:CUSTOM_ID: sys-filesystems
:END:

存储拓扑采用 =LUKS + Btrfs= 架构：
- 根目录 =/= 挂载在 tmpfs，关机即清空。
- 关键系统数据与用户目录持久化存储于 Btrfs 各子卷，子卷清单与挂载点定义于 [[./information.scm][information.scm]] 。
- 支持休眠到独立 swap 分区（Guile initrd 限制下采用明文 swap 恢复）。

#+NAME: filesystem-defines
#+begin_src scheme
(define %swap-uuid "169557cc-00a4-448c-9bb6-7bd80fc2b023")

(define %mapped-devices-config
  (list (mapped-device
         (source (uuid "327f2e02-1e4f-48b2-87f0-797c481850c9"))
         (target "root")
         (type luks-device-mapping))))

(define %tmpfs
  (list (file-system
         (mount-point "/")
         (device "tmpfs")
         (type "tmpfs")
         (flags '(no-atime))
         (options "mode=0755,nr_inodes=1m,size=10%")
         (needed-for-boot? #t)
         (check? #f))
        (file-system
         (device "tmpfs")
         (mount-point "/var/lock")
         (type "tmpfs")
         (flags '(no-suid no-dev strict-atime))
         (options "mode=1777,nr_inodes=100k,size=1%")
         (needed-for-boot? #t)
         (create-mount-point? #t)
         (check? #f))))

(define %persist-filesystem
  (map (match-lambda
         ((subvol mount-point)
          (file-system
           (device (file-system-label "Linux"))
           (mount-point mount-point)
           (type "btrfs")
           (dependencies %mapped-devices-config)
           (options (string-append "subvol=" subvol ",compress=zstd:3"))
           (create-mount-point? #t)
           (needed-for-boot? (not (string=? mount-point "/tmp")))
           (check? (string=? mount-point "/gnu"))))) %btrfs-subvolumes))

(define %data-filesystem
  (file-system
   (device (file-system-label "Linux"))
   (mount-point "/data")
   (type "btrfs")
   (dependencies %mapped-devices-config)
   (options (string-append "subvol=" %btrfs-subvol-data ",compress=zstd:3"))
   (create-mount-point? #t)))

(define %bind-mounts
  (map (lambda (dirs)
         (file-system
          (mount-point (string-append "/home/" username "/" dirs))
          (device (string-append "/data/" dirs))
          (type "none")
          (flags '(bind-mount))
          (options "x-gvfs-hide")
          (dependencies (list %data-filesystem))
          (create-mount-point? #t))) %data-dirs))

(define %file-systems-config
  (append %bind-mounts %persist-filesystem %tmpfs
          (list %data-filesystem
                (file-system
                 (device (uuid "9699-52A2"
                               'fat))
                 (mount-point "/efi")
                 (type "vfat")
                 (create-mount-point? #t))) %base-file-systems))

(define %swap-devices
  (list (swap-space
         (target (uuid %swap-uuid)))))
#+end_src

*** 内核相关服务设置

下列三个服务块按顺序装配进 [[#main-skeleton][main]] 的系统服务列表中。

**** 内核模块加载
加载 =ip_tables= 与 =iptable_nat= 作为兼容层（供 Libvirt 与 Podman 网络后端使用）；在系统启动完成且 zstd 模块就绪后，由 =zswap-zstd= 服务运行时将 zswap 压缩器无缝切换至 zstd。

#+NAME: kernel-module-services
#+begin_src scheme
(list (simple-service 'extend-kernel-module-loader
                      kernel-module-loader-service-type

                      '("ip_tables" "iptable_nat" "kvm_intel" "ntsync" "sch_fq"
                        "tcp_bbr" "uhid" "uinput" "v4l2loopback" "zstd"))


      (simple-service 'zswap-zstd shepherd-root-service-type
                      (list (shepherd-service
                             (documentation
                              "zstd 模块加载后把 zswap 压缩器切到 zstd。")
                             (provision '(zswap-zstd))
                             (requirement '(kernel-module-loader))
                             ;; 内核拒绝时（zstd 不可用）静默放行，不阻断 boot
                             (start #~(lambda _
                                        (system* "/bin/sh" "-c"
                                                 "grep -qw zstd /proc/crypto 2>/dev/null \
&& echo zstd > /sys/module/zswap/parameters/compressor 2>/dev/null; exit 0")
                                        #t))
                             (stop #~(lambda _ #t))
                             (one-shot? #t)
                             (auto-start? #t)
                             (respawn? #f))))

      (simple-service 'v4l2loopback-config etc-service-type
                      (list `("modprobe.d/v4l2loopback.conf"
                              ,(plain-file "v4l2loopback.conf"
                                           "options v4l2loopback devices=1 video_nr=1 card_label=\"OBS Cam\" exclusive_caps=1")))))
#+end_src

**** 休眠 resume 设备
每次开机通过 swap 分区 UUID 反查块设备号（major:minor）并写入 =/sys/power/resume= ，为系统休眠恢复提供底层支持；设备号由内核枚举顺序决定不能硬编码，故经 UUID 符号链接反查块设备名、再从 sysfs 读出。

#+NAME: resume-device-service
#+begin_src scheme
(list (simple-service 'setup-resume-device
                      shepherd-root-service-type
                      (list (shepherd-service
                             (provision '(resume-device))
                             (requirement '(file-systems))
                             (one-shot? #t)
                             (start
                              #~(lambda ()
                                  (let* ([dev-name (basename
                                                    (readlink
                                                     (string-append
                                                      "/dev/disk/by-uuid/"
                                                      #$%swap-uuid)))]
                                         [dev (call-with-input-file
                                                  (string-append
                                                   "/sys/class/block/"
                                                   dev-name "/dev")
                                                read-line)])
                                    (call-with-output-file "/sys/power/resume"
                                      (lambda (port)
                                        (display dev port))))))))))
#+end_src

**** 开机清空 /tmp
持久化 Btrfs 子卷挂载的 =/tmp= 目录开机清理：通过 =/run/cleanup-tmp-done= 标记文件确保每次启动仅执行一次，并通过 =cleanup-/tmp-prereq= 前置注入到 =user-processes= 依赖链。

#+NAME: cleanup-tmp-services
#+begin_src scheme
(list (simple-service 'cleanup-/tmp
                      shepherd-root-service-type
                      (list (shepherd-service
                             (documentation "Empty /tmp once per boot.")
                             (provision '(cleanup-/tmp))
                             (requirement '(file-systems))
                             (one-shot? #t)
                             (start
                              (with-imported-modules (source-module-closure
                                                      '((guix build utils)))
                                                     #~(lambda ()
                                                         (use-modules (guix build utils))
                                                         (unless (file-exists? "/run/cleanup-tmp-done")
                                                           (false-if-exception
                                                            (invoke #$(file-append findutils "/bin/find")
                                                                    "/tmp" "-mindepth" "1" "-delete"))
                                                           (chmod "/tmp" #o1777)
                                                           (call-with-output-file "/run/cleanup-tmp-done"
                                                             (lambda (port)
                                                               (display "done" port))))
                                                         #t))))))

      (simple-service 'cleanup-/tmp-prereq user-processes-service-type
                      (list 'cleanup-/tmp)))
#+end_src

**** /data 权限与 XDG 目录
确保 =/data= 目录权限正确（0755），并在 =/data= 与 =$HOME= 两侧同步创建待持久化目录，供系统 bind-mount 挂载；=/data= 侧目录是 bind-mount 的源，缺失会导致挂载失败，=$HOME= 侧是挂载点，两侧都要建。

#+NAME: data-dirs-services
#+begin_src scheme
(list (simple-service 'fix-data-perms activation-service-type
                      #~(begin
                          (use-modules (guix build utils))
                          (mkdir-p "/data")
                          (chmod "/data" #o755)))

      (simple-service 'create-xdg-dirs activation-service-type
                      (with-imported-modules
                       (source-module-closure '((guix build utils)))
                       #~(begin
                           (use-modules (guix build utils))
                           (let* ([pw (getpwnam #$username)]
                                  [uid (passwd:uid pw)]
                                  [gid (passwd:gid pw)]
                                  [home (string-append "/home/" #$username)])
                             (for-each
                              (lambda (dir)
                                (let ([data-path (string-append "/data/" dir)]
                                      [home-path (string-append home "/" dir)])
                                  (mkdir-p data-path)
                                  (chown data-path uid gid)

**** 服务装配

脚本模板见下文各自小节（tangle 到 =tmp/= 后由 =local-file= 引入）；=render-script= 统一做「拷贝模板 + 按 alist 注入 store 路径 + 置执行位」（udev RUN / shepherd system* / dispatcher 直接执行产物，store 内必须带执行位）。

各服务要点：
- =nm-powersave-conf=：NM 每次连接都把 WiFi 省电重置为默认开启，dispatcher 在 up 事件补救实测不可靠（NM 默认启用省电覆盖了它）；改为 =[connection]= 段默认 =wifi.powersave=2= ，连接时恒不省电（低延迟，远程操控优先），电池时由 udev ac-power 规则在插拔瞬间切 on。注意 =[connection]= 段枚举与 profile 属性不同：0=NM默认 1=ignore 2=disable省电 3=enable省电。
- =openssh=：=permit-root-login 'prohibit-password= 显式声明——root 锁定密码仅允许密钥登录，防上游默认漂移。
- =mihomo-daemon=：=-d= 指定数据目录（geodata/cache/UI/proxies）归位到 =/var/lib/mihomo= 随 @data 子卷持久化；此前 root 环境下 mihomo 默认写到 =/.config/mihomo= 。启动经 =mihomo-run= 包装：模板（dotfiles immutable 部署，订阅 URL 为 =$MIHOMO_SUB_*= 占位符，密文入库明文不入库）渲染到 =/var/lib/mihomo/config.yaml= 后 exec，订阅轮换只需改密文 + 重启服务。
- =hotspot-uap0-udev=：NM 隔离 uap0 走 udev =NM_UNMANAGED= 官方机制（85-nm-unmanaged.rules 同款），规则文件随系统代原子切换；不走 conf.d =device.*= 段——NM 1.54 不认 =device.interface-name= 键（事故根因之一），且 =/etc/NetworkManager= 是持久子卷，坏文件跨代残留。顺带清掉 =ID_NET_NAME*= 防 udev 因共享 MAC 试图把 uap0 改名成 wlp0s20f3（每次开机都报 rename 冲突）；序号须 > 75（75-net-description 会无条件重设这些属性，reviewer 实证 eudev 3.2.14）。
- =hotspot-stale-conf-cleanup=：一次性清理——事故版本把键名错误的 conf.d 文件写进了持久子卷，回滚系统代不清除，必须显式删。
- =hotspot-ap=：热点本体，hostapd 直管 uap0（type __ap），不随机启动，由决策脚本 =herd start/stop= ；信道由决策脚本写入 =/run= 状态文件，执行体读不到合法信道号即拒绝启动。不 respawn：失败即停，由决策脚本在下个触发点重拉，避免反复折腾接口的风暴。
- =hotspot-dnsmasq=：热点子网 DHCP/DNS，=--bind-dynamic= 绑 uap0，无热点时闲置；dnsmasq 不碰 radio，崩溃即拉起保住热点子网 DHCP。
- =auto-hotspot=：开机入口，热点去留由决策脚本按电源与可信 profile 判定；stop 是 no-op——热点本体由 =hotspot-ap= 服务承载，手动关闭直接 =herd stop hotspot-ap= 。
- =hotspot-recheck=：周期兜底每分钟重跑决策，覆盖 dispatcher / udev 事件覆盖不到的场景（热点开着时可信网络出现、STA 换信道、hostapd 死后重拉）；command gexp 必须是字面量表——shepherd-timer 内部 =#$@= 会把 =#~(list …)= 的 list 符号拼进命令，触发时 fork+exec 报错杀死 timer fiber（永久失效，reviewer 实证）。
- =hotspot-ac-trigger=：电源插拔入口，=power_supply= 有 =online= 属性的源（Mains/USB-C，Battery 无此属性被 TEST 过滤）变化即重跑热点决策，脚本自读当前电源状态无需参数。

**** NM dispatcher 脚本

可信连接切换 + 热点决策触发入口；tangle 到 =tmp/= 后由 [[#main-skeleton][服务装配]] 注入 =@VAR@= 占位符，activation 拷贝到 =/etc/NetworkManager/dispatcher.d/= 。热点判定输入包含任意设备的连接状态（网线插拔同样改变判定），故对所有设备的 up/down 重跑决策，失败不阻断 trusted-set。

#+NAME: nm-dispatcher-trusted-connection
#+begin_src sh :tangle ../tmp/nm-dispatcher-trusted-connection
#!/bin/sh
# Auto-generated by Guix config.org.

WIFI_IFACE="wlp0s20f3"
AGE_IDENTITY="@AGE_IDENTITY@"
TRUSTED_CONNECTIONS_CIPHER="@TRUSTED_CONNECTIONS_CIPHER@"
AGE_BIN="@AGE_BIN@"
NFT_BIN="@NFT_BIN@"
GREP_BIN="@GREP_BIN@"
HOTSPOT_DECIDE_BIN="@HOTSPOT_DECIDE_BIN@"

ACTION="$2"
CONNECTION_ID="${CONNECTION_ID:-}"

case "$ACTION" in
    up|down) "$HOTSPOT_DECIDE_BIN" || true ;;
esac

[ "$1" = "$WIFI_IFACE" ] || exit 0

is_trusted_connection() {
    [ -r "$AGE_IDENTITY" ] || return 1
    "$AGE_BIN" -d -i "$AGE_IDENTITY" "$TRUSTED_CONNECTIONS_CIPHER" 2>/dev/null |
        "$GREP_BIN" -Fqx -- "$1"
}

remove_wifi_from_trusted_set() {
    "$NFT_BIN" delete element inet filter trusted_ifaces { "$WIFI_IFACE" } 2>/dev/null || true
}

add_wifi_to_trusted_set() {
    remove_wifi_from_trusted_set
    "$NFT_BIN" add element inet filter trusted_ifaces { "$WIFI_IFACE" }
}

case "$ACTION" in
    up)
        if is_trusted_connection "$CONNECTION_ID"; then
            add_wifi_to_trusted_set
        else
            remove_wifi_from_trusted_set
        fi
        ;;
    down)
        remove_wifi_from_trusted_set
        ;;
esac
#+end_src

**** 热点决策脚本

热点开关决策：AC 供电且物理无线口未连可信 profile 时开启热点，其余情况（电池供电、已连可信 WiFi）关闭。四个入口共用：shepherd =auto-hotspot= （开机）、NM dispatcher（任意设备 up/down）、udev =power_supply= 插拔、=hotspot-recheck= timer（每分钟兜底）。

2026-09-09 断网事故的安全不变式（改动前必读）：
1. AP 与 STA 并发共享 radio（#channels<=1），AP beacon 会把 radio 锁死在其信道——起在错误信道 = STA 永远连不上别的信道。因此 =target_channel= 无法给出确定信道时绝不起热点，exit 0 等下个触发点。
2. udev / dispatcher 上下文里同步执行会拖慢调用方的事件处理（dispatcher 版曾被 NM 退出的 SIGTERM 杀死），检测到事件环境即自重入后台执行。
3. 多入口并发由 flock 串行化。
4. 应急开关：=/run/hotspot-disabled= 存在时只关不开（tmpfs，重启自愈）。

变量可用环境覆盖，便于离线真值表测试；udev 与 dispatcher 环境不含这些名字，默认值即部署值。只依赖 sh 内建与注入的绝对路径，在 udev 的贫瘠 PATH 下也能运行。

=sta_channel= ：=iw link= 输出只有 freq（MHz），按频段换算信道号——2.4G: ch=(freq-2407)/5，5G: ch=(freq-5000)/5。

#+begin_src sh :tangle ../tmp/hotspot-decide
sta_channel() {
    freq=$("$IW_BIN" dev "$WIFI_IFACE" link 2>/dev/null |
               "$SED_BIN" -n 's/^[[:space:]]*freq: \([0-9][0-9]*\)$/\1/p')
    case "$freq" in
        "") return 1 ;;
        *) if [ "$freq" -ge 5000 ] 2>/dev/null; then
               echo $(( (freq - 5000) / 5 ))
           else
               echo $(( (freq - 2407) / 5 ))
           fi ;;
    esac
}

ap_channel() {
    "$SED_BIN" -n 's/^channel=\([0-9][0-9]*\)$/\1/p' "$HOSTAPD_CONF" 2>/dev/null
}
#+end_src

=target_channel= ——热点的唯一合法信道来源（安全闸）：
1. STA 已连接：跟随 STA 信道；
2. STA 未连接：扫描缓存里可见的 autoconnect WiFi profile 的信道（按信号序取首个命中），让 NM 稍后自动关联时天然同信道；
3. 都没有：返回失败，调用方必须放弃本次动作。

=nmcli -t= 会把值里的冒号转义为 =\:= ，前后两种输出的转义形式一致，故全程用转义形式匹配。不做子串 grep（"Office" 会误吞 "HomeOffice:"），改为对扫描行按信号序逐行做字面前缀剥离 + 纯数字校验。

#+begin_src sh :tangle ../tmp/hotspot-decide
target_channel() {
    ch=$(sta_channel) && { echo "$ch"; return 0; }
    scan=$("$NMCLI_BIN" -t -f SSID,CHAN device wifi list ifname "$WIFI_IFACE" 2>/dev/null) || return 1
    [ -n "$scan" ] || return 1
    autoconns=$("$NMCLI_BIN" -t -f NAME,TYPE,AUTOCONNECT connection show 2>/dev/null |
                    "$SED_BIN" -n 's/:802-11-wireless:yes$//p')
    [ -n "$autoconns" ] || return 1
    while IFS= read -r sline; do
        [ -n "$sline" ] || continue
        while IFS= read -r name; do
            [ -n "$name" ] || continue
            ch=${sline#"$name":}
            case "$ch" in
                ''|*[!0-9]*) continue ;;
*) ap_channel_ok "$ch" || continue
   echo "$ch"; return 0 ;;
esac
done <<EONAMES
$autoconns
EONAMES
done <<EOSCAN
$scan
EOSCAN
return 1
}
#+end_src

=ap_channel_ok= ——信道允许 AP 主动辐射校验：本机 self-managed regdom（world）下 5G 全带 no IR，扫描分支（STA 未连）起在这些信道会被 hostapd 拒绝（NO-IR）。带 IR-CONCURRENT 的信道在 STA 关联后限制解除——跟随 STA 的分支不需要此过滤，只有扫描分支（发起时 STA 未连）必须选无 no IR 标志的信道。=iw phy= 的 Frequencies 行格式：=* 5785 MHz [157] (22.0 dBm) (no IR)= 。

#+begin_src sh :tangle ../tmp/hotspot-decide
ap_channel_ok() {
    line=$("$IW_BIN" phy 2>/dev/null | "$GREP_BIN" -E "MHz \[$1\] ")
    [ -n "$line" ] || return 1
    case "$line" in
        *"no IR"*) return 1 ;;
        *) return 0 ;;
    esac
}
#+end_src

主流程：目标信道变化（STA 漫游 / 出现可关联网络）时重启热点跟随；shepherd 把进程退出过的服务标记 disabled，=herd start= 会拒绝，故先 =enable= （幂等，未禁用时无副作用）。

#+begin_src sh :tangle ../tmp/hotspot-decide
stop_hotspot() {
    "$HERD_BIN" stop "$HOTSPOT_SVC" 2>/dev/null
    "$IP_BIN" addr flush dev "$HOTSPOT_IFACE" 2>/dev/null
    return 0
}

if [ -e "$DISABLE_SENTINEL" ]; then
    hotspot_active && stop_hotspot
    exit 0
fi

if on_ac_power && ! wifi_trusted; then
    ch=$(target_channel) || exit 0
    if hotspot_active; then
        ap_ch=$(ap_channel)
        [ -n "$ap_ch" ] && [ "$ap_ch" = "$ch" ] && exit 0

**** 热点 AP 执行体

=hotspot-ap= shepherd 服务的执行体：从 =/run= 状态文件读决策脚本选定的信道（缺失或非法即拒绝启动——绝不用默认信道起 AP，2026-09-09 事故的教训之一）、按信道段生成 hw_mode（hostapd 默认 g 只有信道 1-14，5G 信道号配 g 报 "Could not determine operating frequency"，事故中热点 8 连败的真凶）、从 age 密文解出 SSID/密码、纠正接口类型（managed 残留 → __ap，切换需先 down）、配置 uap0 的热点子网地址，最后 exec hostapd 成为 shepherd 跟踪的主进程。凭据只经管道与 =/run= （tmpfs）过境，不落持久盘。变量可用环境覆盖，便于离线测试。

#+NAME: hotspot-ap-run
#+begin_src sh :tangle ../tmp/hotspot-ap-run
#!/bin/sh
# Auto-generated by Guix config.org.

HOTSPOT_IFACE="${HOTSPOT_IFACE:-uap0}"
AP_ADDR="${AP_ADDR:-192.168.77.1/24}"
CONF_DIR="${CONF_DIR:-/run/auto-hotspot}"

HOTSPOT_CREDS_CIPHER="${HOTSPOT_CREDS_CIPHER:-@HOTSPOT_CREDS_CIPHER@}"
AGE_BIN="${AGE_BIN:-@AGE_BIN@}"
IW_BIN="${IW_BIN:-@IW_BIN@}"
IP_BIN="${IP_BIN:-@IP_BIN@}"
SED_BIN="${SED_BIN:-@SED_BIN@}"

#+end_src

信道必须由决策脚本显式提供（安全闸在决策侧，此处是防御性校验）；信道号决定频段与 hw_mode：1-14 是 2.4G（g），其余 5G（a）。

#+begin_src sh :tangle ../tmp/hotspot-ap-run
ch=$(cat "$CHANNEL_FILE" 2>/dev/null)
case "$ch" in
    ''|*[!0-9]*) exit 1 ;;
                 esac

                 if [ "$ch" -le 14 ] 2>/dev/null; then
                     hw_mode=g
                 else
                     hw_mode=a
                 fi

                 creds=$("$AGE_BIN" -d -i "$AGE_IDENTITY" "$HOTSPOT_CREDS_CIPHER" 2>/dev/null) || exit 1
                 ssid=$(printf '%s\n' "$creds" | "$SED_BIN" -n '1p')
                 psk=$(printf '%s\n' "$creds" | "$SED_BIN" -n '2p')
                 [ -n "$ssid" ] && [ -n "$psk" ] || exit 1

                 cur_type=$("$IW_BIN" dev "$HOTSPOT_IFACE" info 2>/dev/null |
                                "$SED_BIN" -n 's/^[[:space:]]*type \([a-z_]*\)$/\1/p')
                 if [ "$cur_type" != "__ap" ]; then
                     "$IP_BIN" link set "$HOTSPOT_IFACE" down 2>/dev/null
                     "$IW_BIN" dev "$HOTSPOT_IFACE" set type __ap || exit 1
                 fi

                 "$MKDIR_BIN" -p "$CONF_DIR"
                 umask 077
                 {
                     echo "interface=$HOTSPOT_IFACE"
                     echo "driver=nl80211"
                     echo "country_code=CN"
                     echo "ieee80211d=1"
                     echo "ssid=$ssid"
                     echo "hw_mode=$hw_mode"
                     echo "channel=$ch"
                     echo "wpa=2"
                     echo "wpa_passphrase=$psk"
                     echo "wpa_key_mgmt=WPA-PSK"
                     echo "rsn_pairwise=CCMP"
                     echo "auth_algs=1"
                     echo "macaddr_acl=0"
                 } > "$conf"

                 "$IP_BIN" addr flush dev "$HOTSPOT_IFACE" 2>/dev/null
                 "$IP_BIN" addr add "$AP_ADDR" dev "$HOTSPOT_IFACE" || exit 1
                 "$IP_BIN" link set "$HOTSPOT_IFACE" up
                 exec "$HOSTAPD_BIN" "$conf"

*** 桌面服务
基于 =%desktop-services= 深度定制：替换显示管理器为 greetd + tuigreet（在 TTY7 启动 Niri 会话），配置 EarlyOOM 内存保护、Thermald 散热守护、Goodix 指纹识别栈（PAM 认证优先）、蓝牙与休眠 Polkit 提权规则。

要点：
- elogind：仅使用 shutdown 模式休眠（platform 模式在此硬件上不可用）；连接电源时合盖只锁屏不挂起。
- earlyoom：PSI 驱动的 OOM 兜底，优先杀浏览器/IM 类大内存进程，保护会话关键进程（shepherd/niri/合成栈/Emacs daemon）。
- thermald：持续负载热管理，维持睿频、防热悬崖；=adaptive= 读 INT340x 自适应表（MTL 已支持），=ignore-cpuid-check= 防新型号被白名单静默拒跑。
- fprintd：指纹栈（定义见自定义包板块），libfprint 1.94.100 经 fprintd 依赖引入；守护进程 D-Bus 按需激活，非 shepherd 服务。
- fingerprint-pam：指纹认证接入 PAM，=pam_fprintd sufficient= 置于 pam_unix 前（对标 NixOS fprintAuth），指纹失败自动回落密码。
- fingerprint-udev：libfprint 的 autosuspend hwdb（含 27c6:689a）挂系统 udev；goodixmoc 走 USB，root 守护进程直连 libusb，无 udev 权限规则需求。
- rtkit：注册 rtkit 的 D-Bus activation，PipeWire 请求 RT 时自动拉起 rtkit-daemon 授予 SCHED_FIFO。
- screen-locker：swaylock 二进制当前不在任何 profile（锁屏走 noctalia），此服务只为保留 =/etc/pam.d/swaylock= 条目——将来切回 swaylock 时装上包即可用，无需再等 PAM 生效。

**** 指纹识别栈

本机传感器 Goodix =27c6:689a= 需 libfprint ≥1.94.9（=goodixmoc= 才认领），Guix 上游 1.94.5 不认——故变体包：libfprint =1.94.100= + fprintd =1.94.5= 两包必须同步升级。变体点（nss→openssl、=udev_hwdb=enabled= 等）与系统侧接线见 source/AGENTS.md；升级仅改两个 version 与对应 hash（=guix hash -f nix-base32=）。

两个 Guix 细节：=inherit= 变体中 thunk 字段的兄弟字段引用只覆盖本表单显式设置的字段，=name= 仅存在于父定义、引用必 unbound，故 origin 内用顶层变量 + 字面量；=content-hash= 用单参字符串形式规避 sha256 字面量遮蔽（同 cachyos-lts 块）。fprintd 1.94.5 提供 libsystemd provider 选项，取代旧 =patch-systemd-dependencies= 的 substitute* 补丁；=pam_wrapper= 已 =required:false= 、python 测试依赖检查仅告警，旧 =ignore-test-dependencies= 补丁不再需要。

***** usb-power-watch 脚本

熄屏断电守护，被上面的 =essential-desktop-services= 以普通用户拉起（shepherd 服务在块内引用 =tmp/usb-power-watch= ）：轮询背光 =bl_power= （普通用户可读，灭屏 0→4），全灭持续 THRESHOLD 秒 → 挂起清单端口上的 USB 设备；复亮立即恢复。覆盖手动 power-off-monitors、合盖关屏等一切熄屏路径；外接无背光屏不产生信号，取向安全侧（不断电）。只读 sysfs，不依赖图形会话——避开 graphical-session 启动竞态导致的拉起失败。

断电端口清单：挂在这些物理 USB 口上的设备（含 hub 子树）无论是什么一律挂起，清单外端口不碰。名称为 =/sys/bus/usb/devices/= 下的设备名（bus-port）；同一物理口的 USB2/USB3 视图各占一个名字（3-5 与 4-5 为同一口），空口列上无副作用。3-2 是外接 dock 的 USB2 视图，键盘/鼠标等 USB2 外设挂其子树；USB3 视图 2-2 不列入——网卡在 2-2.4，避免熄屏断网（USB3 设备不占 USB2 视图，互不影响）。挂起的 HID 收到输入由内核自动恢复，事件不丢；不要把承载远程链路的设备插进清单口。依赖 udev 规则 =95-usb-power-control-perms.rules= 已把 =power/control= 放开为 0666，本脚本以普通用户身份运行。

清单端口熄屏写 auto、亮屏写 on，不看设备当前值也不记挂了谁：写入幂等，熄屏期每轮都执行，新插设备下一轮即被覆盖。

#+NAME: usb-power-watch
#+begin_src sh :tangle ../tmp/usb-power-watch
#!/bin/sh
# Auto-generated by Guix config.org.

THRESHOLD=120
INTERVAL=30

PORTS="3-2 3-5 3-6 4-5 4-6"
in_ports() {
    for p in $PORTS; do
        case "$1" in "$p"|"$p."*) return 0 ;; esac
    done
    return 1
}

set_ports() {
    for dev in /sys/bus/usb/devices/*-*; do
        case "${dev##*/}" in *:*) continue ;; esac   # 跳过接口目录
[ -f "$dev/power/control" ] || continue
if in_ports "${dev##*/}"; then
    echo "$1" > "$dev/power/control" 2>/dev/null
fi
done
}

 off_since=0
 state=on
 while :; do
     lit=0; dark=0
     for b in /sys/class/backlight/*/bl_power; do
         [ -r "$b" ] || continue
         if [ "$(cat "$b" 2>/dev/null)" = 0 ]; then lit=1; else dark=1; fi
     done
     if [ "$lit" = 0 ] && [ "$dark" = 1 ]; then
         now=$(date +%s)
         [ "$off_since" = 0 ] && off_since=$now
         if [ $((now - off_since)) -ge $THRESHOLD ]; then
             set_ports auto; state=off
         fi
     else
         off_since=0
         if [ "$state" != on ]; then set_ports on; state=on; fi
     fi
     sleep $INTERVAL
 done
#+end_src

* Live ISO
:PROPERTIES:
:CUSTOM_ID: iso
:END:

自建 Live 安装镜像的 =operating-system= 声明，与主机 =%system= 独立。
- 构建命令：执行 =blue build-iso= 进行 tangle 并调用 =tools/build-image.scm= 生成 ISO 镜像文件。
- 桌面环境：默认搭载 XFCE + labwc（Wayland），提供 live 用户免密自动登录，包含常用网络排障与系统装机工具链。
- 自包含设计：ISO 镜像专用的模块引用直接内联在本块中，tangle 输出至独立的 =tmp/live-iso.scm= 。
- 精简频道（guix+nonguix）写进 Live 的 =/etc/guix/channels.scm= ；=(gnu packages xfce)= 提供 xfce4-session 包（startxfce4 的 store 路径）；sshd 调试用随系统启动（base OS 默认 =%auto-start? #f= ）。
