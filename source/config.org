*** 服务构造函数

为了消除重复的样板代码，这里将 Shepherd 服务最常见的三种形态封装为辅助函数。其中 =command= 参数接收「可执行程序 + 参数」的列表，列表元素既可以是普通字符串，也可以是 Guix 的可 lower 对象（构建期自动展开为 =/gnu/store/……= 下的真实路径，无需手写绝对路径）：

- *普通字符串* :: 如 ~"/bin/sh"~ 、 ~"--bind-dynamic"~ ，按原样拼入命令行。
- *包内路径与本地文件* :: 如 ~(file-append kdeconnect "/bin/kdeconnect-indicator")~ 或 ~(local-file "usb-power-watch")~ ，构建时自动解析为对应 store 路径。
- *G-expression（gexp，构建期模板）* ::
  - ~define*~ 与 ~#:key~ ：定义带可选关键字参数的函数，调用时未显式传入的参数自动取默认值。
  - =#~(……)= ：声明构建期模板，内部代码不在读取配置时立即执行，而是延后至构建或服务运行期求值。
  - ~#$expr~ 与 ~#$@lst~ ：在模板内插入外部值（包或文件对象在此展开为绝对路径）； ~#$@~ 则会将列表元素逐个摊平拼接到当前位置。
- =home-daemon-service= :: 构造用户态常驻守护进程，自动继承启动时的用户环境变量，并将日志统一落盘至 =$XDG_STATE_HOME/shepherd/<name>.log= 。

#+NAME: home-daemon-service-helpers
#+begin_src scheme
(define* (home-daemon-service name command
                              #:key (requirement '())
                              (auto-start? #t) (respawn? #t)
                              (environment-variables #~(environ))
                              (documentation "[No documentation.]"))
  (shepherd-service
   (provision (list name))
   (requirement requirement)
   (documentation documentation)
   (start #~(make-forkexec-constructor
             (list #$@command)
             #:environment-variables #$environment-variables
             #:log-file (string-append (getenv "XDG_STATE_HOME")
                                       "/shepherd/" #$(symbol->string name)
                                       ".log")))
   (stop #~(make-kill-destructor))
   (auto-start? auto-start?)
   (respawn? respawn?)))
#+end_src

- =root-daemon-service= :: 构造系统级常驻守护进程，支持通过 ~#:log-file~ 指定日志路径，或通过 ~#:one-shot?~ 切换为单次任务。

#+NAME: root-daemon-service-helpers
#+begin_src scheme
(define* (root-daemon-service name command
                              #:key (requirement '())
                              (auto-start? #t) (respawn? #t)
                              one-shot? log-file
                              (documentation "[No documentation.]"))
  (simple-service name shepherd-root-service-type
                  (list (shepherd-service
                         (provision (list name))
                         (requirement requirement)
                         (documentation documentation)
                         (one-shot? one-shot?)
                         (auto-start? auto-start?)
                         (respawn? respawn?)
                         (start #~(make-forkexec-constructor
                                   (list #$@command)
                                   #:log-file #$log-file))
                         (stop #~(make-kill-destructor))))))
#+end_src

- =root-one-shot-service= :: 构造开机仅执行一次的系统初始化任务（ ~one-shot? #t~ ）， ~start~ 直接传入 gexp 过程。

#+begin_quote
*Shepherd 单次服务的两个细节* ：
1. ~stop~ 默认设为 =#~(const #f)= （向 Shepherd 表示「已停止」），对 one-shot 服务而言 ~stop~ 与 ~respawn?~ 均为惰性，调用处无需重复传参。
2. Shepherd 会把 ~start~ 的 gexp 单独序列化并编译为 =.go= 字节码，编译期仅可见 ~#:modules~ 声明的模块（默认为 ~%default-modules~ ）。 *写在 gexp 内部的 ~(use-modules ...)~ 不会参与编译期绑定* ，若用到额外模块（如提供 ~read-line~ 的 ~(ice-9 rdelim)~ ），必须通过 ~#:modules~ 显式追加。
#+end_quote

#+NAME: root-one-shot-service-helpers
#+begin_src scheme

(define* (root-one-shot-service name requirement start
                                #:key (stop #~(const #f))
                                (respawn? #t)
                                (modules %default-modules)
                                (documentation "[No documentation.]"))
  (simple-service name shepherd-root-service-type
                  (list (shepherd-service
                         (provision (list name))
                         (requirement requirement)
                         (documentation documentation)
                         (one-shot? #t)
                         (auto-start? #t)
                         (respawn? respawn?)
                         (modules modules)
                         (start start)
                         (stop stop)))))
#+end_src

- =%flatpak-update-script= :: 生成供系统层或用户态定时器复用的 Flatpak 自动更新脚本（ =scope= 取 ~"system"~ 或 ~"user"~ ）。脚本先用 =grep= 检查外接电源状态（ =/sys/class/power_supply/A*/online= ），电池供电时直接退出并跳过更新，插电时通过 ~exec~ 替换为 =flatpak update= 进程。

#+NAME: flatpak-service-helpers
#+begin_src scheme

(define (%flatpak-update-script scope)
  (mixed-text-file
   (string-append "flatpak-" scope "-update.sh")
   grep "/bin/grep"
   " -q 1 /sys/class/power_supply/A*/online 2>/dev/null"
   " && exec " flatpak "/bin/flatpak"
   " update --" scope " -y"))
#+end_src

* 系统配置

系统层遵循 *最小化原则* ，仅承载底层引导、内核与硬件基础设施；桌面应用与个人开发工具统一交由 [[#home-packages][用户配置（Home 层）]] 管理。

** Bootloader
:PROPERTIES:
:CUSTOM_ID: sys-bootloader
:END:

采用 =rosenthal= 频道提供的 =Limine= 引导方案：构建时通过 =systemd-stub= 将内核与 initrd 打包为可直接由 UEFI 固件拉起的 UKI（Unified Kernel Image）， =Limine= 仅负责展示世代菜单。相比传统 GRUB 在引导阶段用软件解密 LUKS，该方案把解密交给内核 initrd，大幅缩短了全盘加密环境下的冷启动耗时。

#+NAME: bootloader-configs
#+begin_src scheme
(bootloader (bootloader-configuration
             (bootloader limine-efi-removable-bootloader)
             (targets '("/efi"))))
#+end_src

** FileSystems
:PROPERTIES:
:CUSTOM_ID: sys-filesystems
:END:

存储架构采用 *Tmpfs on Root* （无状态内存根）配合 *LUKS 全盘加密 + Btrfs 子卷* ：根目录 =/= 每次关机自动清空，只有显式声明的系统子卷与用户目录才会落盘保存。所有磁盘 UUID、卷标与子卷映射表均集中定义在 [[./information.scm][source/information.scm]] 中（救援脚本 =tools/rescue-chroot.sh= 同样直接解析该文件）。

最终传给系统的 =%file-systems-config= 由以下五层挂载按序拼接而成：

| 挂载分组                               | 数据来源与作用                                                                                     |
|----------------------------------------+----------------------------------------------------------------------------------------------------|
| =%bind-mounts=                         | 遍历 =%data-dirs= 清单，将持久化分区下的 =/data/<目录>= 逐一 =bind-mount= 到 =$HOME/<目录>=        |
| =%persist-filesystem=                  | 用 ~match-lambda~ 解构 =%btrfs-subvolumes= 的 ~(子卷 挂载点)~ 二元组，批量生成 18 条系统级子卷挂载 |
| =%tmpfs=                               | 承载根目录 =/= （10% 内存上限）与 =/var/lock= 的内存文件系统                                       |
| =%data-filesystem= / =%efi-filesystem= | 挂载用户数据主子卷 =/data= 与 EFI 引导分区 =/efi=                                                  |
| =%base-file-systems=                   | Guix 内置基础挂载（ =/dev/pts= 、 =/dev/shm= 、 =efivars= 及只读的 =/gnu/store= 等）               |

- *子卷挂载的两处特判* :: 在 =%persist-filesystem= 的 18 条记录中，仅 =/tmp= 将 ~needed-for-boot?~ 设为 ~#f~ （无需在 initrd 阶段挂载，开机后由 =cleanup-/tmp= 服务清理），且仅 =/gnu= 将 ~check?~ 设为 ~#t~ （挂载前执行文件系统自检）。
- *休眠与独立 Swap* :: 由于 Guile initrd 暂不支持从加密 swap 恢复休眠镜像，此处使用未加密的独立 swap 分区（ =%swap-devices= ），配合内核参数 ~resume=UUID= ……~ 与下文的 =resume-device= 服务实现休眠唤醒。

内核采用本地定制编译的 =linux-cachyos= （详见 [[./files/kernel/AGENTS.md][source/files/kernel/AGENTS.md]]），配套微码与无线/声卡固件取自 =nonguix= 频道。主要内核启动参数的设计意图如下：

**** 回收站放行（utab 注入）

由于用户目录全部通过 Btrfs 子卷或 =bind-mount= 挂载，GLib（GVfs、Thunar 等 GUI 组件）默认会将此类挂载判定为「系统内部挂载（ =system internal= ）」并拒绝移入回收站。解除该限制需要用户态挂载选项 =x-gvfs-trash= ，但内核 ~mount(2)~ 并不认识该选项，而 Guix 挂载文件系统时直接走系统调用、不经过 ~mount(8)~ 写入 =/run/mount/utab= 。因此本服务在开机挂载完成后自动补齐这张表：

- *扫描与过滤* :: 解析 =/proc/self/mountinfo= ，仅挑出 =/data= 与 =$HOME= 下的子卷及 bind 挂载点（系统子卷如 =/gnu= 、 =/var/lib= 保持拒绝回收站）。
- *生成 utab 记录* :: 按 =libmount= 规范向 =/run/mount/utab= 写入完整字段（ ~ID=~ 、 ~SRC=~ 、 ~TARGET=~ 、 ~ROOT=~ 与 ~OPTS=x-gvfs-trash~ ），并将权限设为全局可读（ =0644= ）供用户态进程解析。

#+NAME: trash-utab-services
#+begin_src scheme
(list (root-one-shot-service
       'trash-utab '(file-systems)
       (with-imported-modules (source-module-closure '((guix build utils)))
                              #~(lambda ()
                                  (let ([home-prefix (string-append "/home/" #$username)]
                                        [entries '()])
                                    ;; mountinfo 每行: ID 父ID 主:次 root 挂载点 挂载选项 [可选字段...] - fstype 源 超级选项
                                    ;; 按空格分词后: [0]=ID [3]=root [4]=挂载点; 源在独立 "-" 分词后第 2 个字段
                                    (define (source-of fields)
                                      (let loop ([fs (cdr fields)] [idx 1])
                                        (cond [(null? fs) #f]
                                              [(string=? (car fs) "-")
                                               (and (>= (length fields) (+ idx 3))
                                                    (list-ref fields (+ idx 2)))]
                                              [else (loop (cdr fs) (1+ idx))])))
                                    (call-with-input-file "/proc/self/mountinfo"
                                      (lambda (port)
                                        (let loop ()
                                          (let ([line (read-line port)])
                                            (unless (eof-object? line)
                                              (let ([fields (string-tokenize line)])
                                                (when (>= (length fields) 10)
                                                  (let ([id (list-ref fields 0)]
                                                        [root (list-ref fields 3)]
                                                        [target (list-ref fields 4)]
                                                        [source (source-of fields)])
                                                    ;; root != "/" 即子卷/bind 挂载；只放行用户数据区，
                                                    ;; 系统子卷(/gnu, /var/lib...)保持拒绝回收站
                                                    (when (and source
                                                               (not (string=? root "/"))
                                                               (or (string=? target "/data")
                                                                   (string-prefix? home-prefix target)))
                                                      (set! entries
                                                            (cons (string-append
                                                                   "ID=" id " SRC=" source
                                                                   " TARGET=" target
                                                                   " ROOT=" root
                                                                   " OPTS=x-gvfs-trash")
                                                                  entries))))))
                                              (loop))))))
                                    (mkdir-p "/run/mount")
                                    (call-with-output-file "/run/mount/utab"
                                      (lambda (port)
                                        (for-each (lambda (entry)
                                                    (display entry port)
                                                    (newline port))
                                                  (reverse entries))))
                                    (chmod "/run/mount/utab" #o644)
                                    #t)))
       ;; read-line 来自 (ice-9 rdelim), 必须经 #:modules 进 .scm 顶层 use-modules
       ;; (gexp 内层 use-modules 不参与 shepherd 服务的 .go 编译期绑定)
       #:modules (cons '(ice-9 rdelim) %default-modules)

*** 网络相关配置

网络栈围绕 *nftables 接口信任模型* 与 *Age 机密动态注入* 构建：

- *防火墙模型* :: =nftables= 规则集在开机时一次性全局加载，入站流量默认丢弃（ ~policy drop~ ）；虚拟网桥 =virbr0= 与 =tailscale0= 默认位于 =trusted_ifaces= 白名单集合中，而无线网卡仅在连上可信 WiFi Profile（存于加密文件 =wifi-trust.age= ）时由 NetworkManager dispatcher 动态加入该集合。
- *核心网络服务* :: 同时装配 =mihomo-daemon= （透明代理内核，数据目录位于 =/var/lib/mihomo= ）、 =openssh= （禁止密码登录，root 仅允许密钥认证）、 =tailscale= 以及 WiFi 默认关闭省电策略（ =wifi-powersave.conf= ）。

**** 服务装配

=mihomo-run= 与 =nm-dispatcher-trusted-connection= 两份脚本需要注入 =/gnu/store= 下的绝对路径及机密文件路径，它们遵循同一套四步构建流水线：

1. *抽离模板* :: 下方脚本块通过 ~:tangle ../tmp/<文件名>~ 输出至 =tmp/= 目录（与 =tmp/config.scm= 同级）。
2. *引入构建输入* :: 用 ~(local-file "./<文件名>")~ 将模板纳入 store 构建输入；若路径由 ~string-append~ 动态拼成（如下方的 =secret= 辅助函数），则外包一层 ~assume-source-relative-file-name~ ，避免退化为按当前工作目录解析。
3. *构建期渲染（ =render-script= ）* :: 通过 ~computed-file~ 将模板拷入输出路径，再用 ~substitute*~ 将形如 =@VAR@= 的占位符批量替换为真实 store 路径并赋予 =0555= 可执行权限。
4. *系统激活落盘* :: =mihomo-run= 直接交由 Shepherd 执行；dispatcher 脚本与 WiFi 省电配置则由 activation 服务安装至 =/etc/NetworkManager/= 对应目录。

**** mihomo 启动包装

=mihomo= 的配置模板由不可变层 dotfiles 部署至 =~/.config/mihomo/config.yaml= ，其中订阅链接以 =$MIHOMO_SUB_ONE= / =$MIHOMO_SUB_TWO= 环境变量占位。本启动包装脚本负责在运行期补齐真实订阅并拉起守护进程：

- *渲染与启动流* :: 解密 =mihomo-subscriptions.age= 密文并导出环境变量 → 调用 =envsubst= 将订阅注入 =/var/lib/mihomo/config.yaml= （权限收敛为 =0600= ）→ ~exec~ 启动 =mihomo= 。
- *降级容错设计* :: 脚本刻意不启用 ~set -e~ ：除了配置模板本身缺失会以退出码 1 终止外，若私钥缺失或解密失败，脚本会自动降级为空订阅启动（保证基础直连网络可用），避免触发 Shepherd 无限重启风暴。
- *更换订阅命令* :: 执行 ~secrets set mihomo-subscriptions MIHOMO_SUB_ONE "<url>"~ （或 ~secrets edit~ ）后，运行 ~sudo herd restart mihomo-daemon~ 即可生效。

#+NAME: mihomo-run
#+CAPTION: 解密订阅 → envsubst 渲染模板 → exec mihomo；构建期注入 @VAR@，运行期同名环境变量可覆盖
#+begin_src sh :tangle ../tmp/mihomo-run
#!/bin/sh

AGE_BIN="${AGE_BIN:-@AGE_BIN@}"
AGE_IDENTITY="${AGE_IDENTITY:-@AGE_IDENTITY@}"
CHMOD_BIN="${CHMOD_BIN:-@CHMOD_BIN@}"
ENVSUBST_BIN="${ENVSUBST_BIN:-@ENVSUBST_BIN@}"
MIHOMO_BIN="${MIHOMO_BIN:-@MIHOMO_BIN@}"
MIHOMO_TEMPLATE="${MIHOMO_TEMPLATE:-@MIHOMO_TEMPLATE@}"
MKDIR_BIN="${MKDIR_BIN:-@MKDIR_BIN@}"
MV_BIN="${MV_BIN:-@MV_BIN@}"
SUBS_CIPHER="${SUBS_CIPHER:-@SUBS_CIPHER@}"

log() { echo "mihomo-run: $*" >&2; }
die() { echo "mihomo-run: 失败: $*" >&2; exit 1; }

# DATA_DIR 可环境覆盖，便于离线 mock 测试
DATA_DIR="${DATA_DIR:-/var/lib/mihomo}"
OUT="$DATA_DIR/config.yaml"

"$MKDIR_BIN" -p "$DATA_DIR"
[ -f "$MIHOMO_TEMPLATE" ] || die "模板不存在: $MIHOMO_TEMPLATE (immutable 部署, 需 just home)"

if subs=$("$AGE_BIN" -d -i "$AGE_IDENTITY" "$SUBS_CIPHER" 2>/dev/null); then
    set -a
    eval "$subs"
    set +a
else
    log "警告: 订阅解密失败 (age exit=$?), 以空订阅启动; 密文=$SUBS_CIPHER 私钥=$AGE_IDENTITY"
fi

"$ENVSUBST_BIN" '$MIHOMO_SUB_ONE $MIHOMO_SUB_TWO' <"$MIHOMO_TEMPLATE" >"$OUT.tmp"
"$CHMOD_BIN" 600 "$OUT.tmp"
"$MV_BIN" "$OUT.tmp" "$OUT"
log "配置已渲染: $OUT (sub1=$([ -n "${MIHOMO_SUB_ONE:-}" ] && echo 已注入 || echo 空), sub2=$([ -n "${MIHOMO_SUB_TWO:-}" ] && echo 已注入 || echo 空))"

exec "$MIHOMO_BIN" -d "$DATA_DIR" -f "$OUT"

**** NM dispatcher 脚本

当无线网卡连接状态变化时，NetworkManager 会以 root 身份调用 =/etc/NetworkManager/dispatcher.d/10-trusted-ssid= ，并通过参数传入 =<接口名> <action>= 、通过环境变量传入 =CONNECTION_ID= （NM Profile 名称）：

- *动态集合切换* :: 仅处理无线接口（存在 =/sys/class/net/$IFACE/wireless= ）。在 ~up~ 事件下，脚本在内存管道中解密 =wifi-trust.age= 并精确匹配 =CONNECTION_ID= ，命中则将无线接口加入 nftables 的 =trusted_ifaces= 集合；未命中或触发 ~down~ 事件时立即从集合中移除。
- *安全降级与日志* :: 私钥或密文不可读时一律按「不可信网络」处理（移出集合），绝不阻断正常联网；运行日志输出至 stderr，可按 =trusted-ssid:= 前缀在 =/var/log/messages= 中检索。

#+NAME: nm-dispatcher-trusted-connection
#+CAPTION: NM dispatcher：按加密的可信名单把无线接口加进/移出 nftables trusted_ifaces
#+begin_src sh :tangle ../tmp/nm-dispatcher-trusted-connection
#!/bin/sh

AGE_BIN="@AGE_BIN@"
AGE_IDENTITY="@AGE_IDENTITY@"
GREP_BIN="@GREP_BIN@"
NFT_BIN="@NFT_BIN@"
TRUSTED_CONNECTIONS_CIPHER="@TRUSTED_CONNECTIONS_CIPHER@"
IFACE="$1"
ACTION="$2"
CONNECTION_ID="${CONNECTION_ID:-}"

# 只处理无线接口：有线/虚拟接口的 up/down 不进可信集合
[ -d "/sys/class/net/$IFACE/wireless" ] || exit 0

log() { echo "trusted-ssid: $*" >&2; }

is_trusted_connection() {
    if [ ! -r "$AGE_IDENTITY" ]; then
        log "私钥不可读: $AGE_IDENTITY, 按不可信处理"
        return 1
    fi
    "$AGE_BIN" -d -i "$AGE_IDENTITY" "$TRUSTED_CONNECTIONS_CIPHER" 2>/dev/null |
        "$GREP_BIN" -Fqx -- "$1"
}

remove_wifi_from_trusted_set() {
    "$NFT_BIN" delete element inet filter trusted_ifaces { "$IFACE" } 2>/dev/null || true
}

add_wifi_to_trusted_set() {
    remove_wifi_from_trusted_set
    "$NFT_BIN" add element inet filter trusted_ifaces { "$IFACE" }
}

log "action=$ACTION iface=$IFACE conn='${CONNECTION_ID:-}'"

case "$ACTION" in
    up)
        if [ -z "$CONNECTION_ID" ]; then
            remove_wifi_from_trusted_set
            log "CONNECTION_ID 为空, 无法比对可信名单, 按不可信处理"
        elif is_trusted_connection "$CONNECTION_ID"; then
            if add_wifi_to_trusted_set; then
                log "可信连接 '$CONNECTION_ID': $IFACE 已加入 trusted_ifaces"
            else
                log "nft 添加失败 (exit=$?), trusted_ifaces 可能未更新"
            fi
        else
            remove_wifi_from_trusted_set
            log "不在可信名单: $IFACE 已确保移出 trusted_ifaces"
        fi
        ;;
    down)
        remove_wifi_from_trusted_set
        log "断开: $IFACE 已移出 trusted_ifaces"
        ;;
esac
#+end_src

**** nftables 规则集

防火墙基础规则集在开机时整体加载一次，运行期仅由上方 dispatcher 脚本原子增删 =trusted_ifaces= 集合成员（绝不在运行期执行 ~flush ruleset~ ）：

- *入站与转发控制* :: 默认丢弃所有未匹配入站包，但始终放行已建立连接、本地回环、DHCP/ICMP 基础协议以及 Tailscale WireGuard 直连端口（UDP =41641= ），确保不可信网络下也能正常获取地址与打洞。
- *虚拟机 NAT* :: 为 =virbr0= 网桥配置出站 masquerade 伪装（排除组播与广播地址），供 Libvirt 虚拟机访问外网。

#+NAME: nftables-conf
#+begin_src conf :tangle ../tmp/nftables.conf
flush ruleset

table inet filter {
# The dispatcher temporarily adds the WiFi interface for trusted connection profiles.
set trusted_ifaces {
type ifname
elements = { "virbr0", "tailscale0" }
}

chain input {
type filter hook input priority filter; policy drop;

ct state { established, related } accept
iifname "lo" accept

udp sport 67 udp dport 68 accept
udp sport 547 udp dport 546 accept
ip protocol icmp icmp type {
destination-unreachable,
time-exceeded,
parameter-problem
} accept
ip6 nexthdr ipv6-icmp accept

# VMs and trusted WiFi may access local services.
iifname @trusted_ifaces accept

# Tailscale WireGuard direct endpoint.
udp dport 41641 accept

reject with icmpx type port-unreachable
}

chain forward {
type filter hook forward priority filter; policy drop;

iifname @trusted_ifaces accept
oifname @trusted_ifaces ct state { established, related } accept
}

chain output {
type filter hook output priority 0; policy accept;
}
}

table inet nat {
chain postrouting {
type nat hook postrouting priority srcnat; policy accept;

# Do not masquerade multicast/broadcast traffic from VMs.
iifname "virbr0" ip daddr { 224.0.0.0/4, 255.255.255.255/32 } return
iifname "virbr0" oifname != "virbr0" masquerade
}
}
#+end_src

*** UDEV 规则

集中管理硬件外设节点权限、AC 电源热插拔调优以及 USB 端口熄屏挂起授权。

**** 静态规则

| 调优维度                        | 插电模式（ =on= ）                       | 电池模式（ =off= ）    |
|---------------------------------+------------------------------------------+------------------------|
| *PPD 电源档位*                  | =performance=                            | =power-saver=          |
| *WiFi 省电（动态探测无线口）*   | ~power_save off~ （低延迟优先）          | ~power_save on~        |
| *Intel P-State 频率下限与加速*  | ~min_perf_pct=30~ / ~dynamic_boost=1~    | ~min_perf_pct=8~ / =0= |

        (program-file
         "ac-power-profile"

                           (cadr (command-line))
                           ""))
                 (ppdctl #$ppdctl)
                 (iw-bin #$iw-bin))

                (call-with-output-file path
                  (lambda (port) (display val port)))))

                     '()
                     (let loop ([acc '()])
                       (let ([entry (readdir dir)])
                         (cond [(or (not entry) (eof-object? entry))
                                (closedir dir)
                                (reverse acc)]

                                                             entry "/wireless"))

                               [else (loop acc)]))))))

                           (system* iw-bin "dev" dev "set" "power_save"
                                    (if ac? "off" "on")))
                         (wireless-interfaces))
               (set-sys "/sys/devices/system/cpu/intel_pstate/min_perf_pct"

                        (if ac? "1" "0"))

                        (if ac? "N" "Y"))

                                          "/power/control")

                '("0000:00:02.0"   ; i915 iGPU
                  "0000:01:00.0"   ; YMTC PC300 NVMe
                  "0000:00:14.3")) ; iwlwifi wlp0s20f3
               (set-sys "/sys/module/snd_hda_intel/parameters/power_save"
                        (if ac? "0" "10"))
               ;; KSM 扫描参数仅 AC 写
               (when ac?
                 (set-sys "/sys/kernel/mm/ksm/pages_to_scan" "200")
                 (set-sys "/sys/kernel/mm/ksm/sleep_millisecs" "50"))
               (set-sys "/sys/kernel/mm/ksm/run" (if ac? "1" "0"))
               (set-sys "/proc/sys/kernel/nmi_watchdog" "0")
               (set-sys "/proc/sys/kernel/soft_watchdog" "0"))))]

          "ATTR{type}==\"Mains\", ATTR{online}==\"1\", "

*** Kanata 键盘映射

针对笔记本内置键盘（ =AT Translated Set 2 keyboard= ）定制键位重映射，核心目标是： *在不插外接客制化小键盘时，内置键盘也能提供完全一致的肌肉记忆与层切换手感* 。

外接小键盘的四列依次对应标准键盘的四行（列 4 ↔ =QWERTY= 、列 3 ↔ =ASDF= 、列 2 ↔ =ZXCV= 、列 1 ↔ 底部修饰行），且列首键自上而下为 =Esc= / =Tab= / =Shift= / =Alt= 。据此将内置键盘映射为两层：

- *Base 基础层改动* ：
  - =QWERTY= 行首（物理 =Tab= 键）→ 映射为 =Esc=
  - =ASDF= 行首（物理 =CapsLock= 键）→ 映射为 =Tab= （原 =CapsLock= 下沉至 =fn= 层）
  - 底部左侧前两键（物理 =Left Ctrl= 与 =Left Alt= ）→ 互换位置，对齐小键盘拇指区
  - 右侧 =Right Alt= → 按住激活 =fn= 层（ ~layer-while-held fn~ ）
- *Fn 扩展层映射（按住 =Right Alt= 触发）* ：

| 物理键区                      | Fn 层输出                 | 对应外接小键盘设计         |
|-------------------------------+---------------------------+----------------------------|
| =Q W E R T Y U I O P=         | =1 2 3 4 5 6 7 8 9 0=     | 列 4 的 Fn 层接管整排数字  |
| =A S D F G=                   | =F1 F2 F3 F4 F5=          | 列 3 的 Fn 层左半接管 F1–5 |
| =H J K L=                     | =[ ] ; '=                 | 列 2 的 Fn 层右半接管符号  |
| =Z X C V B N M=               | =F6 F7 F8 F9 F10 F11 F12= | 列 2 的 Fn 层接管 F6–12    |
| 物理 =Tab= （现 Base =Esc= ） | =`= （反引号）            | 小键盘左上角键位           |
| 物理 =CapsLock= （现 =Tab= ） | =CapsLock=                | 在 Fn 层保留大小写锁定     |
| =Backspace= / =Enter=         | =-= （减号，两键同映射）  | 取代原 =\= 与 =Enter= 映射 |

**** usb-power-watch 脚本

配合系统层 ~95-usb-power-control-perms.rules~ （将 USB 设备的 =power/control= 放宽为 =0666= ），在屏幕连续熄灭后自动挂起指定物理 USB 端口上的外设以节省待机功耗，亮屏后立即恢复供电：

- *状态机与防抖* :: 每 =30= 秒轮询一次 =/sys/class/backlight/*/bl_power= （ =0= 表示点亮）。仅当所有背光均处于熄灭状态且持续满 =120= 秒（ =THRESHOLD= ）时，才向白名单端口（ =PORTS= ）写入 =auto= 挂起设备，避免短暂黑屏引发外设断连。
- *唤醒恢复* :: 一旦检测到任一背光点亮（或无可读背光节点时按安全默认视为亮屏），若当前处于挂起态则立即向受管端口写回 =on= 。

#+NAME: usb-power-watch
#+CAPTION: 熄屏守护：连续熄屏 120s 后挂起清单内 USB 物理口，亮屏恢复
#+begin_src sh :tangle ../tmp/usb-power-watch
#!/bin/sh
# usb-power-watch — 熄屏后把清单内物理 USB 口挂起省电，亮屏即恢复供电。

INTERVAL=30
THRESHOLD=120
PORTS="3-2 3-5 3-6 4-5 4-6"

in_ports() {
    for p in $PORTS; do
        case "$1" in "$p"|"$p."*) return 0 ;; esac
    done
    return 1
}

set_ports() {
    for dev in /sys/bus/usb/devices/*-*; do
        case "${dev##*/}" in *:*) continue ;; esac
        [ -f "$dev/power/control" ] || continue
        if in_ports "${dev##*/}"; then
            echo "$1" > "$dev/power/control" 2>/dev/null
        fi
    done
}

off_since=0
state=on
while :; do
    lit=0; dark=0
    for b in /sys/class/backlight/*/bl_power; do
        [ -r "$b" ] || continue
        if [ "$(cat "$b" 2>/dev/null)" = 0 ]; then lit=1; else dark=1; fi
    done
    if [ "$lit" = 0 ] && [ "$dark" = 1 ]; then
        now=$(date +%s)
        [ "$off_since" = 0 ] && off_since=$now
        if [ $((now - off_since)) -ge $THRESHOLD ]; then
            set_ports auto; state=off
        fi
    else
        off_since=0
        if [ "$state" != on ]; then set_ports on; state=on; fi
    fi
    sleep $INTERVAL
done
#+end_src

**** clipsync 剪切板桥接

在 =Niri= + =xwayland-satellite= 架构下，X11 与 Wayland 的 =CLIPBOARD= 彼此隔离、不会自动互相转发，导致只走 X11 剪切板的 XWayland 应用（如 Flatpak 版 QQ、微信等）无法与 Wayland 原生应用互相复制粘贴。本守护脚本（Guile 实现，架构等价于已归档的 [[https://github.com/SHORiN-KiWATA/linuxqq-clipsync][linuxqq-clipsync]]）通过监听 =clipnotify= （X11 侧）与 ~wl-paste --watch echo~ （Wayland 侧），调用 =xclip= 与 =wl-copy= / =wl-paste= 完成双向同步，并与 =cliphist= 历史记录天然兼容。

#+begin_quote
*核心不变量（修改代码前必读，均有实机验证依据）* ：
1. *防环靠归一化内容比对，而非单纯依赖时间窗* ：文本剥除空白与 =NUL= 、URI 列表剥除 =file://= 前缀及 =copy= / =cut= 操作行后再做字节比对；内容相同即视为回声跳过，若删掉内容比对必然触发死循环。
2. *对向 1 秒抑制窗口必须「推迟处理」而非直接丢弃* ：由于本机无自动转发回声，若直接丢弃窗口内的事件，会把用户快速切换窗口时的真实复制永久吞掉。
3. *必须在写入目标剪切板之前调用 ~record!~ 登记状态* ：防止对向监听线程在写入中途回读大图，避开 =xclip= 在 INCR 分块传输下的并发丢包缺陷。
4. *所有读写子进程必须外包 ~timeout 10~* ：当源端窗口意外关闭时， =xclip= 的 INCR 传输会永久挂死，不加超时会直接卡死同步线程。
5. *事件触发后先经 30 ms 去抖（ ~usleep 30000~ ）再读取* ：消除剪切板所有权声明与实际数据可读之间的微小时间差。
#+end_quote

(define %last-time 0)        ; 完成时刻（微秒）
(define %last-norm #f)       ; 最近同步内容的归一化字节串（防环比较基准）

;; ---------- 工具函数 ----------

(define (now-us)
  ;; gettimeofday 返回点对 (sec . usec)，个别实现返回双元素表，两种都要兼容
  (let* ([t (gettimeofday)] [rest (cdr t)])
    (+ (* (car t) 1000000) (if (pair? rest) (car rest) rest))))

(define (logline tag fmt . args)
  (format #t "[~a ~a] ~?\n"
          (strftime "%H:%M:%S" (localtime (current-time))) tag fmt args)
  (force-output))

(define (clip-read . args)
  ;; 子进程必须包 timeout：对端死亡时 xclip 的 INCR 传输挂死，会拖死线程
  ;; 返回 bytevector 或 #f（无内容 / 超时 / 子进程失败）
  (let* ([p (apply open-pipe* OPEN_READ "timeout" "10" args)]
         [bv (get-bytevector-all p)]
         [status (close-pipe p)])
    (and (not (eof-object? bv)) (zero? status)
         (> (bytevector-length bv) 0) bv)))

(define (clip-write bv . args)
  (catch #t
    (lambda ()
      (let ([p (apply open-pipe* OPEN_WRITE "timeout" "10" args)])
        (put-bytevector p bv)
        (force-output p)
        (zero? (close-pipe p))))
    (lambda args #f)))

;; ---------- 内容归一化（防环比较的基准，见不变量 1） ----------

(define (norm-text bv)
  ;; 去空白与 NUL 后比较：容忍 xclip / wl-copy 之间的尾部换行差异
  (string->utf8
   (string-filter (lambda (c) (not (memv c '(#\nul #\newline #\return #\space #\tab))))
                  (utf8->string bv))))

(define (norm-uri bv)
  (define (strip-file-uri s)
    (if (string-prefix? "file://" s) (substring s 7) s))
  (let loop ([lines (string-split (utf8->string bv) #\newline)]
             [acc '()])
    (cond [(null? lines)
           (string->utf8 (apply string-append (reverse acc)))]
          [else
           (let ([t (string-trim-both (car lines))])
             (cond [(or (member t '("copy" "cut")) (string=? t ""))
                    (loop (cdr lines) acc)]
                   [else (loop (cdr lines) (cons (strip-file-uri t) acc))]))])))

(define (normalize bv mode)
  (catch #t
    (lambda ()
      (let ([r (case mode
                 [(text) (norm-text bv)]
                 [(uri) (norm-uri bv)]
                 [else bv])])
        (and (> (bytevector-length r) 0) r)))
    (lambda args #f)))

(define (sanitize-uri-list bv)
  ;; 写入前净化：丢 copy/cut 操作行，裸路径补 file://，使两端格式一致
  (let loop ([lines (string-split (utf8->string bv) #\newline)]
             [acc '()])
    (if (null? lines)
        (string->utf8 (string-join (reverse acc) "\n"))
        (let ([t (string-trim-both (car lines))])
          (cond [(or (member t '("copy" "cut")) (string=? t ""))
                 (loop (cdr lines) acc)]
                [(string-prefix? "/" t)
                 (loop (cdr lines) (cons (string-append "file://" t) acc))]
                [else (loop (cdr lines) (cons t acc))])))))

;; ---------- 同步核心 ----------

(define (wait-out-suppression! opposite-dir)
  ;; 对向写入 1s 内的事件不丢弃，推迟到窗口结束再处理（不变量 2：
  ;; 无自动转发回声的环境下，直接跳过会吞掉窗口内的真实复制）
  (let loop ()
    (lock-mutex %lock)
    (let ([sup (and (string=? %last-dir opposite-dir)
                    (< (- (now-us) %last-time) 1000000))])
      (unlock-mutex %lock)
      (when sup (usleep 100000) (loop)))))

(define (same-as-last? norm)
  (lock-mutex %lock)
  (let ([r (and %last-norm norm (bytevector=? %last-norm norm))])
    (unlock-mutex %lock)
    r))

(define (record! dir norm)
  ;; 必须在写入目标剪切板之前登记，防对向线程在写入中回读大图（不变量 3）
  (lock-mutex %lock)
  (set! %last-dir dir)
  (set! %last-time (now-us))
  (set! %last-norm norm)
  (unlock-mutex %lock))

(define (handle-x11->wayland)
  (let* ([types-bv (clip-read "xclip" "-selection" "clipboard" "-t" "TARGETS" "-o")]
         [types (and types-bv (catch #t (lambda () (utf8->string types-bv))
                                (lambda args #f)))])
    (when types
      (let ([pick (pick-x11 types)])
        (when pick
          (let* ([src (car pick)] [dst (cadr pick)] [mode (caddr pick)])
            (let ([data (clip-read "xclip" "-selection" "clipboard" "-o" "-t" src)])
              (when data
                (let ([norm (normalize data mode)])
                  (when (and norm (not (same-as-last? norm)))
                    (logline "X2W" "同步 ~a (~a 字节)" dst (bytevector-length data))
                    (let ([out (if (eq? mode 'uri) (sanitize-uri-list data) data)])
                      (record! "X2W" norm)
                      (clip-write out "wl-copy" "-t" dst))))))))))))

(define (handle-wayland->x11)
  (let* ([types-bv (clip-read "wl-paste" "--list-types")]
         [types (and types-bv (catch #t (lambda () (utf8->string types-bv))
                                (lambda args #f)))])
    (when types
      (let ([pick (pick-wayland types)])
        (when pick
          (let* ([src (car pick)] [mode (cadr pick)])
            (let ([data (clip-read "wl-paste" "-n" "-t" src)])
              (when data
                (let ([norm (normalize data mode)])
                  (when (and norm (not (same-as-last? norm)))
                    (let* ([out (if (eq? mode 'uri) (sanitize-uri-list data) data)]
                           [target (if (or (string=? src "text/plain")
                                           (string=? src "text/plain;charset=utf-8"))
                                       "UTF8_STRING" src)])
                      (logline "W2X" "同步 ~a (~a 字节)" target (bytevector-length data))
                      (record! "W2X" norm)
                      (clip-write out "xclip" "-selection" "clipboard" "-i" "-t"
                                  target))))))))))))

(define (x11-watcher)
  (logline "SYS" "X11 监视线程启动")
  (let loop ([fast-exits 0])
    (let ([t0 (now-us)])
      (system* "timeout" "3600" "clipnotify")
      (let ([elapsed (- (now-us) t0)])
        (cond [(< elapsed 100000)
               ;; clipnotify 秒退说明 X 连接异常：退避重试，连续 5 次放弃（交 shepherd respawn）
               (if (>= fast-exits 4)
                   (begin (logline "ERR" "clipnotify 持续秒退，X11 事件源失效，守护退出")
                          (primitive-exit 1))
                   (begin (sleep 1) (loop (1+ fast-exits))))]
              [else
               ;; 30ms 去抖：所有权生效与数据可读之间有时序差（不变量 5）
               (usleep 30000)
               (wait-out-suppression! "W2X")
               (handle-x11->wayland)
               (loop 0)])))))

(define (wayland-watcher)
  (logline "SYS" "Wayland 监视启动")
  (let ([p (open-pipe* OPEN_READ "wl-paste" "--watch" "echo")])
    ;; echo 的输出内容无意义，只把「每次剪切板变化」变成一行事件信号
    (let loop ()
      (let ([line (read-line p)])
        (if (eof-object? line)
            (begin (logline "ERR" "wl-paste --watch 退出，守护退出") (primitive-exit 1))
            (begin (usleep 30000)
                   (wait-out-suppression! "X2W")
                   (handle-wayland->x11)
                   (loop)))))))

**** kb-backup 备份脚本

每晚自动为两处本地高频演进数据生成 Git 快照，日志追加至 =~/.cache/kb-backup.log= ：

- *两步独立容错* :: 依次备份本仓库的 =dotfiles/mutable/agents/hermes= 子目录（通过 Stow 软链反推仓库根路径，仅 ~git add~ 该子目录以防误吞其他未提交工作）与 =~/Documents/Org= 知识库。工作区无改动时静默跳过；任一步失败仅记录告警日志，最终退出码恒为 =0= 。

#+NAME: kb-backup-script
#+CAPTION: 每日自动 commit hermes 包与 Org 知识库；两步独立容错，退出码恒 0
#+begin_src sh :tangle ../tmp/kb-backup
#!/bin/sh
# kb-backup: hermes + Org 知识库每日自动 commit，日志追加 ~/.cache/kb-backup.log。

PATH="$HOME/.guix-home/profile/bin:/run/current-system/profile/bin:$PATH"
log="$HOME/.cache/kb-backup.log"
mkdir -p "$(dirname "$log")"
warn() { echo "[$(date '+%Y-%m-%d %H:%M:%S')] WARN: $1" >>"$log"; }

# hermes 包: 仅 add 该子目录，避免吞并用户未提交的 WIP。
# 仓库根经 HERMES_HOME 锚点反推（stow 链回仓库的文件），不写死路径。
(
    hermes_home="${HERMES_HOME:-$HOME/.local/share/hermes}"
    repo=""
    for anchor in "$hermes_home/config.yaml" "$hermes_home/SOUL.md"; do
        [ -L "$anchor" ] || continue
        target=$(readlink -f "$anchor") || continue
        repo=$(git -C "$(dirname "$target")" rev-parse --show-toplevel 2>/dev/null) || continue
        break
    done
    [ -n "$repo" ] || { echo "找不到链回仓库的 hermes 锚点文件 ($hermes_home)"; exit 1; }
    git -C "$repo" add dotfiles/mutable/agents/hermes || exit 1
    git -C "$repo" diff --cached --quiet || git -C "$repo" commit -m "chore(hermes): backup $(date)" || exit 1
) >>"$log" 2>&1 || warn "hermes 备份失败, 详见上方 git 输出"

# Org 知识库: agenote 卡片仓库，本地无 remote，add -A 安全
(
    cd "$HOME/Documents/Org" || exit 1
    git add -A || exit 1
    git diff --cached --quiet || git commit -m "chore(backup): auto $(date '+%Y-%m-%d %H:%M:%S')" || exit 1
) >>"$log" 2>&1 || warn "Org 知识库备份失败, 详见上方 git 输出"
#+end_src

* Live ISO
:PROPERTIES:
:CUSTOM_ID: iso
:END:

自包含的 *系统救援 + 全新装机* 双用途 Live ISO 声明（与宿主机的 =%system= 独立，通过 =blue build-iso= 抽离至 =tmp/live-iso-<variant>.scm= 并交由 =tools/build-image.scm= 构建镜像，详见 [[../docs/iso-build.md][docs/iso-build.md]]）：

| 变体名称  | 输出文件                   | 适用场景与会话设计                                                                                                  |
|-----------+----------------------------+---------------------------------------------------------------------------------------------------------------------|
| =desktop= | =tmp/live-iso-desktop.scm= | 搭载 =XFCE= + =labwc= （Wayland）与 =IceCat= 浏览器，开机自动免密登录 =live= 用户桌面，网络走 NetworkManager        |
| =minimal= | =tmp/live-iso-minimal.scm= | 纯终端轻量救援盘： =TTY1= 保留官方 TUI 安装器（网络走 connman）， =TTY2= 为手册， =TTY3= – =TTY6= 为免密 root Shell |

- *开箱即用的救砖与装机载荷* :: 镜像内直接将 =rescue-chroot.sh= 与 =emergency-blue.sh= 打包进系统 =PATH= （ =live-rescue-tools= ），并将当前仓库快照（剔除 =.git= 、 =dist= 与 =tmp= ）预置到 =~/Guix-configs= ，配合内嵌的 =emacs-minimal= ，启动后无需联网克隆即可直接执行 ~emergency-blue.sh init~ 。
- *硬件兼容性与远程排障* :: 内置完整 =linux= 内核与 =linux-firmware= ，并移除了上游安装盘默认屏蔽 AMD 显卡 KMS 的 ~modprobe.blacklist=radeon,amdgpu~ 参数；同时默认自启 =sshd= 并允许密码登录（ =root= 与 =live= 账户密码均为 =live= ）。
- *模块自包含* :: 两个变体块各自在顶部内联所需的 ~use-modules~ ，公共底座通过 ~<<live-common>>~ 展开，唯一跨区复用的代码块是上文的系统级 ~<<guix-substitutes>>~ 镜像源配置。
