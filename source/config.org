*** 服务构造函数
对 shepherd 服务的三种高频形态进行封装，来方便配置文件全局进行调用。

=command= 为「程序 + 参数」的 argv 列表：第一个元素是程序，其余每个元素是一个参数，逐段列出而非写成一整条命令字符串。元素可以是字符串，也可以是可 lower 对象——构建期统一展开为具体值后拼成真正的命令行：

- 字符串： ="/bin/sh"= 、 ="--bind-dynamic"= -> 原样使用；
- 可 lower 对象：
   =(file-append kdeconnect "/bin/kdeconnect-indicator")= -> 展开为 =/gnu/store/…= 下的绝对路径
   =(local-file "usb-power-watch")= -> 指向本地文件
   gexp =#~(…)= -> 在构建期求值。
因此无需手写 =/gnu/store= 路径，直接引用包对象即可。

上面这些写法能成立，靠的是 Guix 的 gexp（构建期模板）机制。本节三个封装只用到下面这几个语法点，先在此集中说明：

- =define*= 与 =#:key= :: 定义带关键字可选参数的函数：形如 =#:requirement= 的形参调用时可以不传，不传就取定义处写好的默认值；
- =#~(…)= :: 构建期模板，括号内的代码不在读取配置时求值，而是留到构建阶段再求值；
- =#$expr= :: 在模板中插入一个构建期已知的值（包对象、 =string-append= 的结果等），包与文件对象在此处展开为其绝对路径；
- =#$@lst= :: 与 =#$= 类似，但要求 =lst= 是列表：把其中每个元素依次拼接到当前位置。

+ =home-daemon-service= ：用户常驻进程，日志统一写入到 =$XDG_STATE_HOME/shepherd/<name>.log= 中。会自动继承调用时的用户环境。
#+NAME: home-daemon-service-helpers
#+begin_src scheme
(define* (home-daemon-service name command
                              #:key (requirement '())
                              (auto-start? #t) (respawn? #t)
                              (documentation "[No documentation.]"))
  (shepherd-service
   (provision (list name))
   (requirement requirement)
   (documentation documentation)
   (start #~(make-forkexec-constructor
             (list #$@command)
             #:environment-variables (environ)
             #:log-file (string-append (getenv "XDG_STATE_HOME")
                                       "/shepherd/" #$(symbol->string name)
                                       ".log")))
   (stop #~(make-kill-destructor))
   (auto-start? auto-start?)
   (respawn? respawn?)))
#+end_src

+ =root-daemon-service= ：系统常驻进程，支持 =#:log-file= 与 =#:one-shot?= 。
#+NAME: root-daemon-service-helpers
#+begin_src scheme
(define* (root-daemon-service name command
                              #:key (requirement '())
                              (auto-start? #t) (respawn? #t)
                              one-shot? log-file
                              (documentation "[No documentation.]"))
  (simple-service name shepherd-root-service-type
                  (list (shepherd-service
                         (provision (list name))
                         (requirement requirement)
                         (documentation documentation)
                         (one-shot? one-shot?)
                         (auto-start? auto-start?)
                         (respawn? respawn?)
                         (start #~(make-forkexec-constructor
                                   (list #$@command)
                                   #:log-file #$log-file))
                         (stop #~(make-kill-destructor))))))
#+end_src

+ =root-one-shot-service= ：开机跑一次即退出（one-shot + 不 respawn）， =start= / =#:stop= 直接传 gexp。
  =stop= 默认 =(const #f)= ——向 shepherd 返回「已停止」的正确值； =respawn?= 默认 #t。对 one-shot 服务这两者均惰性（start 成功即视为 stopped、进程退出也不 respawn），调用处无需再传这两个参数。
  =#:modules= 默认 =%default-modules= （ =shepherd service= + =guix build utils= + =guix build syscalls= ）。shepherd 服务的 =start= gexp 会被序列化成独立 .scm 再编译成 .go，编译环境只有这些模块——**gexp 内层写的 =(use-modules …)= 不参与编译期绑定**，运行到未绑定变量才报错。需要额外模块（如 =(ice-9 rdelim)= 提供 =read-line= ）时，必须经此参数追加进顶层 use-modules。
#+NAME: root-one-shot-service-helpers
#+begin_src scheme

(define* (root-one-shot-service name requirement start
                                #:key (stop #~(const #f))
                                (respawn? #t)
                                (modules %default-modules)
                                (documentation "[No documentation.]"))
  (simple-service name shepherd-root-service-type
                  (list (shepherd-service
                         (provision (list name))
                         (requirement requirement)
                         (documentation documentation)
                         (one-shot? #t)
                         (auto-start? #t)
                         (respawn? respawn?)
                         (modules modules)
                         (start start)
                         (stop stop)))))
#+end_src

+ 每日备份脚本（ =kb-backup= timer 专用）：对 Guix-configs 的 hermes 包与 =~/Documents/Org= 知识库各自 =git add= 后，无变更即静默跳过、有变更则按既有风格 =git commit= ；任一步 git 命令失败（如 index.lock 冲突、gpg 签名失败）只向 =~/.cache/kb-backup.log= 追加一条带时间戳的 warning 并继续下一步，整体退出码恒为 0。
  git 与 gpg 通过脚本内 PATH 前缀（home profile + system profile）定位，不依赖 shepherd 运行环境；提交签名沿用用户 gitconfig（ =commit.gpgsign= ）。
#+NAME: kb-backup-script
#+begin_src scheme

(define (%kb-backup-script)
  (mixed-text-file
   "kb-backup.sh"
   "#!/bin/sh\n"
   "# kb-backup: hermes + Org 知识库每日自动 commit, 日志追加 ~/.cache/kb-backup.log\n"
   "PATH=\"$HOME/.guix-home/profile/bin:/run/current-system/profile/bin:$PATH\"\n"
   "log=\"$HOME/.cache/kb-backup.log\"\n"
   "mkdir -p \"$(dirname \"$log\")\"\n"
   "warn() { echo \"[$(date '+%Y-%m-%d %H:%M:%S')] WARN: $1\" >>\"$log\"; }\n"
   "\n"
   ;; hermes 包: 仅 add 该子目录, 避免吞并用户未提交的 WIP
   ;; 仓库根经 HERMES_HOME 锚点反推（stow 链回仓库的文件），不写死路径
   "(\n"
   "  hermes_home=\"${HERMES_HOME:-$HOME/.local/share/hermes}\"\n"
   "  repo=\"\"\n"
   "  for anchor in \"$hermes_home/config.yaml\" \"$hermes_home/SOUL.md\"; do\n"
   "    [ -L \"$anchor\" ] || continue\n"
   "    target=$(readlink -f \"$anchor\") || continue\n"
   "    repo=$(git -C \"$(dirname \"$target\")\" rev-parse --show-toplevel 2>/dev/null) || continue\n"
   "    break\n"
   "  done\n"
   "  [ -n \"$repo\" ] || { echo \"找不到链回仓库的 hermes 锚点文件 ($hermes_home)\"; exit 1; }\n"
   "  git -C \"$repo\" add dotfiles/mutable/agents/hermes || exit 1\n"
   "  git -C \"$repo\" diff --cached --quiet || git -C \"$repo\" commit -m \"chore(hermes): backup $(date)\" || exit 1\n"
   ") >>\"$log\" 2>&1 || warn \"hermes 备份失败, 详见上方 git 输出\"\n"
   "\n"
   ;; Org 知识库: agenote 卡片仓库, 本地无 remote, add -A 安全
   "(\n"
   "  cd \"$HOME/Documents/Org\" || exit 1\n"
   "  git add -A || exit 1\n"
   "  git diff --cached --quiet || git commit -m \"chore(backup): auto $(date '+%Y-%m-%d %H:%M:%S')\" || exit 1\n"
   ") >>\"$log\" 2>&1 || warn \"Org 知识库备份失败, 详见上方 git 输出\"\n"))
#+end_src

** FileSystems
:PROPERTIES:
:CUSTOM_ID: sys-filesystems
:END:

存储采用 =tmpfs on rootfs= 作为基础，利用 =LUKS 加密的 Btrfs Subvolume= 来持久化需要的数据：
- 根目录 =/= 挂载在 tmpfs，关机即清空。
- 关键系统数据与用户目录持久化存储于 Btrfs 子卷中，直接挂载到对应目录，子卷清单与挂载点定义于 [[./information.scm][information.scm]] 。
- 休眠到独立 swap 分区（由于 Guile initrd 有限制，所以只能采用没有加密的 swap 恢复）。

最终生效的 =file-systems= 由下列部分按顺序 =append= 而成（ =main= 里只写 =(file-systems %file-systems-config)= ）：
1. =%bind-mounts= ： =%data-dirs= 里每个目录（清单同样在 [[./information.scm][information.scm]] ）对应一条 bind-mount，把 =/data/<目录>= 挂到 =$HOME/<目录>= ；
2. =%persist-filesystem= ：由 =%btrfs-subvolumes= 数据表逐条生成 18 条 Btrfs 子卷挂载；
3. =%tmpfs= ：根 =/= 与 =/var/lock= 两条 tmpfs 记录（整棵根文件系统就是 tmpfs，所以取这个名字）；
4. =%data-filesystem= 与 =%efi-filesystem= ： =/data= 子卷与 EFI 分区各一条；
5. =%base-file-systems= ：Guix 预置的基础挂载（ =/dev/pts= 、 =/sys/kernel/debug= 、 =/dev/shm= 、 =/sys/firmware/efi/efivars= ，以及只读的 =/gnu/store= bind-mount）。

=%persist-filesystem= 读作「把 =%btrfs-subvolumes= 的每条记录变成一条 =file-system= 」：该表是 =(子卷路径 挂载点)= 二元组列表， =match-lambda= 的 =(subvol mount-point)= 子句逐条解构这两项，再填进 =device= / =mount-point= / =options= 等字段；表内顺序即生成顺序，每条都通过 =(dependencies %mapped-devices-config)= 依赖 LUKS 解锁先于挂载。18 条挂载里有两处特判，其余记录取值相同：
- =/tmp= 不设 =needed-for-boot?= （不需要在 initrd 阶段挂载，开机后再挂；它的开机清理由 =cleanup-/tmp= 服务负责），其他挂载点都是 =#t= ；
- =/gnu= 是唯一把 =check?= 设为 =#t= 的挂载点，即挂载前先做一次文件系统检查，其余记录都是 =#f= 。

另外 =%swap-uuid= 有意定义在本段：它是 swap 分区 UUID 的单一真源，Kernel 段的 resume=UUID= 内核参数（该字符串自带等号，加等宽标记会破坏 org 配对，故用普通文本）与 =resume-device= 服务都引用它。

加载 =ip_tables= 与 =iptable_nat= 作为兼容层，供 Libvirt 与 Podman 网络后端使用；

**** 回收站放行（utab 注入）
本机用户数据都住在 btrfs 子卷 / bind-mount 上，GLib（GVfs、Thunar 等绝大多数 GUI 应用）把这类挂载一律判为 =system internal= 而拒绝回收站操作（报「不支持在系统内部挂载上的丢弃到回收站操作」）。逃逸开关是挂载选项 =x-gvfs-trash= ，但它是纯用户态选项，内核不认、不能写进挂载参数；用户态的读取方（libmount）会从 =/run/mount/utab= 把用户选项按挂载 ID 合并进挂载表。Guix 直接 =syscall mount= 不经过 =mount(8)= ，从不写这个文件，所以这里开机补写：
+ 服务在 =file-systems= 就绪后运行一次，扫描 =/proc/self/mountinfo= ，给 =/data= 与 =$HOME= 下所有数据挂载点生成 =ID= SRC= TARGET= ROOT= OPTS=x-gvfs-trash= 行（=SRC= / =ROOT= 为 libmount 合并的必填字段，缺了整行被丢弃）；
+ 写到 =/run/mount/utab= （tmpfs，重开机自然清空，挂载 ID 也随重启变化，所以必须每次开机重算）；
+ 目录 =/run/mount= 需事先存在且普通用户可读（GLib 在用户进程里解析该文件）。

#+NAME: trash-utab-services
#+begin_src scheme
(list (root-one-shot-service
       'trash-utab '(file-systems)
       (with-imported-modules (source-module-closure '((guix build utils)))
                              #~(lambda ()
                                  (let ([home-prefix (string-append "/home/" #$username)]
                                        [entries '()])
                                    ;; mountinfo 每行: ID 父ID 主:次 root 挂载点 挂载选项 [可选字段...] - fstype 源 超级选项
                                    ;; 按空格分词后: [0]=ID [3]=root [4]=挂载点; 源在独立 "-" 分词后第 2 个字段
                                    (define (source-of fields)
                                      (let loop ([fs (cdr fields)] [idx 1])
                                        (cond [(null? fs) #f]
                                              [(string=? (car fs) "-")
                                               (and (>= (length fields) (+ idx 3))
                                                    (list-ref fields (+ idx 2)))]
                                              [else (loop (cdr fs) (1+ idx))])))
                                    (call-with-input-file "/proc/self/mountinfo"
                                      (lambda (port)
                                        (let loop ()
                                          (let ([line (read-line port)])
                                            (unless (eof-object? line)
                                              (let ([fields (string-tokenize line)])
                                                (when (>= (length fields) 10)
                                                  (let ([id (list-ref fields 0)]
                                                        [root (list-ref fields 3)]
                                                        [target (list-ref fields 4)]
                                                        [source (source-of fields)])
                                                    ;; root != "/" 即子卷/bind 挂载；只放行用户数据区，
                                                    ;; 系统子卷(/gnu, /var/lib...)保持拒绝回收站
                                                    (when (and source
                                                               (not (string=? root "/"))
                                                               (or (string=? target "/data")
                                                                   (string-prefix? home-prefix target)))
                                                      (set! entries
                                                            (cons (string-append
                                                                   "ID=" id " SRC=" source
                                                                   " TARGET=" target
                                                                   " ROOT=" root
                                                                   " OPTS=x-gvfs-trash")
                                                                  entries))))))
                                              (loop))))))
                                    (mkdir-p "/run/mount")
                                    (call-with-output-file "/run/mount/utab"
                                      (lambda (port)
                                        (for-each (lambda (entry)
                                                    (display entry port)
                                                    (newline port))
                                                  (reverse entries))))
                                    (chmod "/run/mount/utab" #o644)
                                    #t)))
       ;; read-line 来自 (ice-9 rdelim), 必须经 #:modules 进 .scm 顶层 use-modules
       ;; (gexp 内层 use-modules 不参与 shepherd 服务的 .go 编译期绑定)
       #:modules (cons '(ice-9 rdelim) %default-modules)
       #:documentation "Inject x-gvfs-trash into /run/mount/utab for user data mounts."))
#+end_src

*** 网络相关配置
防火墙采用接口信任模型：
+ nftables 规则集 *开机加载一次* ，之后就只会由 NM dispatcher 来原子增删 =trusted_ifaces= 成员
+ *可信 WiFi 名单* 存于 =wifi-trust.age= 加密文件中。

**** 服务装配
本块装配的服务：
- =nm-powersave-conf= ：电池供电时由 ~ac-power~ 这条 udev 规则来进行切换，电源未连接的时候启用 WiFi 省电，以此达到省电的效果。
- =openssh= ：root 仅允许通过密钥登录。
- =mihomo-daemon= ：数据目录放到 =/var/lib/mihomo= ；利用 =mihomo-run= 来将配置文件的模板填入真正的订阅链接。

其中 =mihomo-run= 与 =nm-dispatcher-trusted-connection= 两个模板脚本（见下文的小节）不是被直接引用的，而是经同一条流水线变成可执行文件：

1. 各自的脚本块用 =:tangle ../tmp/<文件名>= 把脚本原文写进仓库根目录的 =tmp/= （ =main= 块自己也 tangle 成 =tmp/config.scm= ，所以 =tmp/= 是「源码与产物同目录」的约定）；
2. =(local-file "./<文件名>")= 把这份 tangle 产物作为构建输入引入。 =local-file= 对字符串字面量的相对路径按「相对当前 Scheme 源文件所在目录」解析，而当前源文件就是 =tmp/config.scm= ，因此 ="./nftables.conf"= 就是 =tmp/nftables.conf= ；用 =string-append= 拼出来的路径享受不到这条规则（会退化成相对 cwd），要额外包一层 =assume-source-relative-file-name= （ =secret= 就是为此）；
3. =render-script= 用 =computed-file= 在构建期把模板复制进 store 输出，跑 =substitute*= 把 =@XXX@= 占位符换成真实 store 路径，再 =chmod= 555；
4. 最后： =mihomo-run= 的产物由 shepherd 当命令直接执行；dispatcher 脚本文本由 activation 服务 =install= 到 =/etc/NetworkManager/dispatcher.d/10-trusted-ssid= ； =nm-powersave-conf= 作为 =plain-file= 由 activation 服务写到 =/etc/NetworkManager/conf.d/wifi-powersave.conf= ；nftables 规则集交给 =nftables-service-type= 。activation 代码运行在目标系统上（不是构建期），所以里面直接用裸命令 =mkdir= / =install= / =rm= ，按 =PATH= 解析。

=render-script= 的第三个参数是一张 =(占位符 . 替换值)= alist， =map= + =match-lambda= 把它逐条拍成 =substitute*= 的子句： =(list (list pattern) replacement)= 生成的就是 =(("正则") 替换文本)= 。 =substitute*= 的子句形态是 =((正则 捕获变量…) 替换表达式…)= ，这里不捕获任何变量，替换表达式就是要注入的 store 路径字符串； =pattern= 按 POSIX 扩展正则解释（ =substitute*= 内部以 =make-regexp= 的 =regexp/extended= 语法编译），而 =@XXX@= 里没有正则元字符，所以是按字面量匹配。

占位符与替换值靠 **名字** 对应，且没有构建期检查：模板里写错一个 =@XXX@= 不会报错，只会把这个名字原样留在脚本里。两张对照表（照下面的代码）：

=spec->pkg= 与 =pkg-bin= 是上面 =let*= 里的两个小工具： =spec->pkg= 来自 rosenthal 频道的 =rosenthal utils packages= ，就是 =(gnu packages)= 的 =specification->package= —— 按字符串包名查包、返回包对象，适合「只用到某个包里一两个程序」的场合（不必为它写 =use-package-modules= 导入）； =pkg-bin= 在此基础上拼出程序路径： =(pkg-bin "coreutils" "/bin/mv")= 展开为 =/gnu/store/…-coreutils-…/bin/mv= 。这些绝对路径在构建期就固定，脚本运行时不需要 PATH。

**** mihomo 启动包装
模板由 dotfiles immutable 部署到 =~/.config/mihomo/config.yaml= ，订阅 URL 以 =$MIHOMO_SUB_ONE/TWO= 占位；
daemon 启动时会解密 =mihomo-subscriptions.age= （使用全局统一的私钥），通过 ~envsubst~ 来将订阅链接写入到 =/var/lib/mihomo/config.yaml= 之后再启动。解密失败则降级为空订阅状态启动（直连仍可用），防止反复 respawn；
换订阅： =secrets set mihomo-subscriptions MIHOMO_SUB_ONE "<url>"= （或 =secrets edit= ） 后 =herd restart mihomo-daemon= 。

脚本开头 9 行采用 =${VAR:-@VAR@}= 形式：构建期由「服务装配」的替换表把 =@VAR@= 填成 store 路径，运行期同名环境变量可以覆盖它（ =DATA_DIR= 那行是同一模式、默认值为字面量，注释里写明了用途）。占位符名与替换表必须一致，写错不会有构建报错，只会把 =@VAR@= 原样留在脚本里。

#+NAME: mihomo-run
#+begin_src sh :tangle ../tmp/mihomo-run
#!/bin/sh

AGE_BIN="${AGE_BIN:-@AGE_BIN@}"
AGE_IDENTITY="${AGE_IDENTITY:-@AGE_IDENTITY@}"
CHMOD_BIN="${CHMOD_BIN:-@CHMOD_BIN@}"
ENVSUBST_BIN="${ENVSUBST_BIN:-@ENVSUBST_BIN@}"
MIHOMO_BIN="${MIHOMO_BIN:-@MIHOMO_BIN@}"
MIHOMO_TEMPLATE="${MIHOMO_TEMPLATE:-@MIHOMO_TEMPLATE@}"
MKDIR_BIN="${MKDIR_BIN:-@MKDIR_BIN@}"
MV_BIN="${MV_BIN:-@MV_BIN@}"
SUBS_CIPHER="${SUBS_CIPHER:-@SUBS_CIPHER@}"

log() { echo "mihomo-run: $*" >&2; }
die() { echo "mihomo-run: 失败: $*" >&2; exit 1; }

# DATA_DIR 可环境覆盖，便于离线 mock 测试
DATA_DIR="${DATA_DIR:-/var/lib/mihomo}"
OUT="$DATA_DIR/config.yaml"

"$MKDIR_BIN" -p "$DATA_DIR"
[ -f "$MIHOMO_TEMPLATE" ] || die "模板不存在: $MIHOMO_TEMPLATE (immutable 部署, 需 blue home)"

if subs=$("$AGE_BIN" -d -i "$AGE_IDENTITY" "$SUBS_CIPHER" 2>/dev/null); then
    set -a
    eval "$subs"
    set +a
else
    log "警告: 订阅解密失败 (age exit=$?), 以空订阅启动; 密文=$SUBS_CIPHER 私钥=$AGE_IDENTITY"
fi

"$ENVSUBST_BIN" '$MIHOMO_SUB_ONE $MIHOMO_SUB_TWO' <"$MIHOMO_TEMPLATE" >"$OUT.tmp"
"$CHMOD_BIN" 600 "$OUT.tmp"
"$MV_BIN" "$OUT.tmp" "$OUT"
log "配置已渲染: $OUT (sub1=$([ -n "${MIHOMO_SUB_ONE:-}" ] && echo 已注入 || echo 空), sub2=$([ -n "${MIHOMO_SUB_TWO:-}" ] && echo 已注入 || echo 空))"

exec "$MIHOMO_BIN" -d "$DATA_DIR" -f "$OUT"
#+end_src

**** NM dispatcher 脚本
WiFi 连上可信 profile 时把发起连接的无线接口加入 nftables 中的 =trusted_ifaces= 集合，断开或不可信时移除；
tangle 到 =tmp/= 后由 [[#main-skeleton][服务装配]] 注入 =@VAR@= 占位符，利用 activation 拷贝到 =/etc/NetworkManager/dispatcher.d/= 。

#+NAME: nm-dispatcher-trusted-connection
#+begin_src sh :tangle ../tmp/nm-dispatcher-trusted-connection
#!/bin/sh

AGE_BIN="@AGE_BIN@"
AGE_IDENTITY="@AGE_IDENTITY@"
GREP_BIN="@GREP_BIN@"
NFT_BIN="@NFT_BIN@"
TRUSTED_CONNECTIONS_CIPHER="@TRUSTED_CONNECTIONS_CIPHER@"
IFACE="$1"
ACTION="$2"
CONNECTION_ID="${CONNECTION_ID:-}"

# 只处理无线接口：有线/虚拟接口的 up/down 不进可信集合
[ -d "/sys/class/net/$IFACE/wireless" ] || exit 0

# 输出由 NetworkManager 收进自身日志（syslog → /var/log/messages）
log() { echo "trusted-ssid: $*" >&2; }

is_trusted_connection() {
    if [ ! -r "$AGE_IDENTITY" ]; then
        log "私钥不可读: $AGE_IDENTITY, 按不可信处理"
        return 1
    fi
    "$AGE_BIN" -d -i "$AGE_IDENTITY" "$TRUSTED_CONNECTIONS_CIPHER" 2>/dev/null |
        "$GREP_BIN" -Fqx -- "$1"
}

remove_wifi_from_trusted_set() {
    "$NFT_BIN" delete element inet filter trusted_ifaces { "$IFACE" } 2>/dev/null || true
}

add_wifi_to_trusted_set() {
    remove_wifi_from_trusted_set
    "$NFT_BIN" add element inet filter trusted_ifaces { "$IFACE" }
}

log "action=$ACTION iface=$IFACE conn='${CONNECTION_ID:-}'"

case "$ACTION" in
    up)
        if [ -z "$CONNECTION_ID" ]; then
            remove_wifi_from_trusted_set
            log "CONNECTION_ID 为空, 无法比对可信名单, 按不可信处理"
        elif is_trusted_connection "$CONNECTION_ID"; then
            if add_wifi_to_trusted_set; then
                log "可信连接 '$CONNECTION_ID': $IFACE 已加入 trusted_ifaces"
            else
                log "nft 添加失败 (exit=$?), trusted_ifaces 可能未更新"
            fi
        else
            remove_wifi_from_trusted_set
            log "不在可信名单: $IFACE 已确保移出 trusted_ifaces"
        fi
        ;;
    down)
        remove_wifi_from_trusted_set
        log "断开: $IFACE 已移出 trusted_ifaces"
        ;;
esac
#+end_src

**** nftables 规则集
开机整体加载一次，dispatcher 只动 =trusted_ifaces= ；DHCP/ICMP 始终放行，保证不可信状态也能引导联网。本块 tangle 到 =tmp/nftables.conf= ，在「网络相关配置 → 服务装配」里以 =(local-file "./nftables.conf")= 引入。

#+NAME: nftables-conf
#+begin_src conf :tangle ../tmp/nftables.conf
flush ruleset

table inet filter {
# The dispatcher temporarily adds the WiFi interface for trusted connection profiles.
set trusted_ifaces {
type ifname
elements = { "virbr0", "tailscale0" }
}

chain input {
type filter hook input priority filter; policy drop;

ct state { established, related } accept
iifname "lo" accept

udp sport 67 udp dport 68 accept
udp sport 547 udp dport 546 accept
ip protocol icmp icmp type {
destination-unreachable,
time-exceeded,
parameter-problem
} accept
ip6 nexthdr ipv6-icmp accept

# VMs and trusted WiFi may access local services.
iifname @trusted_ifaces accept

# Tailscale WireGuard direct endpoint.
udp dport 41641 accept

reject with icmpx type port-unreachable
}

chain forward {
type filter hook forward priority filter; policy drop;

iifname @trusted_ifaces accept
oifname @trusted_ifaces ct state { established, related } accept
}

chain output {
type filter hook output priority 0; policy accept;
}
}

table inet nat {
chain postrouting {
type nat hook postrouting priority srcnat; policy accept;

# Do not masquerade multicast/broadcast traffic from VMs.
iifname "virbr0" ip daddr { 224.0.0.0/4, 255.255.255.255/32 } return
iifname "virbr0" oifname != "virbr0" masquerade
}
}
#+end_src

**** AC 电源状态联动
插电时切换至高性能模式（PPD performance + 关闭 WiFi 省电 + 提升 CPU 最低主频 + 启用 ASPM 性能策略）；拔电时切换至节能策略。开机由 =ac-power-init= 初始化检测。

=ac-power-init= 读 =/sys/class/power_supply/ADP1/online= 判断是否接电：=read= 是 Scheme 读取器，把文件里的 =1= 读成数字；=false-if-exception= 兜住该 sysfs 节点在部分机器上缺失的情况（读不到按 off 处理）。它通过 =root-one-shot-service= 注册，该 helper 已内置「一次性执行」与「停止回调默认返回 #f（即已停止）」的语义，所以不必再传 =#:stop= 或 =#:respawn?= 。

本小节用到四种「文件类」构造器，分工如下：

| 构造器            | 作用                             |
|-------------------+----------------------------------|
| =plain-file=      | 纯文本内容的文件                 |
| =mixed-text-file= | 由字符串与包路径拼出的文本文件   |
| =program-file=    | 可执行的 Scheme 脚本             |
| =file->udev-rule= | 把规则文本包装成 udev 规则对象   |

=udev-rules-service= 只接受规则对象（或自带规则的包），所以 =mixed-text-file= 的产物还要经 =file->udev-rule= 包一层；=(plain-file "empty" "")= 则是「需要一个 file-like、但内容用不上」时的空占位（ =screen-locker-configuration= 的 =program= 字段在 =using-setuid? #f= 下不会被使用）。

#+NAME: ac-power-services
#+begin_src scheme
(let* ([ppdctl (file-append power-profiles-daemon
                            "/bin/powerprofilesctl")]
       [iw-bin (file-append iw "/sbin/iw")]

       [ac-power-script
        (program-file
         "ac-power-profile"
         #~(let ((mode (if (> (length (command-line)) 1)
                           (cadr (command-line))
                           ""))
                 (ppdctl #$ppdctl)
                 (iw-bin #$iw-bin))
             (define (set-sys path val)
               (false-if-exception
                (call-with-output-file path
                  (lambda (port) (display val port)))))
             ;; 无线接口名运行时探测（/sys/class/net/*/wireless），不写死
             ;; 仅用 Guile 核心绑定，不新增模块依赖
             (define (wireless-interfaces)
               (let ([dir (false-if-exception (opendir "/sys/class/net"))])
                 (if (not dir)
                     '()
                     (let loop ([acc '()])
                       (let ([entry (readdir dir)])

**** root 服务与定时任务
包含系统常驻守护与定时任务：
- =smartd= ：S.M.A.R.T. 磁盘健康监控，每日 02:00 短自检、每周六 03:00 长自检（磁盘休眠时跳过）。
- =beesd= ：btrfs 去重守护，hash 表 128M、按负载 5.0 节流。首次运行需全量扫描，IO 开销较大属正常。启动经 =beesd-run= 包装：补 =/dev/disk/by-uuid= 软链（dm 设备无 by-uuid）并注入 =blkid= 的 PATH。
- 每周日 18:00 执行 =guix gc= 清理 30 天前的旧世代（保留至少 20G 空间）。
- 每周六 18:00 在外接电源状态下执行 =flatpak update --system= 。
- 每周日 19:00 执行 =fstrim -av= 进行全盘 TRIM 兜底。

beesd 与 smartd 的配置文件拆为独立块（ =bees.conf= 必须含 =UUID= 行——beesd 不按文件名找配置，靠 grep 定位）；两块的 tangle 目标是 =tmp/bees.conf= 与 =tmp/smartd.conf= ，在 =root-services= 里分别以 =./bees.conf= 、=./smartd.conf= 回引。

=beesd-run= 是 =program-file= 生成的脚本（生成不等于执行：它只是放进 command 列表，由 shepherd 启动时执行）。脚本的运行环境默认不含 Guile 模块，=with-imported-modules= 声明它可用 =(guix build utils)=（ =mkdir-p= 来自这里）；=#~= 是构建期模板，=#$xxx= 在构建时替换成具体值（此处为包路径）；脚本最后用 =execl= 让 =beesd= 直接替换当前 Guile 进程；=setenv PATH= 指向 util-linux 是为了让脚本能调用 =blkid= 。

=2f6b6499-2a27-4583-847f-dd70b9fcb036= 这个 UUID 同时出现在 =bees.conf= 块（tangle → =tmp/bees.conf= ）与 etc 条目路径 =bees/<uuid>.conf= 中，改 UUID 时两处必须同步；=beesd-run= 脚本里也有一份 =uuid= 绑定，但它只在脚本自身的作用域里可见。

=etc-service-type= 的条目形如 ~`("路径" ,文件对象)~：反引号点对中路径是字面量、=,= 后面的文件对象在求值时展开——这是 Guix =etc= 条目与各类配置扩展共用的写法。

*** Fish 服务
=10-source.fish= 由 *rosenthal* 频道的 =computed-substitution-with-inputs= 生成：模板文本（ =<<fish-cfg>>= ）里的 =$$bin/程序名$$= 不是 shell 语法，而是路径注入占位符；构建期会在 =specs->pkgs= 给出的各包目录下逐项查找 =bin/程序名= ，命中就替换为对应的 =/gnu/store/…= 绝对路径，找不到则构建失败并报 =file 'bin/程序名' not found= 。

契约要点：
+ 每个 =$$bin/X$$= 都必须在同处 =specs->pkgs= 列表里登记提供它的包，漏登记会在构建期报错；列表里多写包无害（多出的包只是不被引用）。
+ =specs->pkgs= 是 rosenthal 提供的变参版 =(map specification->package …)= ，直接写包名字符串，返回裸包对象；它不支持 =pkg:output= 形式的规格。
+ 不能改用官方的 =specifications->packages= ：它返回 =(包 输出)= 元组列表，而占位符注入函数要求传入纯包对象（需要能 lower 成 store 目录字符串）。
+ 不需要路径注入的普通配置文件请直接放 =dotfiles/immutable/= ，不必走这条路径。

*** Kanata 键盘映射
笔记本内置键盘（AT Translated Set 2 keyboard）映射。
目标： *不插外接小键盘时，内置键盘也能给出一致的手感* 。小键盘的每一列对应标准键盘的一个行（列 4 ↔ QWERTY、列 3 ↔ ASDF、列 2 ↔ ZXCV、列 1 ↔ 底部行）
+ 这个小键盘的列首键依次是 Esc / Tab / Shift / Alt，因此修改内置键盘的 base 层：
  - QWERTY 行首（物理 Tab）→ Esc
  - ASDF 行首（物理 CapsLock）→ Tab（CapsLock 功能在 fn 层收回）
  - 底部行前两个（物理 Ctrl / Alt）互换

右 Alt 按住时激活 fn 层，复刻小键盘驱动定制后的 Fn 层：
  Q W E R T Y U I O P → 1 2 3 4 5 6 7 8 9 0      列 4 的 Fn 层是整条数字行
  A S D F G          → F1 F2 F3 F4 F5            列 3 的 Fn 层接管 F1-F5
  H J K L            → [ ] ; '                   列 2 的 Fn 层接管符号区域
  Z X C V B N M      → F6 F7 F8 F9 F10 F11 F12   列 2 的 Fn 层接管 F6-F12

原本的 Tab（即小键盘的 Esc 键位）→ `
Enter / Backspace  → \ / -

**** usb-power-watch 脚本
熄屏断电守护，挂在物理 USB 口上的设备无论是什么都一律挂起，清单外的端口不碰，清单内的端口熄屏写 auto、亮屏写 on 。

#+NAME: usb-power-watch
#+begin_src sh :tangle ../tmp/usb-power-watch
#!/bin/sh

INTERVAL=30
THRESHOLD=120

PORTS="3-2 3-5 3-6 4-5 4-6"
in_ports() {
    for p in $PORTS; do
        case "$1" in "$p"|"$p."*) return 0 ;; esac
    done
    return 1
}

set_ports() {
    for dev in /sys/bus/usb/devices/*-*; do
        case "${dev##*/}" in *:*) continue ;; esac   # 跳过接口目录
        [ -f "$dev/power/control" ] || continue
        if in_ports "${dev##*/}"; then
            echo "$1" > "$dev/power/control" 2>/dev/null
        fi
    done
}

off_since=0
state=on
while :; do
    lit=0; dark=0
    for b in /sys/class/backlight/*/bl_power; do
        [ -r "$b" ] || continue
        if [ "$(cat "$b" 2>/dev/null)" = 0 ]; then lit=1; else dark=1; fi
    done
    if [ "$lit" = 0 ] && [ "$dark" = 1 ]; then
        now=$(date +%s)
        [ "$off_since" = 0 ] && off_since=$now
        if [ $((now - off_since)) -ge $THRESHOLD ]; then
            set_ports auto; state=off
        fi
    else
        off_since=0
        if [ "$state" != on ]; then set_ports on; state=on; fi
    fi
    sleep $INTERVAL
done
#+end_src

+ 每周日 19:30 清理 Nix 用户 profiles 中 14 天前的旧 generation 并回收 store（在 18:00 的 guix-gc 之后错峰执行）。

* Live ISO
:PROPERTIES:
:CUSTOM_ID: iso
:END:

自建 Live 安装镜像的 =operating-system= 声明，与主机 =%system= 独立。定位是**救砖 + 装机**双用途救援盘。
- 构建命令：执行 =blue build-iso= 进行 tangle 并调用 =tools/build-image.scm= 生成 ISO 镜像文件。
- 变体： =desktop= （XFCE + labwc，greetd 免密自动登录 live 用户，登出后自动回桌面）与 =minimal= （保留 tty1 TUI 安装器，tty3-6 root 免密 shell），分别 tangle 到 =tmp/live-iso-desktop.scm= / =tmp/live-iso-minimal.scm= 。
- 救砖装机载荷： =rescue-chroot.sh= / =emergency-blue.sh= 经 =live-rescue-tools= 包装进系统 PATH；本仓库快照（剔除 =.git= / =dist= / =tmp= ）放进各用户 =~/Guix-configs= ，配合内嵌的 =emacs-minimal= 让 =emergency-blue.sh init= 开箱可跑。
- 自包含设计：ISO 镜像专用的模块引用（ =use-modules= ）直接内联在本块中；唯一的跨区共享是 =<<guix-substitutes>>= 服务（定义于 System 区「Guix 下载源」小节），宿主与 ISO 有意共用同一组 substitute 源。
- 精简频道（guix+nonguix）写进 Live 的 =/etc/guix/channels.scm= ；sshd 随系统启动，root 与 live 密码均为 =live= （救援盘场景可接受）； =modprobe.blacklist=radeon,amdgpu= 已删——黑名单会让 AMD 显卡失去 KMS，Wayland 桌面直接起不来。
- 网络栈：desktop 变体删掉安装器基底默认的 connman，统一走 =xfce-desktop-service-type= 自带的 NetworkManager + nm-applet（ =nmtui= 亦可）；minimal 变体保留 connman（TUI 安装器的网络步骤依赖它）。

;; 仓库快照过滤：剔除 .git / dist / tmp（dist 里有旧 ISO，绝不能进镜像）。
(define (%live-repo-select? file stat)
  (define (excluded? name)
    (or (string-suffix? (string-append "/" name) file)
        (string-contains file (string-append "/" name "/"))))
  (not (or (excluded? ".git") (excluded? "dist") (excluded? "tmp"))))

;; live 与 root 都用 fish（骨架里带 fish 配置与速查 greeting）；
;; 密码都是 live——救援盘需要确定性的 sudo/ssh 口令。
(define %live-users
  (cons* (user-account
          (name "live")
          (group "users")
          (password (crypt "live" "$6$abc"))
          (supplementary-groups '("wheel" "audio" "video" "netdev"))
          (shell (file-append fish "/bin/fish")))
         (user-account
          (inherit %root-account)
          (password (crypt "live" "$6$abc"))
          (shell (file-append fish "/bin/fish")))
         %base-user-accounts))

;; 骨架 = livecd dotfiles + 仓库快照（~/Guix-configs）。
