*** 服务构造函数

以下三个辅助函数封装 Shepherd 服务的常见构造形态。 =command= 参数接收可执行程序与参数的列表，列表元素支持普通字符串与 Guix 可 lower 对象（构建期自动展开为 =/gnu/store/……= 下的真实路径）：

- *普通字符串* :: 如 ~"/bin/sh"~ 、 ~"--bind-dynamic"~ ，按原样拼入命令行。
- *包内路径与本地文件* :: 如 ~(file-append kdeconnect "/bin/kdeconnect-indicator")~ 或 ~(local-file "clipsync.scm")~ ，构建时解析为对应 store 路径。
- *G-expression（gexp，构建期模板）* ::
  - ~define*~ 与 ~#:key~ ：定义带可选关键字参数的函数，未显式传入的参数取默认值。
  - =#~(……)= ：声明构建期模板，内部代码延后至构建或服务运行期求值。
  - ~#$expr~ 与 ~#$@lst~ ：在模板内插入外部值（包或文件对象在此展开为绝对路径）； ~#$@~ 将列表元素逐个摊平拼接到当前位置。
- =home-daemon-service= :: 构造用户态常驻守护进程，继承启动时的用户环境变量，并将日志写入 =$XDG_STATE_HOME/shepherd/<name>.log= 。

#+NAME: home-daemon-service-helpers
#+begin_src scheme
(define* (home-daemon-service name command
                              #:key (requirement '())
                              (auto-start? #t) (respawn? #t)
                              (environment-variables #~(environ))
                              (log-file #f)
                              (documentation "[No documentation.]"))
  (shepherd-service
   (provision (list name))
   (requirement requirement)
   (documentation documentation)
   (start #~(make-forkexec-constructor
             (list #$@command)
             #:environment-variables #$environment-variables
             #:log-file #$(if log-file
                              log-file
                              #~(string-append (getenv "XDG_STATE_HOME")
                                               "/shepherd/" #$(symbol->string name)
                                               ".log"))))
   (stop #~(make-kill-destructor))
   (auto-start? auto-start?)
   (respawn? respawn?)))
#+end_src

- =root-daemon-service= :: 构造系统级常驻守护进程，支持通过 ~#:log-file~ 指定日志路径，或通过 ~#:one-shot?~ 切换为单次任务。

#+NAME: root-daemon-service-helpers
#+begin_src scheme
(define* (root-daemon-service name command
                              #:key (requirement '())
                              (auto-start? #t) (respawn? #t)
                              one-shot? log-file
                              (documentation "[No documentation.]"))
  (simple-service name shepherd-root-service-type
                  (list (shepherd-service
                         (provision (list name))
                         (requirement requirement)
                         (documentation documentation)
                         (one-shot? one-shot?)
                         (auto-start? auto-start?)
                         (respawn? respawn?)
                         (start #~(make-forkexec-constructor
                                   (list #$@command)
                                   #:log-file #$log-file))
                         (stop #~(make-kill-destructor))))))
#+end_src

- =root-one-shot-service= :: 构造开机仅执行一次的系统初始化任务（ ~one-shot? #t~ ）， ~start~ 直接传入 gexp 过程。

#+begin_quote
*Shepherd 单次服务的两个细节* ：
1. ~stop~ 默认设为 =#~(const #f)= （向 Shepherd 表示「已停止」），对 one-shot 服务而言 ~stop~ 与 ~respawn?~ 均为惰性，调用处无需重复传参。
2. Shepherd 会把 ~start~ 的 gexp 单独序列化并编译为 =.go= 字节码，编译期仅可见 ~#:modules~ 声明的模块（默认为 ~%default-modules~ ）。 *写在 gexp 内部的 ~(use-modules ...)~ 不会参与编译期绑定* ，若用到额外模块（如提供 ~read-line~ 的 ~(ice-9 rdelim)~ ），必须通过 ~#:modules~ 显式追加。
#+end_quote

#+NAME: root-one-shot-service-helpers
#+begin_src scheme

(define* (root-one-shot-service name requirement start
                                #:key (stop #~(const #f))
                                (respawn? #t)
                                (modules %default-modules)
                                (documentation "[No documentation.]"))
  (simple-service name shepherd-root-service-type
                  (list (shepherd-service
                         (provision (list name))
                         (requirement requirement)
                         (documentation documentation)
                         (one-shot? #t)
                         (auto-start? #t)
                         (respawn? respawn?)
                         (modules modules)
                         (start start)
                         (stop stop)))))
#+end_src

* 系统配置

系统层遵循 *最小化原则* ，仅承载底层引导、内核与硬件基础设施；桌面应用与个人开发工具统一交由 [[#home-packages][用户配置（Home 层）]] 管理。

** Bootloader
:PROPERTIES:
:CUSTOM_ID: sys-bootloader
:END:

采用 =rosenthal= 频道提供的 =Limine= 引导方案：构建时通过 =systemd-stub= 将内核与 initrd 打包为可直接由 UEFI 固件拉起的 UKI（Unified Kernel Image）， =Limine= 仅负责展示世代菜单。相比传统 GRUB 在引导阶段用软件解密 LUKS，该方案把解密交给内核 initrd，大幅缩短了全盘加密环境下的冷启动耗时。

#+NAME: bootloader-configs
#+begin_src scheme
(bootloader (bootloader-configuration
             (bootloader limine-efi-removable-bootloader)
             (targets '("/efi"))))
#+end_src

** FileSystems
:PROPERTIES:
:CUSTOM_ID: sys-filesystems
:END:

存储架构采用 *Tmpfs on Root* （无状态内存根）配合 *LUKS 全盘加密 + Btrfs 子卷* ：根目录 =/= 每次关机自动清空，只有显式声明的系统子卷与用户目录才会落盘保存。所有磁盘 UUID、卷标与子卷映射表均集中定义在 [[./information.scm][source/information.scm]] 中（救援脚本 =tools/rescue-chroot.sh= 同样直接解析该文件）。

最终传给系统的 =%file-systems-config= 由以下六组挂载按序拼接而成：

| 挂载分组                               | 数据来源与作用                                                                                     |
|----------------------------------------+----------------------------------------------------------------------------------------------------|
| =%bind-mounts=                         | 遍历 =%data-dirs= 清单，将持久化分区下的 =/data/<目录>= 逐一 =bind-mount= 到 =$HOME/<目录>=        |
| =%persist-filesystem=                  | 用 ~match-lambda~ 解构 =%btrfs-subvolumes= 的 ~(子卷 挂载点)~ 二元组，批量生成 18 条系统级子卷挂载 |
| =%tmpfs=                               | 承载根目录 =/= （10% 内存上限）与 =/var/lock= 的内存文件系统                                       |
| =%data-filesystem= / =%efi-filesystem= | 挂载用户数据主子卷 =/data= 与 EFI 引导分区 =/efi=                                                  |
| =%base-file-systems=                   | Guix 内置基础挂载（ =/dev/pts= 、 =/dev/shm= 、 =efivars= 及只读的 =/gnu/store= 等）               |
| =%v1-freezer-filesystem=               | 挂载 cgroup v1 的 =freezer= 层级至 =/sys/fs/cgroup/freezer= ，供 Waydroid 容器休眠冻结使用         |

- *子卷挂载的两处特判* :: 在 =%persist-filesystem= 的 18 条记录中，仅 =/tmp= 将 ~needed-for-boot?~ 设为 ~#f~ （无需在 initrd 阶段挂载，开机后由 =cleanup-/tmp= 服务清理），且仅 =/gnu= 将 ~check?~ 设为 ~#t~ （挂载前执行文件系统自检）。
- *Waydroid 容器冻结兼容* :: Waydroid 在熄屏挂起容器时依赖 cgroup v1 的 =freezer= 层级。LXC 读取 =/proc/1/cgroup= 枚举到 =elogind= 的 v1 挂载后，会将整个 cgroup 布局判定为 =HYBRID= ，此时 ~lxc_cmd_freeze_callback~ 会拒绝执行冻结操作。因此必须显式挂载 =/sys/fs/cgroup/freezer= ，让 LXC 走 legacy 路径写入 =freezer.state= 。
- *休眠与独立 Swap* :: 由于 Guile initrd 暂不支持从加密 swap 恢复休眠镜像，此处使用未加密的独立 swap 分区（ =%swap-devices= ），配合内核参数 ~resume=UUID= ……~ 与下文的 =resume-device= 服务实现休眠唤醒。

**** 回收站放行（utab 注入）

由于用户目录全部通过 Btrfs 子卷或 =bind-mount= 挂载，GLib（GVfs、Thunar 等 GUI 组件）默认会将此类挂载判定为「系统内部挂载（ =system internal= ）」并拒绝移入回收站。解除该限制需要用户态挂载选项 =x-gvfs-trash= ，但内核 ~mount(2)~ 并不认识该选项，而 Guix 挂载文件系统时直接走系统调用、不经过 ~mount(8)~ 写入 =/run/mount/utab= 。本服务在开机挂载完成后补齐这张表：

- *mountinfo 解析与过滤* :: =/proc/self/mountinfo= 每行格式为 =ID 父 ID 主:次 root 挂载点 挂载选项 [可选字段……] - fstype 源 超级选项= 。按空格分词后，下标 =0= 为 =ID= 、 =3= 为 =root= 、 =4= 为挂载点，源设备位于独立分隔符 ~"-"~ 之后的第 2 个字段。脚本仅筛选 ~root != "/"~ （即子卷或 bind 挂载）且目标路径位于 =/data= 或 =$HOME= 下的记录，系统子卷（如 =/gnu= 、 =/var/lib= ）保持拒绝回收站。
- *生成 utab 记录与模块导入* :: 按 =libmount= 规范向 =/run/mount/utab= 写入 ~ID=~ 、 ~SRC=~ 、 ~TARGET=~ 、 ~ROOT=~ 与 ~OPTS=x-gvfs-trash~ 字段，权限设为 =0644= 。所用 ~read-line~ 来自 ~(ice-9 rdelim)~ ，必须经 ~#:modules~ 注入 Shepherd 服务的顶层编译环境（gexp 内层的 ~use-modules~ 不参与 =.go= 编译期绑定）。

#+NAME: trash-utab-services
#+begin_src scheme
(list (root-one-shot-service
       'trash-utab '(file-systems)
       (with-imported-modules (source-module-closure '((guix build utils)))
                              #~(lambda ()
                                  (let ([home-prefix (string-append "/home/" #$username)]
                                        [entries '()])
                                    (define (source-of fields)
                                      (let loop ([fs (cdr fields)] [idx 1])
                                        (cond [(null? fs) #f]
                                              [(string=? (car fs) "-")
                                               (and (>= (length fields) (+ idx 3))
                                                    (list-ref fields (+ idx 2)))]
                                              [else (loop (cdr fs) (1+ idx))])))
                                    (call-with-input-file "/proc/self/mountinfo"
                                      (lambda (port)
                                        (let loop ()
                                          (let ([line (read-line port)])
                                            (unless (eof-object? line)
                                              (let ([fields (string-tokenize line)])
                                                (when (>= (length fields) 10)
                                                  (let ([id (list-ref fields 0)]
                                                        [root (list-ref fields 3)]

                                                            (cons (string-append
                                                                   "ID=" id " SRC=" source
                                                                   " TARGET=" target
                                                                   " ROOT=" root
                                                                   " OPTS=x-gvfs-trash")
                                                                  entries))))))
                                              (loop))))))
                                    (mkdir-p "/run/mount")
                                    (call-with-output-file "/run/mount/utab"
                                      (lambda (port)
                                        (for-each (lambda (entry)
                                                    (display entry port)
                                                    (newline port))
                                                  (reverse entries))))
                                    (chmod "/run/mount/utab" #o644)
                                    #t)))

*** 网络相关配置

网络栈围绕 *nftables 接口信任模型* 与 *Age 机密动态注入* 构建：

- *防火墙模型* :: =nftables= 规则集在开机时一次性全局加载，入站流量默认丢弃（ ~policy drop~ ）；虚拟网桥 =virbr0= 与 =tailscale0= 默认位于 =trusted_ifaces= 白名单集合中，而无线网卡仅在连上可信 WiFi Profile（存于加密文件 =wifi-trust.age= ）时由 NetworkManager dispatcher 动态加入该集合。

**** mihomo 启动包装

=mihomo= 的配置模板由不可变层 dotfiles 部署至 =~/.config/mihomo/config.yaml= ，其中订阅链接以 =$MIHOMO_SUB_ONE= / =$MIHOMO_SUB_TWO= 环境变量占位。本启动包装脚本负责在运行期补齐真实订阅并拉起守护进程：

- *渲染与启动流* :: 解密 =mihomo-subscriptions.age= 密文并导出环境变量 → 调用 =envsubst= 将订阅注入 =/var/lib/mihomo/config.yaml= （权限收敛为 =0600= ， =DATA_DIR= 可由同名环境变量覆盖以便离线 mock 测试）→ ~exec~ 启动 =mihomo= 。
- *降级容错设计* :: 脚本不启用 ~set -e~ ：除了配置模板本身缺失会以退出码 1 终止外，若私钥缺失或解密失败，脚本会降级为空订阅启动（保证基础直连网络可用），避免触发 Shepherd 无限重启。
- *更换订阅命令* :: 执行 ~secrets set mihomo-subscriptions MIHOMO_SUB_ONE "<url>"~ （或 ~secrets edit~ ）后，运行 ~sudo herd restart mihomo-daemon~ 即可生效。

#+NAME: mihomo-run

**** NM dispatcher 脚本

当无线网卡连接状态变化时，NetworkManager 会以 root 身份调用 =/etc/NetworkManager/dispatcher.d/10-trusted-ssid= ，并通过参数传入 =<接口名> <action>= 、通过环境变量传入 =CONNECTION_ID= （NM Profile 名称）：

- *动态集合切换* :: 仅处理无线接口（存在 =/sys/class/net/$IFACE/wireless= ，有线与虚拟接口直接退出）。在 ~up~ 事件下，脚本在内存管道中解密 =wifi-trust.age= 并精确匹配 =CONNECTION_ID= ，命中则将无线接口加入 nftables 的 =trusted_ifaces= 集合；未命中或触发 ~down~ 事件时立即从集合中移除。
- *安全降级与日志* :: 私钥或密文不可读时一律按「不可信网络」处理（移出集合），不阻断正常联网；运行日志输出至 stderr，可按 =trusted-ssid:= 前缀在 =/var/log/messages= 中检索。

#+NAME: nm-dispatcher-trusted-connection
#+CAPTION: NM dispatcher：按加密的可信名单把无线接口加进/移出 nftables trusted_ifaces
#+begin_src sh :tangle ../tmp/nm-dispatcher-trusted-connection
#!/bin/sh

AGE_BIN="@AGE_BIN@"
AGE_IDENTITY="@AGE_IDENTITY@"
GREP_BIN="@GREP_BIN@"
NFT_BIN="@NFT_BIN@"
TRUSTED_CONNECTIONS_CIPHER="@TRUSTED_CONNECTIONS_CIPHER@"
IFACE="$1"
ACTION="$2"
CONNECTION_ID="${CONNECTION_ID:-}"

[ -d "/sys/class/net/$IFACE/wireless" ] || exit 0

log() { echo "trusted-ssid: $*" >&2; }

is_trusted_connection() {
    if [ ! -r "$AGE_IDENTITY" ]; then
        log "私钥不可读: $AGE_IDENTITY, 按不可信处理"
        return 1
    fi
    "$AGE_BIN" -d -i "$AGE_IDENTITY" "$TRUSTED_CONNECTIONS_CIPHER" 2>/dev/null |
        "$GREP_BIN" -Fqx -- "$1"
}

remove_wifi_from_trusted_set() {
    "$NFT_BIN" delete element inet filter trusted_ifaces { "$IFACE" } 2>/dev/null || true
}

add_wifi_to_trusted_set() {
    remove_wifi_from_trusted_set
    "$NFT_BIN" add element inet filter trusted_ifaces { "$IFACE" }
}

log "action=$ACTION iface=$IFACE conn='${CONNECTION_ID:-}'"

case "$ACTION" in
    up)
        if [ -z "$CONNECTION_ID" ]; then
            remove_wifi_from_trusted_set
            log "CONNECTION_ID 为空, 无法比对可信名单, 按不可信处理"
        elif is_trusted_connection "$CONNECTION_ID"; then
            if add_wifi_to_trusted_set; then
                log "可信连接 '$CONNECTION_ID': $IFACE 已加入 trusted_ifaces"
            else
                log "nft 添加失败 (exit=$?), trusted_ifaces 可能未更新"
            fi
        else
            remove_wifi_from_trusted_set
            log "不在可信名单: $IFACE 已确保移出 trusted_ifaces"
        fi
        ;;
    down)
        remove_wifi_from_trusted_set
        log "断开: $IFACE 已移出 trusted_ifaces"
        ;;
esac
#+end_src

**** nftables 规则集

防火墙基础规则集在开机时整体加载一次，运行期仅由上方 dispatcher 脚本原子增删 =trusted_ifaces= 集合成员（不在运行期执行 ~flush ruleset~ ）：

- *入站与转发控制* :: 默认丢弃所有未匹配入站包，放行已建立连接、本地回环、DHCP/ICMP 基础协议以及 Tailscale WireGuard 直连端口（UDP =41641= ），不可信网络下也能获取地址与打洞。
- *虚拟机 NAT* :: 为 =virbr0= 网桥配置出站 masquerade 伪装（排除 =224.0.0.0/4= 组播与 =255.255.255.255/32= 广播地址），供 Libvirt 虚拟机访问外网。
- *Waydroid 网桥* :: =waydroid0= 与 =virbr0= 同属本地容器/虚拟机网桥，一并列入 =trusted_ifaces= 集合；否则容器内 Android 向网关发的 DHCP/DNS 请求会被 =input= 链丢弃，出向流量也会被 =forward= 链丢弃。

#+NAME: nftables-conf
#+begin_src conf :tangle ../tmp/nftables.conf
flush ruleset

table inet filter {
set trusted_ifaces {
type ifname
elements = { "virbr0", "tailscale0", "waydroid0" }
}

chain input {
type filter hook input priority filter; policy drop;

ct state { established, related } accept
iifname "lo" accept

udp sport 67 udp dport 68 accept
udp sport 547 udp dport 546 accept
ip protocol icmp icmp type {
destination-unreachable,
time-exceeded,
parameter-problem
} accept
ip6 nexthdr ipv6-icmp accept

iifname @trusted_ifaces accept

udp dport 41641 accept

reject with icmpx type port-unreachable
}

chain forward {
type filter hook forward priority filter; policy drop;

iifname @trusted_ifaces accept
oifname @trusted_ifaces ct state { established, related } accept
}

chain output {
type filter hook output priority 0; policy accept;
}
}

table inet nat {
chain postrouting {
type nat hook postrouting priority srcnat; policy accept;

iifname "virbr0" ip daddr { 224.0.0.0/4, 255.255.255.255/32 } return
iifname "virbr0" oifname != "virbr0" masquerade
}
}
#+end_src

**** USB autosuspend 策略

采用内核原生 USB runtime PM：设备无流量满 600 秒自动挂起（功耗降至 µA 级），有输入或流量时即时唤醒。相比监听熄屏信号，该方案在熄屏播放或下载时不会误断外设，也无需常驻轮询进程。白名单按 =VID:PID= 持久放行（ =control=on= ），命中即通过 =GOTO="usb_pm_end"= 跳过全局规则（查 =/sys/bus/usb/devices/*/= 下的 =idVendor= / =idProduct= 获取设备标识）。代码中用 ~string-append~ 逐行拼接而非反斜杠续行，避免 Noweb 展开时的缩进把前导空格混入生成的 udev 规则：

#+NAME: usb-power-services
#+begin_src scheme
(list (udev-rules-service
       'usb-autosuspend
       (file->udev-rule
        "96-usb-autosuspend.rules"
        (plain-file "96-usb-autosuspend.rules"
                    (string-append
                     "# USB runtime PM：空闲 600s 挂起、有活动即时唤醒（内核 autosuspend），\n"
                     "# 替代已退役的 usb-power-watch 熄屏守护。白名单按 VID:PID 持久放行，\n"
                     "# 命中即 GOTO 跳过全局规则；某设备唤醒体验差时仿照注释行添加。\n"
                     "#ACTION==\"add\", SUBSYSTEM==\"usb\", ATTR{idVendor}==\"28e9\", ATTR{idProduct}==\"31ff\", ATTR{power/control}=\"on\", GOTO=\"usb_pm_end\"\n"
                     "ACTION==\"add\", SUBSYSTEM==\"usb\", TEST==\"power/control\", ATTR{power/control}=\"auto\", ATTR{power/autosuspend}=\"600\"\n"
                     "LABEL=\"usb_pm_end\"\n")))))
#+end_src

*** Kanata 键盘映射

针对笔记本内置键盘（ =AT Translated Set 2 keyboard= ）定制键位重映射，使未接入外接客制化小键盘时仍保持一致的键位布局与层切换行为。

外接小键盘为 4 行布局，各行依次对应标准键盘的 =QWERTY= / =ASDF= / =ZXCV= / 底部修饰行；行首键自上而下为 MT 键（短按 =Tab= 、按住 ≥150 ms 为 =Esc= ）与 =Ctrl= / =Shift= ，底行 =Ctrl-Win-Alt= 与标准键盘一致。据此将内置键盘映射为两层：

- *Base 基础层改动* ：
  - =QWERTY= 行首（物理 =Tab= 键）→ 复刻小键盘 MT 键：短按 =Tab= ，按住 ≥150 ms 为 =Esc= （ ~tap-hold~ ，别名为 =@tabesc= ）
  - =ASDF= 行首（物理 =CapsLock= 键）→ 映射为左 =Ctrl= ，对齐小键盘 =A= 前的 =Ctrl= （原 =CapsLock= 下沉至 =fn= 层）
  - 底部修饰行 → 全部透传（小键盘底行 =Ctrl-Win-Alt= 已与标准键盘一致； =Left Ctrl= 与 =Left Alt= 的互换只在 Fn 层复刻，见下表）
  - 右侧 =Right Alt= → 按住激活 =fn= 层（ ~layer-while-held fn~ ）
- *Fn 扩展层映射（按住 =Right Alt= 触发）* ：

| 物理键区                                       | Fn 层输出                 | 对应外接小键盘设计                      |
|------------------------------------------------+---------------------------+-----------------------------------------|
| =Q W E R T Y U I O P=                          | =1 2 3 4 5 6 7 8 9 0=     | 列 4 的 Fn 层接管整排数字               |
| =A S D F G=                                    | =F1 F2 F3 F4 F5=          | 列 3 的 Fn 层左半接管 F1–5              |
| =H J K L=                                      | =[ ] ; '=                 | 列 2 的 Fn 层右半接管符号               |
| =Z X C V B N M=                                | =F6 F7 F8 F9 F10 F11 F12= | 列 2 的 Fn 层接管 F6–12                 |
| 物理 =Tab= （Base 层短按 =Tab= / 长按 =Esc= ） | =Esc=                     | 小键盘左上角键位                        |
| 物理 =CapsLock= （现 左 =Ctrl= ）              | =CapsLock=                | 在 Fn 层保留大小写锁定                  |
| =Backspace= / =Enter=                          | =-= / =\=                 | 小键盘 Backspace 位、Enter 位的 Fn 层值 |
| 物理 =L_Ctrl= / =L_Win= / =L_Alt=              | =L_Alt= / =`= / =L_Ctrl=  | 小键盘 Fn 层底行左三（Ctrl/Alt 对调）   |

**** clipsync 剪切板桥接

在 =Niri= + =xwayland-satellite= 架构下，X11 与 Wayland 的 =CLIPBOARD= 彼此隔离、不会自动互相转发，导致只走 X11 剪切板的 XWayland 应用（如 Flatpak 版 QQ、微信等）无法与 Wayland 原生应用互相复制粘贴。本守护脚本（Guile 实现，架构等价于已归档的 [[https://github.com/SHORiN-KiWATA/linuxqq-clipsync][linuxqq-clipsync]]）监听 =clipnotify= （X11 侧）与 ~wl-paste --watch echo~ （Wayland 侧，借 ~echo~ 把每次剪切板变化转为一行事件信号），调用 =xclip= 与 =wl-copy= / =wl-paste= 完成双向同步，并兼容 =cliphist= 历史记录：

- *MIME 协商与格式净化* :: =pick-x11= 返回 ~(源MIME 目标 MIME 模式)~ 三元组（无匹配返回 ~#f~ ）， =pick-wayland= 返回 ~(源MIME 模式)~ 二元组（无匹配返回 ~#f~ ）。 =sanitize-uri-list= 在写入前剔除 =copy= / =cut= 操作行，并为裸路径补齐 =file://= 前缀，保证两端格式一致。
- *共享状态与时间戳* :: 互斥锁 =%lock= 保护三个全局变量： =%last-dir= （最近同步方向 ~"X2 W"~ 或 ~"W2X"~ ）、 =%last-time= （微秒时间戳， =now-us= 同时兼容 ~gettimeofday~ 返回点对或双元素表的实现）与 =%last-norm= （最近同步内容的归一化字节串）。
- *异常退避* :: 若 =clipnotify= 在 100 ms 内退出，说明 X11 连接异常， =x11-watcher= 会每次休眠 1 秒退避重试，连续 5 次秒退则主动退出进程并交由 Shepherd 重启。

#+begin_quote
*核心不变量（修改代码前必读，均有实机验证依据）* ：
1. *防环靠归一化内容比对，而非单纯依赖时间窗* ： =norm-text= 剥除空白与 =NUL= （容忍 =xclip= 与 =wl-copy= 的尾部换行差异）， =norm-uri= 剥除 =file://= 前缀及 =copy= / =cut= 操作行后再做字节比对；内容相同即视为回声跳过，删掉内容比对会触发死循环。
2. *对向 1 秒抑制窗口推迟处理而非直接丢弃* ： =wait-out-suppression!= 将对向写入 1 秒内的事件推迟到窗口结束再处理；本机无自动转发回声，若直接跳过会把用户快速切换窗口时的真实复制吞掉。
3. *在写入目标剪切板之前调用 ~record!~ 登记状态* ：防止对向监听线程在写入中途回读大图，避开 =xclip= 在 INCR 分块传输下的并发丢包缺陷。
4. *所有读写子进程外包 ~timeout 10~* ： =clip-read= （失败、空内容或超时返回 ~#f~ ）与 =clip-write= 均通过 ~timeout 10~ 调用子进程；当源端窗口意外关闭时， =xclip= 的 INCR 传输会永久挂死，不加超时会卡死同步线程。
5. *事件触发后先经 30 ms 去抖（ ~usleep 30000~ ）再读取* ：消除剪切板所有权声明与实际数据可读之间的时间差。
#+end_quote

(define %lock (make-mutex))
(define %last-dir "")
(define %last-time 0)
(define %last-norm #f)

(define (now-us)
  (let* ([t (gettimeofday)] [rest (cdr t)])
    (+ (* (car t) 1000000) (if (pair? rest) (car rest) rest))))

(define (logline tag fmt . args)
  (format #t "[~a ~a] ~?\n"
          (strftime "%H:%M:%S" (localtime (current-time))) tag fmt args)
  (force-output))

(define (clip-read . args)
  (let* ([p (apply open-pipe* OPEN_READ "timeout" "10" args)]
         [bv (get-bytevector-all p)]
         [status (close-pipe p)])
    (and (not (eof-object? bv)) (zero? status)
         (> (bytevector-length bv) 0) bv)))

(define (clip-write bv . args)
  (catch #t
    (lambda ()
      (let ([p (apply open-pipe* OPEN_WRITE "timeout" "10" args)])
        (put-bytevector p bv)
        (force-output p)
        (zero? (close-pipe p))))
    (lambda args #f)))

(define (norm-text bv)
  (string->utf8
   (string-filter (lambda (c) (not (memv c '(#\nul #\newline #\return #\space #\tab))))
                  (utf8->string bv))))

(define (norm-uri bv)
  (define (strip-file-uri s)
    (if (string-prefix? "file://" s) (substring s 7) s))
  (let loop ([lines (string-split (utf8->string bv) #\newline)]
             [acc '()])
    (cond [(null? lines)
           (string->utf8 (apply string-append (reverse acc)))]
          [else
           (let ([t (string-trim-both (car lines))])
             (cond [(or (member t '("copy" "cut")) (string=? t ""))
                    (loop (cdr lines) acc)]
                   [else (loop (cdr lines) (cons (strip-file-uri t) acc))]))])))

(define (normalize bv mode)
  (catch #t
    (lambda ()
      (let ([r (case mode
                 [(text) (norm-text bv)]
                 [(uri) (norm-uri bv)]
                 [else bv])])
        (and (> (bytevector-length r) 0) r)))
    (lambda args #f)))

(define (sanitize-uri-list bv)
  (let loop ([lines (string-split (utf8->string bv) #\newline)]
             [acc '()])
    (if (null? lines)
        (string->utf8 (string-join (reverse acc) "\n"))
        (let ([t (string-trim-both (car lines))])
          (cond [(or (member t '("copy" "cut")) (string=? t ""))
                 (loop (cdr lines) acc)]
                [(string-prefix? "/" t)
                 (loop (cdr lines) (cons (string-append "file://" t) acc))]
                [else (loop (cdr lines) (cons t acc))])))))

(define (wait-out-suppression! opposite-dir)
  (let loop ()
    (lock-mutex %lock)
    (let ([sup (and (string=? %last-dir opposite-dir)
                    (< (- (now-us) %last-time) 1000000))])
      (unlock-mutex %lock)
      (when sup (usleep 100000) (loop)))))

(define (same-as-last? norm)
  (lock-mutex %lock)
  (let ([r (and %last-norm norm (bytevector=? %last-norm norm))])
    (unlock-mutex %lock)
    r))

(define (record! dir norm)
  (lock-mutex %lock)
  (set! %last-dir dir)
  (set! %last-time (now-us))
  (set! %last-norm norm)
  (unlock-mutex %lock))

(define (handle-x11->wayland)
  (let* ([types-bv (clip-read "xclip" "-selection" "clipboard" "-t" "TARGETS" "-o")]
         [types (and types-bv (catch #t (lambda () (utf8->string types-bv))
                                (lambda args #f)))])
    (when types
      (let ([pick (pick-x11 types)])
        (when pick
          (let* ([src (car pick)] [dst (cadr pick)] [mode (caddr pick)])
            (let ([data (clip-read "xclip" "-selection" "clipboard" "-o" "-t" src)])
              (when data
                (let ([norm (normalize data mode)])
                  (when (and norm (not (same-as-last? norm)))
                    (logline "X2W" "同步 ~a (~a 字节)" dst (bytevector-length data))
                    (let ([out (if (eq? mode 'uri) (sanitize-uri-list data) data)])
                      (record! "X2W" norm)
                      (clip-write out "wl-copy" "-t" dst))))))))))))

(define (handle-wayland->x11)
  (let* ([types-bv (clip-read "wl-paste" "--list-types")]
         [types (and types-bv (catch #t (lambda () (utf8->string types-bv))
                                (lambda args #f)))])
    (when types
      (let ([pick (pick-wayland types)])
        (when pick
          (let* ([src (car pick)] [mode (cadr pick)])
            (let ([data (clip-read "wl-paste" "-n" "-t" src)])
              (when data
                (let ([norm (normalize data mode)])
                  (when (and norm (not (same-as-last? norm)))
                    (let* ([out (if (eq? mode 'uri) (sanitize-uri-list data) data)]
                           [target (if (or (string=? src "text/plain")
                                           (string=? src "text/plain;charset=utf-8"))
                                       "UTF8_STRING" src)])
                      (logline "W2X" "同步 ~a (~a 字节)" target (bytevector-length data))
                      (record! "W2X" norm)
                      (clip-write out "xclip" "-selection" "clipboard" "-i" "-t"
                                  target))))))))))))

(define (x11-watcher)
  (logline "SYS" "X11 监视线程启动")
  (let loop ([fast-exits 0])
    (let ([t0 (now-us)])
      (system* "timeout" "3600" "clipnotify")
      (let ([elapsed (- (now-us) t0)])
        (cond [(< elapsed 100000)
               (if (>= fast-exits 4)
                   (begin (logline "ERR" "clipnotify 持续秒退，X11 事件源失效，守护退出")
                          (primitive-exit 1))
                   (begin (sleep 1) (loop (1+ fast-exits))))]
              [else
               (usleep 30000)
               (wait-out-suppression! "W2X")
               (handle-x11->wayland)
               (loop 0)])))))

(define (wayland-watcher)
  (logline "SYS" "Wayland 监视启动")
  (let ([p (open-pipe* OPEN_READ "wl-paste" "--watch" "echo")])
    (let loop ()
      (let ([line (read-line p)])
        (if (eof-object? line)
            (begin (logline "ERR" "wl-paste --watch 退出，守护退出") (primitive-exit 1))
            (begin (usleep 30000)
                   (wait-out-suppression! "X2W")
                   (handle-wayland->x11)
                   (loop)))))))

(define (main)
  (unless (and (getenv "DISPLAY") (getenv "WAYLAND_DISPLAY"))

           (getenv "DISPLAY") (getenv "WAYLAND_DISPLAY"))

  (wayland-watcher))

(main)

**** cpu-dma-latency

通过打开并持有 =/dev/cpu_dma_latency= 文件描述符、写入 32 位整数 =0= ，强制 CPU 保持在浅层 C-state 以消除核心唤醒抖动。因会增加待机功耗，默认设为不自启（ ~#:auto-start? #f~ ），在进行音游或低延迟音频工作时可通过 ~herd start cpu-dma-latency~ 按需开启、用毕 ~herd stop~ 释放。

**** kb-backup 备份脚本

每晚 22:00 自动为两处本地高频变动数据生成 Git 提交，日志追加至 =~/.cache/kb-backup.log= ：

- *两步独立容错* :: 第一步通过 =$HERMES_HOME= 下的 Stow 软链（ =config.yaml= 或 =SOUL.md= ）反推仓库根路径，仅 ~git add dotfiles/mutable/agents/hermes~ 子目录以避免误提交其他未完成改动；第二步进入 =~/Documents/Org= （本地知识库，无远端仓库）执行 ~git add -A~ 并提交。工作区无改动时静默跳过；任一步失败仅写入告警日志，脚本退出码恒为 =0= 。

#+NAME: kb-backup-script
#+CAPTION: 每日自动 commit hermes 包与 Org 知识库；两步独立容错，退出码恒 0
#+begin_src sh :tangle ../tmp/kb-backup
#!/bin/sh

PATH="$HOME/.guix-home/profile/bin:/run/current-system/profile/bin:$PATH"
log="$HOME/.cache/kb-backup.log"
mkdir -p "$(dirname "$log")"
warn() { echo "[$(date '+%Y-%m-%d %H:%M:%S')] WARN: $1" >>"$log"; }

(
    hermes_home="${HERMES_HOME:-$HOME/.local/share/hermes}"
    repo=""
    for anchor in "$hermes_home/config.yaml" "$hermes_home/SOUL.md"; do
        [ -L "$anchor" ] || continue
        target=$(readlink -f "$anchor") || continue
        repo=$(git -C "$(dirname "$target")" rev-parse --show-toplevel 2>/dev/null) || continue
        break
    done
    [ -n "$repo" ] || { echo "找不到链回仓库的 hermes 锚点文件 ($hermes_home)"; exit 1; }
    git -C "$repo" add dotfiles/mutable/agents/hermes || exit 1
    git -C "$repo" diff --cached --quiet || git -C "$repo" commit -m "chore(hermes): backup $(date)" || exit 1
) >>"$log" 2>&1 || warn "hermes 备份失败, 详见上方 git 输出"

(
    cd "$HOME/Documents/Org" || exit 1
    git add -A || exit 1
    git diff --cached --quiet || git commit -m "chore(backup): auto $(date '+%Y-%m-%d %H:%M:%S')" || exit 1
) >>"$log" 2>&1 || warn "Org 知识库备份失败, 详见上方 git 输出"
#+end_src

| 变体名称  | 输出文件                   | 适用场景与会话设计                                                                                                                                  |
|-----------+----------------------------+-----------------------------------------------------------------------------------------------------------------------------------------------------|
| =desktop= | =tmp/live-iso-desktop.scm= | 搭载 =XFCE= + =labwc= （Wayland）与 =IceCat= 浏览器， =greetd= 的初始与默认会话均指向 =%xfce-session= （登出后自动重进桌面），网络走 NetworkManager |
| =minimal= | =tmp/live-iso-minimal.scm= | 纯终端轻量救援盘： =TTY1= 保留官方 TUI 安装器（kmscon）， =TTY2= 为手册， =TTY3= – =TTY6= 为免密 root Shell，登录前 =/etc/issue= 显示救援速查提示   |

- *救砖与装机载荷* :: =live-rescue-tools= 将 =rescue-chroot.sh= 与 =emergency-blue.sh= 装进系统 profile 的 =/bin= （其 builder 仅使用核心 Guile 过程 ~mkdir~ 、 ~copy-file~ 与 ~chmod~ ，无需外包 ~with-imported-modules~ ）。 =%live-skeletons= 将 =source/files/livecd= 配置与当前仓库快照（经 =%live-repo-select?= 剔除 =.git= 、 =dist= 与 =tmp= ，防止把 =dist/= 下的旧 ISO 打进镜像）预置到 =~/Guix-configs= ；由于骨架文件保留 store 的只读权限，使用前需先 ~cp -r~ 复制一份可写副本。 =%live-cli-packages= 内嵌 =emacs-minimal= （ =emergency-blue= 执行 Org Babel tangle 的硬依赖），启动后无需联网即可运行 ~emergency-blue.sh init~ 。
- *硬件兼容、权限与远程排障* :: 内置完整 =linux= 内核与 =linux-firmware= ， =kernel-arguments= 仅保留 ~"quiet"~ （移除基底安装盘屏蔽 AMD 显卡 KMS 的 ~modprobe.blacklist=radeon,amdgpu~ ），并将 =privileged-programs= 恢复为 =%default-privileged-programs= （基底安装盘仅保留 =passwd= ，缺少 =sudo= 、 =su= 、 =mount= 等 setuid 权限）。 =%live-base-services= 默认自启 =sshd= 并允许密码登录（ =root= 与 =live= 账户均使用 =fish= ，密码同为 =live= ），同时通过 =special-files-service-type= 补齐 =/usr/bin/env= （基底仅提供 =/bin/sh= ，救援脚本的 shebang 依赖 =/usr/bin/env= ）。
- *桌面变体服务裁剪与模块自包含* :: =desktop= 变体显式加入 =network-manager-service-type= （ =xfce-desktop-service-type= 仅包含 polkit、PAM 与 profile 扩展，不含 =%desktop-services= ），并从 =%live-base-services= 中配对移除 =kmscon-service-type= 与依赖 =term-tty1= 的 =console-font-service-type= ，同时移除 =connman-service-type= 。两个变体块各自在顶部内联所需的 ~use-modules~ ，公共定义通过 ~<<live-common>>~ 展开（该块不独立 tangle），跨区复用的代码块仅有上文的 ~<<guix-substitutes>>~ 。

(define live-rescue-tools
  (package
   (name "live-rescue-tools")

   (arguments

              (mkdir #$output)
              (mkdir bin)
              (for-each
               (lambda (name)
                 (let ([dst (string-append bin "/" name)])
                   (copy-file (string-append #$source "/" name) dst)
                   (chmod dst #o555)))

   (home-page "")
   (license expat)))

(define (%live-repo-select? file stat)
  (define (excluded? name)
    (or (string-suffix? (string-append "/" name) file)
        (string-contains file (string-append "/" name "/"))))
  (not (or (excluded? ".git") (excluded? "dist") (excluded? "tmp"))))

(define %live-users
