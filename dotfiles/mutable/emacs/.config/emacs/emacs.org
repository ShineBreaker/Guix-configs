* 配置域总览
:PROPERTIES:
:CUSTOM_ID: overview
:END:

本文档 =emacs.org= 是 =custom-config= 的唯一配置真理源。8 个配置域按固定顺序加载（文档顺序 = 求值顺序），定义方必须在调用方之前。配置域的边界、职责与 CUSTOM_ID 一旦建立即稳定不变——新增功能合并到最匹配的现有域，不创建第 9 个。

| 顺序 | 配置域         | CUSTOM_ID        | 主要职责                                                      | 加载前提                  |
|------+----------------+------------------+---------------------------------------------------------------+---------------------------|
|    1 | 启动与基础设施 | [[#startup]]         | GC / 路径常量 / Frame 生命周期 / 键位原语 / 包管理 / 基础行为 | 无                        |
|    2 | 界面与外观     | [[#appearance]]      | Mode-line / Tab-line / 主题字体 / 窗口布局 / Git / 颜色方案   | startup                   |
|    3 | 编辑与文本     | [[#editing]]         | 缩进括号 / EditorConfig / DWIM / mc / 终端集成                | appearance 的窗口路由     |
|    4 | 编程与开发     | [[#programming]]     | Eglot / Tree-sitter / Apheleia / Flymake / 语言注册表         | bootstrap, appearance     |
|    5 | 项目与导航     | [[#projects]]        | project.el / 文件缓冲区导航                                   | terminal, git-display     |

|    8 | 系统工具       | [[#system-tools]]    | 应用 / Daemon 预热 / Dashboard / 兼容性 shim                  | 前述全部域                |

各域内部用 =CUSTOM_ID= 锚定子节，org 链接（如 [[#modeline]]）可在文档内交叉引用。Noweb 组装块以 =#+NAME:= 标记，便于 =scripts/configctl map= 定位和 org 间跳转。

内置 =scripts/configctl= 是面向 AI agent 的片段操纵工具： =map= 结构总览、 =show <ID>= 提取子树、 =locate <ID|ref>= 定位块行号、 =tangle= 拼合产物、 =check= 轻量原则检查（域顺序 / noweb / 单产物 / 括号 / 重复定义）。深度验证（load 报错、ERT 等）由 agent 直接跑 Emacs，不封装进本工具。

** 修改与扩展指引
接手者改代码前先读本节的契约，再按功能定位到具体域动手。

*** 添加 / 修改功能
1. *定位归属域* ：按功能语义合并到 8 个现有域之一（不新建第 9 域）。键位随功能实现所在的域（功能内聚），不集中到键位块。
2. *定位插入点* ： =configctl show <ID>= 提取目标子树， =configctl locate <ID|ref>= 定位块行号区间；跨域符号用 =rg= 搜。
3. *遵守约定* ：命名 / 键位 / noweb / 架构硬约束见下；新 Emacs 包必须同步根仓库 =source/config.org= 的 =home-emacs-packages= 。

*** 命名约定
+ 公开 =custom/...= ；私有 =custom/...--...= ；路径与静态常量 =custom:...= 。
+ 同一符号不得重复 =defun= / =defvar= / =defconst= 。
+ =add-hook= / timer / 异步回调一律用命名函数，不用匿名 lambda。

*** 键位约定
+ 全局 =custom/bind= 、前缀声明 =custom/declare-binding-group= ;mode-local 键在对应 mode 声明处直写。
+ 跨域基础键（=C-x= / =M-s= / =C-c w= / =C-c h=）和无前缀 IDE 直达键集中在 [[#keys-completion]]，其余键位跟随功能域。
+ Which-key 描述、帮助分组二者同源，均从 =custom:binding-spec= 生成。

*** Noweb 分片约定
+ 标题层级是代码组织的唯一轴: =**= 模块内,每个 =***= 方面子节通过 drawer 声明一个 ref——  =:header-args:emacs-lisp: :noweb-ref <domain/aspect> :tangle no :noweb-sep "\n\n"= ,块头裸写 =#+begin_src emacs-lisp= 。必须用语言专属 =:header-args:emacs-lisp:= (普通 =:header-args:= 会被文件级语言设置覆盖,导致产物重复)。
+ 方面子节内可拆多块穿插 prose(拆块点必须在原有空行边界,配合 =noweb-sep "\n\n"= 保证产物零变化);同一 ref 的块不得跨子节。
+ 每个模块末尾设 =*** 加载组装= 子节(CUSTOM_ID =<module>-assembly=)承载唯一组装块 =#+NAME: <domain>-assembly= ; =<<ref>>= 引用必须列 0(noweb 展开会把引用处行首前缀复制到文本每一行)。每个 ref 恰好组装一次;共享实现放 =helpers/...= 并在调用方之前组装。
+ 纯文本数据(如 capture 模板)用 =#+name= 数据块: =org= 语言、=:tangle no=、紧跟唯一引用者;块内行首 =*= / =**= / =#+= 以逗号转义(=,*=)保字面,含双引号的 elisp 表达式写 =\"= ;字符串内引用时开引号留在上一行、ref 顶格,尾部按需补 =\n= 。被引用的 name 块由 =configctl check= 强制 =:tangle no= 。

*** 架构硬约束（不可破坏）
+ 唯一生成物 =main.el= ；禁止把配置 tangle 到 =lisp/= 子目录、禁止 =lisp/= load-path、禁止历史 =custom-*= feature 的 require/provide 引用。
+ 文件末尾只保留 =(provide 'main)= ；不添加全局 =:comments link= 。

** GC 与启动优化
:PROPERTIES:
:CUSTOM_ID: startup-gc
:END:

GC 启动期优化(启动完成后由 gcmh 重置)

+ =gc-cons-threshold= 推到 =most-positive-fixnum= 、=gc-cons-percentage= 推到 0.6 以减少启动期 GC；与 early-init.el 的同设置重复是刻意的——绕过 early-init 直接 batch-load main.el(如 agent 手动加载验证)时入口仍需推高。
+ =gc-cons-percentage= 启动完成后必须显式恢复 0.1:GCMH 只动态调整 =gc-cons-threshold= ,不碰 percentage,否则 GCMH 接管后 percentage 仍停留 0.6。
+ =inhibit-compacting-font-caches= 阻止 GC 压缩 font cache,避免 daemon 长驻期字体渲染抖动。
+ =auto-mode-case-fold nil= : =auto-mode-alist= 匹配不 fold case,减少每个 find-file 的匹配开销。
+ 保留 Emacs 31 默认的 =file-name-handler-alist= 与 bidi 行为。daemon 冷启动不是目标，不能用未测量的优化破坏 TRAMP、压缩文件或 RTL 文本。

#+begin_src emacs-lisp
;;; main.el --- custom-config 主配置(由 emacs.org tangle 生成) -*- lexical-binding: t; -*-

;; SPDX-FileCopyrightText: 2026 BrokenShine <xchai404@gmail.com>
;; SPDX-License-Identifier: MIT

(setq gc-cons-threshold most-positive-fixnum
      gc-cons-percentage 0.6
      inhibit-compacting-font-caches t
      auto-mode-case-fold nil)

(defun custom--reset-gc-percentage ()
  "启动完成后将 `gc-cons-percentage' 恢复为稳态值。"
  (setq gc-cons-percentage 0.1))

(add-hook 'emacs-startup-hook #'custom--reset-gc-percentage)

(message "[LOAD] 基础设施加载完成")
#+end_src

*** 外部命令声明
:PROPERTIES:
:CUSTOM_ID: bootstrap-executables

;; exec-path 前置:daemon 启动与 batch-load main.el 的包启用条件、agenote 调用
;; 都经 `executable-find' 查询当前 `exec-path';配置只保存命令名,不缓存
;; store 绝对路径,跨 generation 后仍由当前 PATH 解析。
(let* ((guix-profile (or (getenv "GUIX_PROFILE")
                         (expand-file-name "~/.guix-profile")))
       (guix-bin (expand-file-name "bin" guix-profile))
       (local-bin (expand-file-name "~/.local/bin")))
  (when (file-directory-p guix-bin)
    (add-to-list 'exec-path guix-bin))
  (when (file-directory-p local-bin)
    (add-to-list 'exec-path local-bin)))

** Frame 生命周期与 daemon
:PROPERTIES:
:CUSTOM_ID: frame
:END:

daemon/client 架构下的 frame 生命周期：display 初始化注册到 created 阶段，在 =after-make-frame-functions= 触发。每个 initializer 通过 frame parameter 保证成功执行一次。

#+begin_src emacs-lisp
(defvar custom--frame-created-initializers nil)

(defun custom--run-frame-initializers (frame functions)
  "在 FRAME 运行 FUNCTIONS，每个函数成功执行一次。"
  (when (frame-live-p frame)
    (let ((done (frame-parameter frame 'custom-frame-created-done)))
      (dolist (function functions)
        (unless (memq function done)
          (condition-case err
              (progn
                (funcall function frame)
                (push function done)
                (set-frame-parameter frame 'custom-frame-created-done done))
            (error
             (message "[frame] %s 失败: %s"
                      function (error-message-string err)))))))))

(defun custom--dispatch-frame-created (frame)
  "运行 FRAME 的 created initializer。"
  (custom--run-frame-initializers
   frame custom--frame-created-initializers))

(defun custom/add-frame-created-hook (function)
  "把 FUNCTION 注册到 frame-created 阶段。"
  (unless (memq function custom--frame-created-initializers)
    (setq custom--frame-created-initializers
          (append custom--frame-created-initializers (list function))))
  (add-hook 'after-make-frame-functions #'custom--dispatch-frame-created)
  (unless (daemonp)
    (custom--dispatch-frame-created (selected-frame))))
#+end_src

** 键位声明
:PROPERTIES:
:CUSTOM_ID: key-helper
:END:

=custom:binding-spec= 是本地键位、Which-key 与帮助的唯一声明源。每条声明在绑定真实 keymap 的同时登记描述；第三方既有 keymap 的翻译继续留在 =data/which-key-zh.el= 。

#+begin_src emacs-lisp
(defvar custom:binding-spec nil
  "本地声明式键位表。")

(defvar custom--pending-wk-descs nil
  "Which-key 加载前暂存的全局键位描述。")

(defun custom/binding--record (entry)
  "把 ENTRY 追加到 binding spec，并拒绝重复 key/mode。"
  (let ((key (plist-get entry :key))
        (mode (or (plist-get entry :mode) 'global)))
    (when (seq-find
           (lambda (existing)
             (and (equal key (plist-get existing :key))
                  (eq mode (or (plist-get existing :mode) 'global))))
           custom:binding-spec)
      (error "重复键位声明: %s (%s)" key mode))
    (setq custom:binding-spec
          (append custom:binding-spec (list entry)))))

(defun custom/binding--register-which-key (key description)
  "为 KEY 注册 DESCRIPTION;which-key 未加载时暂存待注册。"
  (if (featurep 'which-key)
      (which-key-add-key-based-replacements key description)
    (push (cons key description) custom--pending-wk-descs)))

(defun custom/bind (key target description group &rest properties)
  "声明并绑定全局 KEY 到 TARGET。
DESCRIPTION、GROUP 与 PROPERTIES 同时供 Which-key 和帮助使用。"
  (let ((entry (append (list :key key
                             :command target
                             :description description
                             :group group)
                       properties)))
    (custom/binding--record entry)
    (unless (plist-get entry :prefix)
      (keymap-global-set key target))
    (custom/binding--register-which-key key description)
    entry))

(defun custom/declare-binding-group (key description)
  "声明 Which-key 展示的中间分组 KEY。"
  (custom/bind key nil description nil :prefix t))

(defun custom/register-pending-wk-descs ()
  "把暂存的全局键位描述注册到 Which-key。"
  (dolist (entry (nreverse custom--pending-wk-descs))
    (which-key-add-key-based-replacements (car entry) (cdr entry)))
  (setq custom--pending-wk-descs nil))

(defun custom/binding-help-sections ()
  "从 binding spec 生成帮助分组。"
  (let (order table)
    (dolist (entry custom:binding-spec)
      (when-let* ((group (plist-get entry :group)))
        (unless (member group order)
          (setq order (append order (list group))))
        (push (cons (plist-get entry :key)
                    (plist-get entry :description))
              (alist-get group table nil nil #'equal))))
    (mapcar
     (lambda (group)
       (cons group (nreverse (alist-get group table nil nil #'equal))))
     order)))
#+end_src

** 基础行为设置
:PROPERTIES:
:CUSTOM_ID: core-behavior
:END:

GC 策略、文件备份、历史记录、自动保存、custom-file 位置等基础设置。

+ ~gcmh-mode~ :启动后接管 GC,空闲时自动 GC,编辑时不打断
+ ~no-littering~ :把各种包生成的文件统一放到 =var/= 和 =etc/=
+ ~savehist~ / =recentf= :minibuffer 历史与最近文件持久化
+ ~desktop~ :会话恢复(daemon 默认关闭,避免恢复成本转移到启动)
+ ~custom-file~ :指向 =etc/custom.el= ,避免 customize 污染 init.el
+ 失去焦点后在空闲期保存正常访问的本地文件 buffer；不在焦点事件里同步写盘，也不保存内部/伪造临时 buffer

GCMH + 智能垃圾回收管理 (启动后接管 GC)

+ =gcmh-idle-delay 'auto'= 让 GCMH 自适应 idle 时间 (短空闲快 GC、长空闲等更空闲再 GC), 避免编辑过程中被打断。
+ =gcmh-high-cons-threshold 32 MiB= 是 daemon 长运行环境的合理上限: 太小 (默认 16 MiB) → GC 频繁; 太大 (64+ MiB) → 单次 GC 卡顿长。32 MiB 在 8+ GiB 内存机器上不构成压力,与 gcmh-mode 维持的 low-cons-threshold (默认 1 MiB) 的差距让 GCMH 能区分"短暂峰值"和"持续压力"。
+ 不再在 use-package 外手动 =setq gc-cons-threshold=: GCMH 接管后该变量由 GCMH 动态调整,手动 setq 会与 GCMH 打架。

启动画面与基础体验

+ daemon 长驻下 client 关闭 *不退出 Emacs*; kill-emacs 不等待子进程确认
+ 所有未保存内容在 focus-loss 时已落盘, 见下方 =after-focus-change-function= 。

#+begin_src emacs-lisp
(use-package gcmh
  :demand t
  :custom
  (gcmh-idle-delay 'auto)
  (gcmh-auto-idle-delay-factor 10)
  (gcmh-high-cons-threshold (* 32 1024 1024))
  :config
  (gcmh-mode 1))

(setq read-process-output-max (* 4 1024 1024)
      process-adaptive-read-buffering nil
      fast-but-imprecise-scrolling t)

(setq inhibit-startup-screen t
      initial-scratch-message nil
      ring-bell-function 'ignore
      confirm-kill-processes nil
      use-dialog-box nil
      use-file-dialog nil)

(use-package no-littering
  :demand t
  :config
  (setq backup-directory-alist
        `((".*" . ,(no-littering-expand-var-file-name "backup/"))))
  (setq auto-save-file-name-transforms
        `((".*" ,(no-littering-expand-var-file-name "auto-save/") t)))
  (setq custom-file (no-littering-expand-etc-file-name "custom.el"))
  (when (file-exists-p custom-file)
    (load custom-file t)))

(use-package savehist
  :demand t
  :config
  (savehist-mode 1))

(use-package recentf
  :demand t
  :custom
  (recentf-max-saved-items 300)
  ;; Emacs 31:daemon 长驻下定期自动保存,异常死亡不丢历史
  ;; (默认只在 kill-emacs 时写)。
  (recentf-autosave-interval 5)
  :config
  (recentf-mode 1))

(defconst custom:focus-save-idle-delay 1
  "失焦后保存用户文件 buffer 前等待的空闲秒数。")

(defvar custom--focus-save-timer nil
  "失焦保存的 pending idle timer。")

(defun custom/user-file-buffer-p ()
  "当前 buffer 是否为正常访问的、可保存的本地用户文件 buffer。"
  (and buffer-file-name
       buffer-file-truename
       (buffer-modified-p)
       (not buffer-read-only)
       (not (buffer-base-buffer))
       (not (file-remote-p buffer-file-name))))

(defun custom/save-user-file-buffers ()
  "保存已修改的本地用户文件 buffer，不触碰内部或远程 buffer。"
  (setq custom--focus-save-timer nil)
  (save-some-buffers t #'custom/user-file-buffer-p))

(defun custom/schedule-focus-save ()
  "根据当前焦点状态安排或取消空闲保存。
任一存活 frame 已聚焦或焦点状态未知时不保存。"
  (when (timerp custom--focus-save-timer)
    (cancel-timer custom--focus-save-timer)
    (setq custom--focus-save-timer nil))
  (unless (seq-some #'frame-focus-state (frame-list))
    (setq custom--focus-save-timer
          (run-with-idle-timer custom:focus-save-idle-delay nil
                               #'custom/save-user-file-buffers))))

(add-function :after after-focus-change-function #'custom/schedule-focus-save)

(unless (or (daemonp) noninteractive)
  (server-mode 1))
#+end_src

(defun custom/context-menu--translate-string (string)
  "翻译 STRING；未登记时返回原字符串。"
  (if-let* ((translation
             (cdr (assoc (substring-no-properties string)
                         custom:context-menu-label-translations))))
      (apply #'propertize translation (text-properties-at 0 string))
    string))

(defun custom/context-menu--translate-object (object)
  "递归翻译 OBJECT 中的字符串。"
  (cond
   ((stringp object)
    (custom/context-menu--translate-string object))
   ((consp object)
    (mapcar #'custom/context-menu--translate-object object))
   (t object)))

(defun custom/context-menu--translate-menu-item (item)
  "翻译菜单项 ITEM 的标题和子菜单。"
  (when (and (consp item) (eq (car item) 'menu-item))
    (let ((label-cell (cdr item))
          (binding (nth 2 item))
          (properties (nthcdr 3 item)))
      (when label-cell
        (setcar label-cell
                (custom/context-menu--translate-object (car label-cell))))
      (when (keymapp binding)
        (custom/context-menu--translate-keymap binding))
      (while (consp properties)
        (when (and (eq (car properties) :help)
                   (consp (cdr properties)))
          (setcar (cdr properties)
                  (custom/context-menu--translate-object (cadr properties))))
        (setq properties (cddr properties))))))

(defun custom/context-menu--translate-keymap (keymap)
  "递归翻译 KEYMAP 内的菜单标题。"
  (when (keymapp keymap)
    (when (and (consp keymap)
               (eq (car-safe keymap) 'keymap)
               (stringp (cadr keymap)))
      (setcar (cdr keymap)
              (custom/context-menu--translate-string (cadr keymap))))
    (map-keymap
     (lambda (_event binding)
       (cond
        ((and (consp binding) (eq (car binding) 'menu-item))
         (custom/context-menu--translate-menu-item binding))
        ((keymapp binding)
         (custom/context-menu--translate-keymap binding))))
     keymap))
  keymap)

  (custom/context-menu--translate-keymap menu))

** Tab-line
:PROPERTIES:
:CUSTOM_ID: tab-line
:END:

基于内置 =tab-line= 的 per-frame 文件标签,隔离多个 emacsclient frame 的缓冲区序列。

+ 禁用 frame 级 =tab-bar=,改用 window-local =tab-line= 作为文件标签栏——每个文件 buffer 的 window 一条标签栏,避免与 [[#frame][Frame 生命周期]] 的 per-frame 隔离冲突。

*** Per-frame 缓冲区跟踪
:PROPERTIES:
:CUSTOM_ID: tab-line-tracking
:header-args:emacs-lisp: :noweb-ref appearance/tab-line-tracking :tangle no :noweb-sep "\n\n"
:END:

每个 frame 维护一个有序的文件 buffer 列表,存储在 frame parameter =custom--frame-tab-buffers= 中。这是多 emacsclient frame 隔离的核心:不同 frame 的标签序列完全独立。

#+attr_org: :width 60
| 状态变更      | 触发 hook                              | 行为                                     |
|---------------+----------------------------------------+------------------------------------------|
| 缓冲区可见    | =window-buffer-change-functions=         | 唯一注册路径:追加到 frame 列表尾部(去重) |
| 缓冲区被 kill | =kill-buffer-hook=                       | 从所有 frame 的列表移除                  |
| frame 被删除  | =delete-frame-functions=                 | 丢弃该 frame 的标签状态                  |
| 项目切换      | advice =project-switch-project= :after   | 清空当前 frame 列表(见 [[#project-navigation][项目与导航]])       |

注册顺序即标签排列顺序(append-only),保证用户切换的稳定心智模型。=window-buffer-change-functions= 是唯一的注册入口,不再依赖 =find-file-hook= / =server-switch-hook= 等重复触发源。

#+begin_src emacs-lisp
(defun custom--tabs-get-frame-buffer-list (&optional frame)

  (frame-parameter (or frame (selected-frame)) 'custom--frame-tab-buffers))

(defun custom--tabs-set-frame-buffer-list (buffers &optional frame)
  "设置 FRAME 的标签缓冲区列表为 BUFFERS。"
  (set-frame-parameter (or frame (selected-frame)) 'custom--frame-tab-buffers buffers))
#+end_src

注册与注销是一对对称操作:注册做尾部追加(去重),注销做删除;两者只维护 frame parameter 列表,不直接操作窗口。

#+begin_src emacs-lisp
(defun custom--tabs-register-buffer (buffer &optional frame)
  "将 BUFFER 注册到 FRAME 的标签列表尾部(去重)。"
  (let* ((target-frame (or frame (selected-frame)))
         (buffers (or (custom--tabs-get-frame-buffer-list target-frame) '())))
    (unless (memq buffer buffers)
      (custom--tabs-set-frame-buffer-list
       (append buffers (list buffer))
       target-frame))))

(defun custom--tabs-unregister-buffer (buffer &optional frame)
  "从 FRAME 的标签列表中移除 BUFFER。"
  (let* ((target-frame (or frame (selected-frame)))
         (buffers (or (custom--tabs-get-frame-buffer-list target-frame) '())))
    (when (memq buffer buffers)
      (custom--tabs-set-frame-buffer-list
       (delq buffer buffers)
       target-frame))))
#+end_src

=window-buffer-change-functions= 的回调适配两种调用形态:全局 hook 传 frame 时遍历该 frame 所有 window,buffer-local hook 传 window 时直接取其 buffer。

#+begin_src emacs-lisp
(defun custom--tabs-on-window-buffer-change (frame-or-window)
  "缓冲区变更时,把新缓冲区注册到对应 frame。
FRAME-OR-WINDOW 可以是 frame(全局 hook)或 window(buffer-local hook)。
这是标签列表的唯一注册入口,不依赖 find-file-hook / server-switch-hook。"
  (cond
   ((frame-live-p frame-or-window)
    (walk-windows
     (lambda (window)
       (when (eq (window-frame window) frame-or-window)
         (let ((buffer (window-buffer window)))
           (when (and (buffer-live-p buffer)
                      (custom/tab-visible-p buffer)
                      (not (minibufferp buffer)))
             (custom--tabs-register-buffer buffer frame-or-window)))))
     'no-mini frame-or-window))
   ((window-live-p frame-or-window)
    (let ((buffer (window-buffer frame-or-window))
          (frame (window-frame frame-or-window)))
      (when (and (buffer-live-p buffer)
                 (custom/tab-visible-p buffer)
                 (not (minibufferp buffer)))
        (custom--tabs-register-buffer buffer frame))))))
#+end_src

(defun custom--tabs-switch-to-buffer (buffer &optional window)
  "在 WINDOW 中切换到 BUFFER,并刷新标签显示。"
  (when (buffer-live-p buffer)
    (let ((target-window (custom--tabs-target-window window))
          (switch-to-buffer-obey-display-actions nil))
      (with-selected-window target-window
        (switch-to-buffer buffer)
        (tab-line-force-update t)))))

(defun custom/tabs-next (&optional arg)
  "切换到当前标签列表中的下一个标签。ARG 为步数。"
  (interactive "p")
  (let* ((target-window (custom--tabs-target-window))
         (buffers (custom--tabs-frame-buffers target-window))
         (current (window-buffer target-window))
         (position (seq-position buffers current))
         (step (or arg 1)))
    (when (and position buffers)
      (custom--tabs-switch-to-buffer
       (nth (mod (+ position step) (length buffers)) buffers)
       target-window))))

(defun custom/tabs-previous (&optional arg)
  "切换到当前标签列表中的上一个标签。ARG 为步数。"
  (interactive "p")
  (custom/tabs-next (- (or arg 1))))

(defun custom/tabs-close-buffer (&optional window buffer)
  "在 WINDOW 隐藏 BUFFER 的标签(bury + unregister,不 kill buffer)。
BUFFER 默认为 WINDOW 当前显示的 buffer。"
  (interactive)
  (let* ((target-window (custom--tabs-target-window window))
         (target-buffer (or buffer (window-buffer target-window)))
         (target-frame (window-frame target-window)))
    (when (buffer-live-p target-buffer)
      (custom--tabs-unregister-buffer target-buffer target-frame)
      (when (eq target-buffer (window-buffer target-window))
        (if-let* ((next (seq-find (lambda (candidate)
                                    (and (buffer-live-p candidate)
                                         (custom/tab-visible-p candidate)
                                         (not (eq candidate target-buffer))))
                                  (custom--tabs-get-frame-buffer-list target-frame))))
            (custom--tabs-switch-to-buffer next target-window)
          (with-selected-window target-window
            (bury-buffer target-buffer)
            (let ((fallback
                   (seq-find (lambda (candidate)
                               (and (buffer-live-p candidate)
                                    (not (eq candidate target-buffer))))
                             (buffer-list target-frame))))
              (when fallback
                (switch-to-buffer fallback))))))
      (tab-line-force-update t))))

(defun custom/tab-line-close-tab (tab)
  "鼠标关闭按钮回调:与键盘 close 走同一路径(语义对称)。"
  (interactive)
  (let ((buffer (if (bufferp tab) tab (current-buffer))))
    (when (buffer-live-p buffer)
      (custom/tabs-close-buffer (custom--tabs-target-window) buffer))))

;; 标签重排:官方 tab-line-move-tab-forward 带 tabs-function 守卫,只对
;; 内置 tab-line-tabs-fixed-window-buffers 生效,对本模块 frame 列表驱动
;; 的 custom/tab-line-tabs 是静默 no-op,故直接操作 frame 列表实现。
(defun custom/tabs-move (&optional arg)
  "把当前标签在 frame 标签列表中移动 ARG 位(正向后移,负值前移)。"
  (interactive "p")
  (let* ((frame (selected-frame))
         (buffers (custom--tabs-get-frame-buffer-list frame))
         (buffer (current-buffer))
         (pos (seq-position buffers buffer)))
    (when (and pos (> (length buffers) 1))
      (let* ((rest (delq buffer buffers))
             (new-pos (mod (+ pos (or arg 1)) (length buffers))))
        (custom--tabs-set-frame-buffer-list
         (append (seq-take rest new-pos)
                 (list buffer)
                 (seq-drop rest new-pos))
         frame)
        (tab-line-force-update t)))))

(defun custom/tabs-move-backward (&optional arg)
  "把当前标签在 frame 标签列表中前移 ARG 位。"
  (interactive "p")

(defun custom/git-repo-root (&optional file)
  "返回 FILE 所在 Git 仓库根目录(vc 内置 rev-parse,worktree/submodule 安全)。
不能改用 `vc-backend' 做类型判定:它只回答「对象是否被注册」,对目录恒 nil,

  (when-let* ((target (or file (buffer-file-name) default-directory)))
    (vc-call-backend 'Git 'root target)))

(defun custom/git-buffer-file ()
  "返回当前 buffer 对应的文件，不存在时抛出用户错误。"
  (or (buffer-file-name)

(defun custom/git--ensure-repo (&optional file)
  "确保 FILE 或当前 buffer 位于 Git 仓库中，并返回仓库根目录。"
  (or (custom/git-repo-root file)

(defun custom/git--run (&rest args)
  "在当前仓库中执行 Git ARGS。

(defun custom/register-side-window (regex side size)
  "把 REGEX 匹配的 buffer 路由到 SIDE 边的 side-window，占用 SIZE 比例。

REGEX : buffer-name 匹配字符串正则
SIDE  : bottom / right / left / top（符号）
SIZE  : 0~1 浮点比例

规则追加到 `display-buffer-alist' 末尾。顺序敏感：更具体的规则应先注册。"
  (add-to-list 'display-buffer-alist
               `(,regex
                 (display-buffer-in-side-window)
                 (side . ,side)
                 (slot . 0)
                 (,(if (memq side '(left right)) 'window-width 'window-height) . ,size))
               t))

(defun custom/display-buffer-in-main-window (buffer &optional _alist)
  "把 BUFFER 显示在「主编辑窗口」并选中。
主编辑窗口 = 当前 frame 内最靠上（y 坐标最小）的非 side-window 窗口。
保证无论光标当前在哪个窗口（如底部 magit），COMMIT_EDITMSG
都稳定落到上方编辑窗口，与「上编辑 + 下 magit」布局一致。

若无候选（如 frame 只剩 side-window），退化为 `display-buffer-pop-up-window'。

同时用作 `display-buffer-alist' 的 action 函数（参数 ALIST 被忽略）和
`server-window' 的值（server.el 调用时只传 buffer 一个参数）。"
  (let* ((frame (selected-frame))
         (candidates
          (cl-remove-if
           (lambda (w) (window-parameter w 'window-side))
           (window-list frame 'no-minibuf (frame-first-window frame))))
         (target (car (sort candidates
                            (lambda (a b)
                              (let ((ya (nth 1 (window-edges a nil t t)))
                                    (yb (nth 1 (window-edges b nil t t))))
                                (or (< ya yb)
                                    (and (= ya yb)
                                         (< (nth 0 (window-edges a nil t t))
                                            (nth 0 (window-edges b nil t t)))))))))))
    (if (window-live-p target)
        (progn
          (set-window-buffer target buffer)
          (select-window target)
          target)
      (display-buffer buffer '(display-buffer-pop-up-window)))))

(defun custom/display-or-focus (buffer action &optional select)
  "有则聚焦，无则按 ACTION 创建。
BUFFER 已在某窗口显示时，聚焦该窗口（SELECT 非 nil）；否则把 ACTION 绑定为
`display-buffer-overriding-action' 创建——它的优先级高于 `display-buffer-alist',
只影响本次调用，绕过 side-window 规则的同时不屏蔽其他包注册的路由。"
  (when (buffer-live-p buffer)
    (if-let* ((win (get-buffer-window buffer)))
        (when select (select-window win))
      (let ((display-buffer-overriding-action action))
        (display-buffer buffer)))))

*** GUI/TTY 混合 daemon 约束
:PROPERTIES:
:CUSTOM_ID: mixed-gui-tty-constraints
:END:

(defun custom/apply-terminal-faces (&optional frame)
  "让 TTY FRAME 的所有命名 face 使用终端透明背景。
清除背景与反色后，为 `hl-line' 恢复 Ef theme 的柔和背景，为代码块恢复 `bg-alt'
面板，并用
`custom:terminal-face-emphasis' 补充其余非颜色交互语义；所有前景色继续由
当前 Ef theme 提供。Foot 需使用 alpha-mode=all 才能让 hl-line 背景半透明。
仅在真实 TTY（非 batch、至少 8 色）下生效；GUI 为 no-op。"
  (condition-case err
      (when (and (not noninteractive)
                 (not (display-graphic-p frame))
                 (>= (display-color-cells frame) 8))
        (let ((tty (or frame (selected-frame)))
              (hl-line-background (custom/terminal-theme-color 'bg-dim)))
          (with-selected-frame tty
            (dolist (parameter custom:terminal-frame-parameters)
              ;; Ef theme owns foreground-color after startup; only the initial
              ;; frame defaults use unspecified-fg to avoid a pre-theme flash.
              (unless (eq (car parameter) 'foreground-color)
                (set-frame-parameter tty (car parameter) (cdr parameter))))
            (dolist (face (face-list))
              (set-face-attribute face tty
                                  :background 'unspecified
                                  :inverse-video nil))
            (dolist (entry custom:terminal-face-emphasis)
              (when (facep (car entry))
                (apply #'set-face-attribute
                       (car entry) tty (cdr entry))))
            (when (and hl-line-background (facep 'hl-line))
              (set-face-attribute 'hl-line tty
                                  :background hl-line-background
                                  :underline nil
                                  :extend t))
            (when-let* ((block-background
                         (custom/terminal-theme-color 'bg-alt)))
              (dolist (face custom:terminal-block-faces)
                (when (facep face)
                  (set-face-attribute face tty
                                      :background block-background
                                      :extend t)))))))
    (error
     (message "custom/apply-terminal-faces: %s" (error-message-string err)))))

(defun custom/which-key--join-key (prefix key)
  "将 PREFIX 与 KEY 合并为 which-key 可用的键序列字符串。"
  (if (and prefix (> (length prefix) 0))
      (concat prefix " " key)
    key))

(defun custom/which-key--flatten-spec (prefix spec)
  "将 PREFIX 下的单个 SPEC 展开为 ((key . desc) ...) 列表。"
  (pcase spec
    (`(,key ,desc . ,children)
     (let ((full-key (custom/which-key--join-key prefix key)))
       (append (list (cons full-key desc))
               (custom/which-key--flatten-specs full-key children))))
    (`(,key . ,desc)
     (list (cons (custom/which-key--join-key prefix key) desc)))
    (_
     (error "无法识别的 which-key 描述项: %S" spec))))

(defun custom/which-key--flatten-specs (prefix specs)
  "将 PREFIX 下的 SPECS 展开为平铺的 ((key . desc) ...) 列表。"
  (apply #'append
         (mapcar (lambda (spec)
                   (custom/which-key--flatten-spec prefix spec))

  "FRAME（默认 selected-frame）是否可呈现 Ef theme 的完整前景 palette。"
  (with-selected-frame (or frame (selected-frame))
    (or (display-graphic-p)
        (and (not noninteractive)
             (>= (display-color-cells) 256)))))

(defun custom/color-scheme-init ()
  "初始化颜色方案适配：读取 Darkman D-Bus 模式并应用主题、注册监听器。

  (let ((initial-mode (or (custom/color-scheme-get-from-dbus)

  "在 FRAME 可用时补齐与主题相关的 frame 初始化。

          (custom/color-scheme-init)
        (custom/color-scheme--load-theme-if-needed
         (custom/color-scheme--theme-for-mode
          custom/color-scheme-current-mode))))))

  (delq nil
        (mapcar (lambda (entry)
                  (let ((orig-mode (car (plist-get entry :modes)))
                        (ts-mode (plist-get entry :ts-mode)))
                    (when (and orig-mode ts-mode)
                      (cons orig-mode ts-mode))))
                custom:language-capabilities))

(defconst custom:language-eglot-server-programs
  (let ((seen (make-hash-table :test 'equal))
        (result nil))
    (dolist (entry custom:language-capabilities)
      (let ((server (plist-get entry :server)))
        (when server
          (let ((key (mapconcat #'identity server " ")))
            (if-let* ((pair (gethash key seen)))
                (setcar pair (append (car pair) (plist-get entry :modes)))
              (push (cons (plist-get entry :modes) server) result)
              (puthash key (car result) seen))))))
    (nreverse result))
  "附加到 `eglot-server-programs' 的语言服务器配置(从能力表派生,按 server 命令去重)。")

*** Apheleia 与 Flymake

Apheleia 用 =:hook (prog-mode . apheleia-mode)= 而非 =:defer t= 触发加载:后者没有可靠的首次加载入口,=apheleia-global-mode= 不会启用,保存时格式化在用户首次手动调 Apheleia 命令前都失效。进任何 prog buffer 就启用 global mode,保存时格式化立即生效。

仿 Zed project panel 的左侧文件面板:项目根 Dired 固定在左侧 side-window(宽度 0.2),默认隐藏文件详情以适配窄列。RET / mouse-2 / =^= 语义与 Zed 一致——文件在主编辑窗口打开且面板保留,目录(含 =..=)在面板内原地切换(显式 =set-window-buffer= 替换面板 buffer 并 kill 旧 buffer,不堆积;side-window 会拒绝 =find-alternate-file= 内部的 =switch-to-buffer=,故不可用它),面板定制由 =custom/dired--panel-setup= 在每次替换后重放。=C-c w= 前缀声明与总开关见 [[#keybindings][前缀键体系]]。

#+begin_src emacs-lisp
(defconst custom:dired-side-action
  '(display-buffer-in-side-window
    (side . left) (slot . 0) (window-width . 0.2))
  "左侧 Dired 面板的 display-buffer action:宽度 0.2(Zed project panel 比例)。")

(defun custom/dired--panel-setup (buffer)
  "对 BUFFER 应用面板定制:窄视图、header 路径与面板访问键。
所有 Dired buffer 共享 `dired-mode-map',面板 remap 必须落在 buffer
私有的 keymap copy 上,否则会污染其他 Dired buffer。"
  (with-current-buffer buffer
    (dired-hide-details-mode 1)
    (setq-local header-line-format 'default-directory)
    (use-local-map (copy-keymap dired-mode-map))
    (define-key (current-local-map) [remap dired-find-file]
                #'custom/dired-find-file-in-main)
    (define-key (current-local-map) [remap dired-up-directory]
                #'custom/dired-up-in-panel)
    (define-key (current-local-map) [mouse-2]
                #'custom/dired-mouse-find-file-in-main)))

(defun custom/dired--panel-visit (filename)
  "面板访问语义:目录原地替换面板 buffer,文件进主编辑窗口。
FILENAME 须为绝对路径(`dired-get-file-for-visit' 对 =..= 返回
相对名,调用前展开)。目录不能走 `find-alternate-file':其内部
`switch-to-buffer' 会被 side-window 拒绝而把新 Dired 投到其他窗口,
故显式 `set-window-buffer' 替换面板窗口并 kill 旧面板 buffer;
`dired-noselect' 天然复用已存在的同目录 Dired buffer,不堆积。"
  (setq filename (expand-file-name filename))
  (if (not (file-directory-p filename))
      (custom/display-buffer-in-main-window (find-file-noselect filename))
    (let* ((old-buf (current-buffer))
           (new-buf (dired-noselect filename)))
      (unless (eq new-buf old-buf)
        (custom/dired--panel-setup new-buf)
        (set-window-buffer nil new-buf)
        (set-buffer new-buf)
        (kill-buffer old-buf)))))

(defun custom/dired-find-file-in-main ()
  "面板版 RET:目录原地替换面板 buffer,文件进主编辑窗口。
side-window 内直接 RET 会把文件开进面板,故走本命令改写目标窗口。
取行文件名必须用 `dired-get-file-for-visit':裸 `dired-get-filename'
对 =.= / =..= 行会抛 \"Cannot operate on '.' or '..'\"。"
  (interactive)
  (custom/dired--panel-visit (dired-get-file-for-visit)))

(defun custom/dired-up-in-panel ()
  "面板内回到上级目录(原地替换,保持面板定制)。"
  (interactive)
  (custom/dired--panel-visit
   (file-name-directory (directory-file-name (dired-current-directory)))))

(defun custom/dired-mouse-find-file-in-main (event)
  "面板版 mouse-2:与 `custom/dired-find-file-in-main' 同语义。
内置 <mouse-2> 的 other-window 变体会把文件开进面板或新窗口,不走它。"
  (interactive "e")
  (let ((window (posn-window (event-end event)))
        (pos (posn-point (event-end event))))
    (unless (windowp window) (error "No file chosen"))
    (select-window window)
    (save-excursion
      (goto-char pos)
      (custom/dired--panel-visit (dired-get-file-for-visit)))))

(defun custom/panel-dired ()
  "打开项目根(不在项目则当前目录)的左侧 Dired 面板。
有已显示的面板窗口则聚焦;buffer 存在则重新显示;无则新建。
窄面板默认隐藏文件详情,header-line 显示完整路径。"

  (let ((buf (dired-noselect (custom/project-root-or-default))))
    (custom/dired--panel-setup buf)
    (custom/display-or-focus buf custom:dired-side-action t)))

** Completion 框架
:PROPERTIES:
:CUSTOM_ID: completion
:END:

Minibuffer 补全采用 vertico 生态 6 件套:vertico(minibuffer 候选列表) / orderless(空格分隔模糊匹配) / marginalia(候选注解) / consult(搜索导航命令族) / embark(上下文动作) / cape(补全后端扩展);in-region 补全用内置 ~completion-preview-mode~ (ghost-text 预览,比弹出菜单更轻量)。全部为纯 Lisp,daemon 启动期同步加载,首个 client 的第一次 =M-x= 即具备完整补全体验。

+ 直接复用启动域的 aspell/hunspell 路径缓存、savehist 历史与 [[#frame][Frame 生命周期]]
+ ef-themes 内置全部补全包 face 适配,无需手动定义补全相关 face
+ 补全栈的直达键( =C-.= embark-act / =M-/= cape-dabbrev)集中在 [[#global-keys]],consult 命令族键位见本域末尾

*** Minibuffer 补全栈
:PROPERTIES:
:CUSTOM_ID: completion-minibuffer
:header-args:emacs-lisp: :noweb-ref keys/completion-minibuffer :tangle no :noweb-sep "\n\n"
:END:

~vertico~ - minibuffer 候选纵向列表
+ 候选直接显示在 minibuffer 内,输入实时过滤;vertico-cycle 让 C-n/C-p 循环导航。
+ 默认排序 =vertico-sort-history-length-alpha= :按 savehist minibuffer 历史 + 时间衰减 + 长度字母序,近期输入过的候选排前。
+ ~vertico-directory~ 让文件补全的 RET 进入目录、DEL 返回上级目录。

~orderless~ - 空格分隔多模式模糊匹配
+ 输入 =foo bar= 匹配同时含 foo 与 bar 的候选,顺序任意;basic 兜底 orderless 不覆盖的场景。
+ 文件类别保留 basic+partial-completion,=/e/n/p= 这类路径缩写展开需要前缀语义。

~marginalia~ - 候选右侧注解
+ 命令显示 docstring、变量显示值、文件显示大小与权限,与 vertico 同屏。

#+begin_src emacs-lisp
;; vertico:minibuffer 候选纵向列表。TTY frame 同样工作(无 childframe)。
(use-package vertico
  :demand t
  :config
  (setq vertico-cycle t)
  (vertico-mode 1)
  ;; 文件补全中 RET 进入目录、DEL 返回上级,与下方文件类别的
  ;; partial-completion 路径缩写协同。DEL 必须用 delete-char 而非
  ;; vertico-directory-up:后者带 file-category 守卫,在 consult-line 等
  ;; 非文件补全里是 no-op,minibuffer 将无法退格;delete-char 仅在光标
  ;; 前是 / 且为文件补全时才删目录段,否则回退 delete-backward-char。
  (require 'vertico-directory)
  (define-key vertico-map (kbd "RET") #'vertico-directory-enter)
  (define-key vertico-map (kbd "DEL") #'vertico-directory-delete-char))

;; orderless:空格分隔多模式模糊匹配;basic 兜底。
;; completion-category-defaults 置空避免个别 category 的默认样式
;; 覆盖 orderless;文件类别保留 basic+partial-completion。
(use-package orderless
  :demand t
  :config
  (setq completion-styles '(orderless basic)
        completion-category-defaults nil
        completion-category-overrides
        '((file (styles basic partial-completion)))))

;; marginalia:候选右侧注解(命令 docstring / 变量值 / 文件属性)。
(use-package marginalia
  :demand t
  :config
  (marginalia-mode 1))

;; 与 vertico(minibuffer 层)互补,capf 后端(eglot LSP / cape)全部复用。
;; TAB 接受候选,M-n/M-p 循环候选,M-i 补全公共前缀(再按弹 *Completions*);

~consult~ - 搜索与导航命令族,与 vertico 组合获得候选预览

  (setq-local completion-at-point-functions
              (remq 'ispell-completion-at-point
                    completion-at-point-functions)))

** Guix 集成与 daemon 预热
:PROPERTIES:
:CUSTOM_ID: guix-daemon
:END:

Guix 环境检测、shepherd daemon 集成、外部工具加速范式。

+ =exec-path= 在 early-init.el 已扩充(Guix profile bin + ~/.local/bin)
+ 外部命令只缓存命令名，调用时通过当前 =exec-path= 解析，避免长驻 daemon 固定到旧 Guix generation
+ daemon 由 shepherd 的 =emacs-daemon= 服务管理( =emacs --fg-daemon= ),init.el 不重复启用 =server-mode= (仅 standalone 时启用)
+ *预热策略*:daemon 启动时间不敏感，按冷 =require= 基准白名单预载常用交互 feature。不会启动 LSP、聊天或 PDF 子进程；应用型包仍按需加载。
+ 当前白名单消除的本机冷首用成本约为:Magit 0.37s、Org-roam 0.18s、TRAMP 0.17s、Apheleia 0.05s。

#+begin_src emacs-lisp
(defconst custom:daemon-warmup-features
  '(org-agenda org-capture org-roam
               apheleia magit tramp)
  "daemon 启动阶段预载的常用交互 feature 白名单。")

(defun custom/daemon-warmup ()
  "同步预载 `custom:daemon-warmup-features'，让首个 client 直接复用。"
  (let ((gc-cons-threshold most-positive-fixnum)
        (gc-cons-percentage 0.6)
        failed)
    (dolist (feature custom:daemon-warmup-features)
      (condition-case err
          (unless (require feature nil t)
            (push (cons feature "未找到 feature") failed))
        (error
         (push (cons feature (error-message-string err)) failed))))
    (garbage-collect)
    (when failed
      (message "[custom-config] daemon 预热失败: %S" (nreverse failed)))
    (null failed)))
#+end_src

** Dashboard
:PROPERTIES:
:CUSTOM_ID: dashboard
:END:

启动仪表盘,基于第三方 =dashboard= 包(1.8.0)的 doom 风格定制:待办(Agenda)、最近文件、项目三个高频区 + 一行 navigator 二级入口按钮(计时/书签/知识库/快捷键帮助)。

加载模型依赖两个机制而非自建状态机:

- =initial-buffer-choice= 指向 =custom/dashboard-initial-buffer= ——仅当 client 无文件参数时才渲染,=emacsclient FILE= 天然不被覆盖。
- 全局单 =*dashboard*= buffer 由插件维护(多 frame 共享;GUI/TTY 宽窄差异混开时已知有错位取舍,接受)。窗口尺寸变化后用 =M-x dashboard-open= 重排。

Agenda 区由插件的 =org-map-entries= 扫描 =org-agenda-files= 生成,按 scheduled/deadline 时间升序;org 为惰性加载,故包装函数先 =require 'org-agenda= 再渲染。无文件骨架、双列布局、TTL 缓存等自研复杂度均已随本迁移删除。

全量渲染(item 生成 + agenda 扫描 + 装饰)单次上百毫秒,触发侧必须收敛:=dashboard-insert-section= 宏对 list 参数求值 4 次,agenda 的 =org-map-entries= 全量扫描随之重复 4 次,由渲染入口的请求级 advice 合并为 1 次(跨渲染不缓存);=server-after-make-frame-hook= 回调比较渲染宽度,相符(同宽新帧或正常路径)则跳过,只有首帧哑上下文宽度错误才重渲染自愈;resize 事件只挂 idle timer,拖拽的连续中间宽度不逐次全量渲染,静止 0.3s 后按最终宽度刷一次。版心不足 =custom:dashboard-min-content-width= 的窗口(拖拽经过的窄中间态)不做渲染,保留上一次可读内容。

标题行装饰(=custom/dashboard--decorate-headings= )在每次渲染后运行:版心宽度固定为窗口正文宽的 =custom:dashboard-content-ratio= 比例(两侧空列各占余下比例的一半,按 100/140/200 三档常用列宽调优),标题行与分割线都补齐到版心宽;板块内条目行与标题行统一加 =line-spacing= 行间距(像素,仅 GUI 生效),标题与首条目同距。分割线字符数按当前 frame 实测的 ─ 像素宽折算,GUI/TTY 与宽窄字体统一铺满版心。居中分两组:板块区(首板块标题行→末分割线行)统一 =align-to center - 版心/2= 前缀,整体居中、块内左对齐;其余行(banner、Welcome、navigator、init-info、footer)逐行按自身行宽 =align-to center - 行宽/2= 各自居中——整块左对齐对长短不一的行是错的。行宽超过窗口宽的行不加前缀直接贴左:align-to 负值会把整行推出屏幕左缘(内容只剩行尾残片),而 space spec 表达式里没有可用的 max 钳制(Emacs 31 下 max 求值静默回退 0),只能在装饰时静态排除;窗口比渲染时更窄的瞬态(拖拽间隙、多 frame 混开)仍有负对齐破碎,由 resize 合并刷新与已知取舍覆盖。两组都必须先 =remove-text-properties= 清掉既有前缀(banner/标题区带插件自设的测量式前缀,而 add-text-properties 不覆盖已有属性)。超版心的路径条目由 =dashboard-shorten-path= 的 override 降级:先压缩中间目录为首字母,仍超则 =...= 截断。navigator 按钮的 action 由 widget 以 =(widget event)= 两参调用,签名必须 =&rest= 兜底。

(defun custom/dashboard--compact-path (path)
  "把 PATH 中间目录压缩为首字母,首尾段保留。
隐藏目录(以 . 开头)取其第二个字符,避免 ~/./e 这种怪异的路径。"
  (let* ((parts (split-string path "/" t))
         (len (length parts)))
    (if (<= len 3)
        path
      (let* ((head (car parts))
             (file (car (last parts)))
             (middle (cl-subseq parts 1 (1- len)))
             (compressed (mapcar (lambda (d)
                                   (cond ((string-empty-p d) d)
                                         ((string-prefix-p "." d)
                                          (if (> (length d) 1)
                                              (concat "." (substring d 1 2))
                                            d))
                                         (t (substring d 0 1))))
                                 middle)))
        (concat head "/"
                (mapconcat #'identity compressed "/")
                "/" file)))))

(defun custom/dashboard--fit-path (path width)
  "把 PATH 压进 WIDTH 列:先首字母压缩中间目录,仍超则头部 ... 截断。"
  (let ((p (custom/dashboard--compact-path path)))
    (if (<= (string-width p) width)
        p
      (if (<= width 3)
          "..."
        (concat (substring p 0 (- width 3)) "...")))))

显示文本与真实路径经 plugin 的 path-alist 解耦,缩短不影响点击跳转。"
  (custom/dashboard--fit-path
   (abbreviate-file-name path)
   (custom/dashboard--content-width)))

分割线替换板块尾第一段空行。完成后分组居中:板块区按版心左缘统一
前缀,其余行逐行自身居中,理由见节首 prose;不先 remove 则插件/banner
自设的前缀不会被 add-text-properties 覆盖。定位走 heading overlay
(`dashboard-heading' face)而非 `dashboard--section-starts':渲染末尾的
page-separator 替换会使后者的绝对位置漂移。只从
`custom/dashboard--refresh-in-window' 调用,保证运行在正确窗口上下文。"
  (with-current-buffer (get-buffer dashboard-buffer-name)
    (let* ((width (custom/dashboard--content-width window))
           (icon-w (if (and (dashboard-display-icons-p)
                            dashboard-set-heading-icons)
                       2 0))
           (ovs (sort
                 (cl-remove-if-not
                  (lambda (ov)
                    (and (eq (overlay-get ov 'face) 'dashboard-heading)
                         ;; 重渲染后旧 overlay 塌缩成空壳仍残留,剔除
                         (> (overlay-end ov) (overlay-start ov))))
                  (overlays-in (point-min) (point-max)))
                 (lambda (a b) (< (overlay-start a) (overlay-start b)))))
           (inhibit-read-only t))
      ;; 倒序插入,前面的 insert 不影响后面 heading 的位置
      (cl-loop
       for (ov . key) in (reverse (cl-mapcar #'cons ovs
                                             custom:dashboard-heading-keys))
       when key
       do (let* ((name (or (overlay-get ov 'display)
                           (buffer-substring-no-properties
                            (overlay-start ov) (overlay-end ov))))
                 (used (+ 4 icon-w (string-width name))))
            (save-excursion
              ;; 分割线替换板块尾第一段空行(板块边界 = 标题行后第一个空行)
              (goto-char (overlay-start ov))
              (forward-line 1)
              (while (and (< (point) (point-max))
                          (not (custom/dashboard--blank-line-p)))
                (forward-line 1))
              (when (< (point) (point-max))
                ;; 板块内标题与条目行统一行间距:不插空行,靠 GUI 行距
                ;; 拉开;标题行也在内,与首条目保持同一间距
                (let ((sec-end (line-beginning-position)))
                  (goto-char (overlay-start ov))
                  (while (< (point) sec-end)
                    (unless (custom/dashboard--blank-line-p)
                      (put-text-property
                       (line-beginning-position) (line-end-position)
                       'line-spacing custom:dashboard-line-spacing))
                    (forward-line 1))
                  (goto-char sec-end))
                (delete-region (line-beginning-position) (line-end-position))
                (insert (propertize
                         (make-string
                          (custom/dashboard--separator-length width) ?─)
                         'face 'shadow))))
            ;; 标题行缩进 + 快捷键右贴到版心宽
            (goto-char (overlay-start ov))
            (let ((line-start (line-beginning-position))
                  (off-s (- (overlay-start ov) (line-beginning-position)))
                  (off-e (- (overlay-end ov) (line-beginning-position))))
              (goto-char line-start)
              ;; heading overlay 是 front-advance:TTY 无 icon 时其起点恰在
              ;; 行首,行首插入的缩进会被吞进 overlay(display 替换后消失)。
              ;; 记住原文本范围,插入后把 overlay 拨回。缩进继承行首的
              ;; line-prefix,否则标题行脱离板块整体缩进。
              (let ((prefix (get-text-property line-start 'line-prefix)))
                ;; 缩进是 display 行首字符,line-spacing 由它决定,须带上
                (insert (propertize "    " 'line-prefix prefix
                                    'line-spacing
                                    custom:dashboard-line-spacing))
                (move-overlay ov (+ line-start 4 off-s)
                              (+ line-start 4 off-e)))
              (goto-char (line-end-position))
              (insert (concat
                       (make-string
                        (max 1 (- width used (string-width key))) ?\s)
                       (propertize key 'face 'font-lock-comment-face))))))
      ;; 分组居中:先 remove 再改写——add-text-properties 不覆盖已有
      ;; 属性,banner/Welcome/navigator/footer 都带插件自设的测量式
      ;; 前缀。板块区(首板块标题行→末分割线行)统一版心前缀,整体
      ;; 居中、块内左对齐;其余行(banner/Welcome/navigator/init-info/
      ;; footer)长短不一,逐行按自身行宽各自居中,整块左对齐会全贴
      ;; 版心左缘。
      (remove-text-properties (point-min) (point-max)
                              '(line-prefix nil indent-prefix nil))
      (let* ((sec-beg (save-excursion
                        (goto-char (overlay-start (car ovs)))
                        (line-beginning-position)))
             (sec-end (save-excursion
                        (goto-char (point-max))
                        (search-backward "─" nil t)
                        (line-end-position)))
             (block-prefix (propertize
                            " " 'display
                            `(space . (:align-to (- center ,(/ width 2))))))
             (body-width (window-body-width window))
             (center-line
              (lambda ()
                ;; 行宽用插件的像素折算测量:string-width 会把 ─ ═ 等
                ;; ambiguous 字符按双列计,GUI 实际渲染单列,居中会偏;
                ;; dashboard-str-len 与插件原生 footer 居中同款公式。
                ;; 行宽超过窗口时不加前缀:align-to 负值会把整行推出
                ;; 屏幕左缘(内容只剩行尾残片),贴左至少完整可读;
                ;; align-to 表达式没有可用的 max 钳制(Emacs 31 静默
                ;; 回退 0),只能在装饰时静态排除。
                (let ((w (dashboard-str-len
                          (buffer-substring
                           (line-beginning-position)
                           (line-end-position)))))
                  (when (and (> w 0) (<= w body-width))
                    (let ((p (propertize
                              " " 'display
                              `(space . (:align-to (- center ,(/ w 2)))))))
                      (put-text-property
                       (line-beginning-position) (line-end-position)
                       'line-prefix p)
                      (put-text-property
                       (line-beginning-position) (line-end-position)
                       'indent-prefix p)))))))
        (save-excursion
          (goto-char (point-min))
          (while (< (point) sec-beg)
            (funcall center-line)
            (forward-line 1))
          (add-text-properties sec-beg sec-end
                               `(line-prefix ,block-prefix
                                 indent-prefix ,block-prefix))
          (goto-char sec-end)
          (while (and (< (point) (point-max))
                      (progn (forward-line 1) t))
            (funcall center-line)))))))

(defun custom/dashboard--refresh-if-stale ()
  "目标窗口宽度与上次渲染不同时才重渲染 dashboard。
frame 就绪回调与 resize 合并刷新共用:全量渲染(item 生成 + agenda
扫描 + 装饰)成本高,宽度相符就跳过。窗口过窄(版心不足
custom:dashboard-min-content-width)时跳过且不记录宽度——极窄渲染
出来也是破碎的,保留上一次可读的内容,窗口拖宽后宽度仍不匹配,
自然触发重渲染。"
  (when-let* ((win (custom/dashboard--dashboard-window)))
    (and (>= (custom/dashboard--content-width win)
             custom:dashboard-min-content-width)
         (/= (window-body-width win)
             (or custom/dashboard--rendered-width 0))
         (custom/dashboard--refresh-in-window))))

(defun custom/dashboard--on-frame-make (&rest _)
  "新 client frame 就绪后,渲染宽度不匹配才重渲染自愈。
initial-buffer-choice 阶段 selected window 可能仍是 daemon 旧 frame,
首帧版心会按错误宽度装饰且记录下错误宽度,本回调比较后自愈;宽度
相符(正常路径或同宽新帧)则零成本跳过。"
  (run-at-time 0 nil #'custom/dashboard--refresh-if-stale))

(defvar custom/dashboard--resize-timer nil
  "Resize 合并刷新的 pending idle timer,静止后触发一次。")

(defun custom/dashboard--on-resize-idle ()
  "Resize 静止后的合并刷新回调。"
  (setq custom/dashboard--resize-timer nil)
  (custom/dashboard--refresh-if-stale))

(defun custom/dashboard--on-resize (frame)
  "FRAME 尺寸变化时合并重渲染 dashboard,不逐事件全量渲染。
拖拽 resize 每个中间宽度一个事件,逐次渲染会把主循环卡死在连续
全量 item 生成上;只挂一个 idle timer,静止 0.3s 后按最终宽度刷
一次。daemon initial frame 的尺寸事件直接忽略(见
`custom/dashboard--dashboard-window')。"
  (when (and (frame-live-p frame)
             (frame-parameter frame 'client)
             (get-buffer-window dashboard-buffer-name frame))
    (unless custom/dashboard--resize-timer
      (setq custom/dashboard--resize-timer
            (run-with-idle-timer
             0.3 nil #'custom/dashboard--on-resize-idle)))))

(defvar custom/dashboard--agenda-once nil
  "单次渲染内的 agenda 结果请求级缓存。
仅渲染入口的 let 绑定内有效;跨渲染不缓存,数据新鲜度与插件原生
行为一致。")

(defun custom/dashboard--agenda-scan-once (orig &rest _)
  "dashboard-get-agenda 的 :around advice:单次渲染内只扫一次。
插件 \`dashboard-insert-section' 宏对 list 参数求值 4 次(heading
判断 / if 分支 / subseq / section-list 的 car),agenda 的
org-map-entries 全量扫描被重复 4 次,是渲染耗时与 GC 压力的大头;
缓存命中直接复用,未命中扫一次并记住。"
  (or custom/dashboard--agenda-once
      (setq custom/dashboard--agenda-once (funcall orig))))

(defun custom/dashboard--insert-lists-once (orig &rest args)
  "dashboard-insert-startupify-lists 的 :around advice:渲染入口。
let 绑定请求级缓存变量,渲染结束自动丢弃,下次渲染重新扫描。"
  (let ((custom/dashboard--agenda-once nil))
    (apply orig args)))

*** 实验性
本节集中放置生效中的版本兜底 shim(Ghostel/with-editor、Arei .elc 兼容)。它们都是「待上游修复」的 workaround,而非待完成的本地功能——代码已生效,移除条件在上游。

以下 noweb 片段(均为 =:tangle no= )定义 Emacs 31 兼容性 shim,由使用方在文档更靠前的位置前向引用(=<<emacs31/...>>= / =<<compat/...>>= )展开到 main.el。tangle 后代码插入到使用点,加载顺序不变;定义集中在此处是为了可发现性与未来上游修复后统一清理。

#+attr_org: :width 70
| Shim                       | 根因                                 | 受影响功能                     | 移除条件                                            |
|----------------------------+--------------------------------------+--------------------------------+-----------------------------------------------------|

**** Ghostel pre-spawn 的 with-editor 适配
with-editor 3.5.2 的公开导出函数只支持已经存在的 shell/term/vterm 进程；Ghostel 的 pre-spawn hook 运行在进程创建前。当前必须复用宏内部 setup，删除条件是 Ghostel 或 with-editor 提供公开的 pre-spawn 环境构造接口。

#+begin_src emacs-lisp :noweb-ref compat/ghostel-with-editor :tangle no
(defun custom/ghostel-export-git-editor ()
  "在 Ghostel 创建进程前把 GIT_EDITOR 注入动态 `process-environment'。"
  (when (fboundp 'with-editor--setup)
    (let ((with-editor--envvar "GIT_EDITOR"))
      (with-editor--setup))))
#+end_src

**** arei .elc 与 buffer-local-set-state 不兼容(bug#80812)
arei 0.9.7 的 .elc(Guix 用旧版 Emacs byte-compile)与 Emacs 31 的 =buffer-local-set-state= 宏不兼容:arei-mode 第 356 行调用该宏,但旧 .elc 把它当函数调用,参数 =(sesman-system 'Arei)= 被整体传给 =buffer-local-set-state--get= → =wrong-type-argument (symbolp 'Arei)= 。此错误在 =scheme-mode-hook= 里抛出,会中断整个 scheme-mode 初始化,导致 font-lock 失效 → Scheme 代码不染色。

#+begin_src emacs-lisp :noweb-ref emacs31/source-load-compat :tangle no
(defun custom/load-library-from-source (library)
  "从 LIBRARY 对应的 .el 源加载，绕过不兼容的 Guix .elc。
GNU store 只读无法删 .elc，且 .el/.elc 时间戳相同（epoch 1）使
`load-prefer-newer' 无效，故需显式从 .el 加载。返回 t 若成功。"
  (condition-case err
      (when-let* ((found (locate-library library))
                  (source (concat (file-name-sans-extension found) ".el"))
                  ((file-exists-p source)))
        (load source nil t t)
        t)
    (error
     (message "[ERROR] %s 从源加载失败: %S" library err)
     nil)))
#+end_src

#+begin_src emacs-lisp :noweb-ref emacs31/arei-compat :tangle no
(defun custom--maybe-enable-arei-mode ()
  "在真实 Scheme 编辑 buffer 中启用 `arei-mode'(跳过 org src 临时 buffer)。

对 `arei-mode' 调用包裹 condition-case:minor-mode 的故障不应中断
`scheme-mode-hook' 的后续步骤(尤其 font-lock 初始化)。"
  (unless (string-prefix-p " *org-src-fontification:" (buffer-name))
    (condition-case err
        (arei-mode 1)
      (error
       (message "[ERROR] arei-mode 启用失败,Scheme 染色不受影响: %S" err)))))
#+end_src
