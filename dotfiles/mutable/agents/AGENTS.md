# dotfiles/mutable/agents/ — Agent 平台包（两级清单）

本目录按平台分包容纳各 Agent 的运行时配置与部署资产（每包一个子目录，部署目标见 `../AGENTS.md` 的纳管软件包列表）。平台维护分两级的目的是停止「每个平台都例行跟进」的均匀投入——维护精力只投给实际在用的宿主，其余目录冻结。

## 平台分级

| 级别     | 目录                                             | 维护口径                                                       |
| -------- | ------------------------------------------------ | -------------------------------------------------------------- |
| **主力** | `zcode/`、`hermes/`                               | 正常维护：功能演进、上游跟进、例行适配                          |
| **攻坚** | `dsh/`                                           | 按需投入：攻关场景使用，跟进以实际踩坑为驱动                     |
| **frozen** | `devin/`、`skills/`                       | 冻结：只修阻断性 bug，不新增功能、不主动适配、不做例行跟进 |

> `skills/` 虽非平台适配层（askill 锁与自建技能的存放点），同列 frozen——不为冻结平台新增技能适配；阻断性修复与显式任务（如本仓库既定的精简批次）不受此限。

分级清单以本文件为准；级别调整是用户决策，agent 不自行升/降级。
