# skill-impact.md — skill 修改提案审计簿

> WikiSkill 式审计层（arXiv:2608.27454）：**被拒绝的尝试是知识，不是垃圾**。
> 每次 skill 修改提案（无论来源：KB 晋升 / 手工改进 / agent 自发）落地后在此追加一条；
> 策展或 skill 管理前**先读本文件**，避免重复提交被拒过的方案。
> 由 git 跟踪（skills/ 整目录软链自 Guix-configs 仓库），改动随仓库备份。

## 条目格式

```
## YYYY-MM-DD | <skill-name> | Accepted|Rejected|Created
- 提案来源: agenote <卡片ID> | 手工 | 会话 <id>（能溯源就写）
- diff 摘要: <一句话，改了什么>
- 验证结果: <verify 输出要点 / 门禁结论>
- 拒绝原因: <被拒时必填——下次提案者读的就是这行>
```
