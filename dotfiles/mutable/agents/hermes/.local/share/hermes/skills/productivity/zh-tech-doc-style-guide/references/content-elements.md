# 文档内容元素（空白 / 列表 / 表格 / 图形图片 / 注意说明 / 代码块 / 链接 / 引用 / 缩略语 / 数字 / 单位符号）

源：文档内容元素/ 全部十一节。链接、引用、缩略语另见 `references/links-and-refs.md`。

## 空白符号

空白 = 空格、空行；空格分半角与全角。

| 空白类型 | 规范 |
| --- | --- |
| 空格 | - 禁止全角空格，**一律半角空格**。<br>- 中文字符（含汉字和中文标点）之间**禁止空半角空格**。<br>- **英文字符和阿拉伯数字**一般用半角格式，应用半角空格包围；例外：①位于句首时左边空格省略；②右侧为半角或全角标点时右边空格省略。<br>- 除缩进、列表级别、代码块固有空格、Markdown 表格空格外，**禁止连续两个及以上半角空格**。<br>- 不建议用 Tab 替换空格。 |
| 空行 | - 不同段落间建议一个空行隔开。<br>- 不同排版格式间建议一个空行隔开（标题与正文、正文与代码块、正文与表格等）。<br>- **禁止连续两个及以上空行**。 |
| 其他 | 行宽：相同排版格式内保持一致即可，可自由在 80、120 字符中选择，原则上不超过 160 字符宽。 |

Tab 与空格：

- 用空格键而非 Tab 键缩进/对齐（不同编辑器 Tab 默认长度不一致，空格在任何编辑器显示一致）。
- 用 Tab 缩进可接受，但**禁止混用 Tab 和空格**缩进。
- 在 VS Code 等编辑器统一设置「一个 Tab = 四个半角空格」。

## 列表

何时用列表：**3 项或更多**重要信息需展示时，纵向列表最清晰；少于 3 项且无需特别强调时，直接写进句子效果更好。

多级嵌套：某级别下另起一行，缩进**四个空格**开始更低一级。

有序 vs 无序：**顺序不重要用无序，顺序很重要用有序**。

有序列表的适用场景（用例较少）：

- 必须按顺序操作的步骤（最常用）
- 需要排名的多项内容
- 需要在下文引用的规则或信息（下文可说「规则 3」）

**【重要原则】除非顺序很重要，否则不使用有序列表。**

八条使用规范：

1. 并列列表项建议使用**相似的句子结构**（要么都「支持 X」要么都「优化了 X」，不混）。
2. 每一项长度尽量接近（名词性短语对齐，别一条长一条短）。
3. 避免每项开头重复相同词语（重复前缀改为引出句：「TiDB 不支持的功能有如下几种：」）。
4. 用清晰、描述性的句子或短语引出列表（别用「状态可以通过 store 的 state_name 来确定：」这种生硬引出）。
5. 并列列表项**保持标点一致**：列表项是句子 → 每项以句号结尾；是词组 → 不加任何标点；词组与句子混合 → 统一以句号结尾。
6. 不要滥用无序列表，否则失去应有效果。
7. 避免嵌套列表（冗长复杂）；必须多层时**最多 3 级**，且每级用不同样式小圆点。
8. 操作任务步骤用有序列表，为方便记忆**建议严格限制在 7 项以下，最多不超过 9 个步骤**。

## 表格

样式规范：

- 单元格内容**建议保持左对齐**。
- 所有表格都需有表头描述（第一行描述各列内容的短语）。
- 保证表格同一行单元格不跨页。
- 每个表格下空一行，样式为正文；若换页时该空行落在新页第一行，则必须删除。

表头规范：

- 同一文档/产品手册中**相同类型表格的表头描述保持一致**。
- 参数说明表要统一表头描述，不要混用「参数说明」「参数解释」「参数含义」「参数意义」。

单元格内容规范：

- 内容尽量简练，风格一致；避免长篇大段，**单元格内容所占行数建议不超过 6 行**。
- 不出现空白单元格；无内容填「无」或特定含义符号（如「/」），用符号需说明其意义。
- 避免内容重复；多个单元格相同则复制内容或合并单元格，**不要用「同上」**。

表说明规范（表格前后的一行描述，可带序号）：

- 采用名词词组形式。
- 简明扼要，长度不能超过表的宽度。
- 同类表格的表说明全文中风格统一。

## 图形和图片

- 必须使用清晰可辨的图形图片。
- 中文文档里图上文字**建议都用中文**；原图是其他语言须先做图片本地化。
- 文字建议用**免费开源可商用字体**，以免法律风险；不确定能否商用可在「360 查字体」网站查证。
- 同一文档内图上中文统一字体（如思源黑体），英文和数字也统一字体（如 Times New Roman）。
- 图中避免大段文字，描述性语言放图外，用编号替代。
- 图中含缩略语时，需在图说明中解释该缩略语。
- 图说明和图尽量保证同页显示。
- 图片命名建议用描述性文字。
- 插入图片建议添加替代文本（无障碍）：HTML 用 `alt` 属性，Markdown 用 `![替代文本](...)`，Word 用「编辑替换文字」功能。

## 注意和说明

- 按提示内容的级别和分类使用不同文字描述，如「危险」「警告」「小心」「注意」「说明」「建议」「举例」「错误」。
- 注意和说明中**不能包含表格和图形**。
- 内容不能过长，**建议不超过 4 行**。

## 代码块和代码注释

代码块：

- 代码块前后**必须加一行空行**。
- 注意缩进：代码块属列表项内容时，在该列表项缩进基础上**再缩进四格**。
- 前端支持则建议高亮代码块。
- 前端支持则建议加「直接复制代码」按钮，提高易用性。

代码注释（多行代码块中）：

- 一行注释不能太长，太长时适当断句切到下一行。
- 一行注释末尾建议加标点，一般是句号；与下一行内容承接时用逗号。
- **必须按代码块定义的语法选相应注释符**，不能自创注释符。

## 数字

汉字数字 vs 阿拉伯数字的选用：除惯用/特殊场景外，要**突出强调、易于辨识**用阿拉伯数字；要突出**正式、庄重**用汉字数字。

### 用阿拉伯数字

| 场景 | 例 |
| --- | --- |
| 计量用数字（加减乘除、正负整数、小数、百分比、比例、分数） | -126、34.05%、63%～67%、1:500、87/90 |
| 数值伴随计量单位（长度/容积/面积/体积/质量/温度/经纬度/音量/频率，尤其单位以字母表达） | 524.5 km、53 MB、12 h |
| 编号 | 电话 98888、邮编 100083、章节编号 4.1.2、产品型号 PH-3000、车牌 京A00001、公交 302 路、国道 101、公文编号 国办发[1987]9 号、ISBN 978-7-80184-224-4 |
| 名称书写形式已稳定含阿拉伯数字的事物 | 4G 手机、MP4 播放器、维生素 B12、「5·27」事件 |
| 要突出简洁醒目 | 2020 年 10 月 1 日 12 点整 |

### 用汉字数字

| 场景 | 例 |
| --- | --- |
| 概数（数字连用、含「几」） | 三四个月、一二十个、五六万套、几十万分之一 |
| 干支纪年、农历月日、历史朝代纪年等非公历纪年 | 腊月二十三、正月初五、秦文公四十四年、丙寅年十月十五日 |
| 长期稳定下来的含汉字数字词语 | 星期五、四氧化三铁、不二法门、八国联军、半斤八两 |
| 要庄重典雅 | 六方会谈（不写「6 方会谈」）、十一届全国人大一次会议（不写「11 届全国人大 1 次会议」） |

### 两者均可

数字个数不多、简洁性与辨识性无明显差异时随意：3 倍/三倍、100 多个数据中心/一百多个、约 300 人/约三百人、第 40 页/第四十页、0.5/零点五、公元前 8 世纪/公元前八世纪、下午 4 点 27 分/下午四点二十七分。

其他注意事项：

- **同一场景同类别同形式**：2020 年 10 月 1 日 或 二〇二〇年十月一日（不写「二〇二〇年 10 月 1 日」）；第一章…第十二章（不混「第 12 章」）；下一级可用 2.1、2.1.1。
- 避免相邻两个阿拉伯数字歧义：高三 3 个班（不写「高 3 3 个班」）、高三 2 班或高三 (2) 班。
- 法律/公告/财务文件可同时用两种形式：`万分之一点五七五零 (0.015750%)`、`35.5 元（三十五元五角）`。

### 阿拉伯数字格式

- 一律**半角**，禁用全角：错误「每２分钟」，正确「每 2 分钟」。
- 不作后期排版处理时，半角数字**两旁各空一个空格**：错误「每2分钟」，正确「每 2 分钟」。
- 一个阿拉伯数字书写的数值**必须在同一行，不能断开移行**。

多位数值：

- 巨大精确数字用「亿、万」作单位：10 亿 231 万 3245 人。
- 千位以上加半角逗号分节，每三位一节：2,345,567,456；小数部分不分节 19,256,289.23456；四位以内可不分节 1289。

数值范围：

- 用浪纹式「～」或一字线「—」：-36～-8 ℃、400—429 页。
- 前后附加符号/单位相同且不造成歧义时，前一个可省略：9 亿～20 亿 → 9～20 亿；15%～30% → 15～30%。

年月日：

- 四位年份不简写为两位（「2019 年」≠「19 年」）。
- 按口语自然顺序：2008 年 8 月 8 日。
- 「年」「月」可用「-」替代，但**年月日不完整时不能替代**：2020-8-8 可以，「8-8」「2020-8」不行。
- 月日为一位数可补 0：2020-08-08。

时分秒：

- 12 小时制与 24 小时制均可（11 时 31 分 / 21 时 12 分）。
- 可用「:」替代：14:12:16。

含月日的专名：阿拉伯数字表示时用间隔号「·」分隔月日并加引号：「3·15」消费者权益日。

### 汉字数字

- 概数：两数字连用**之间不用顿号**：二三米、三五天、五六十年代。
- 年份简写后会理解为概数时不简写：「一九七八年」不写「七八年」。
- 含月日专名：涉一月、十一月、十二月时用间隔号「·」并加引号：「一·二八」事变、「一二·九」运动；其他月份不用间隔号（五一国际劳动节）。
- 大写形式：零（或〇）、壹、贰、叁、肆、伍、陆、柒、捌、玖、拾、佰、仟、万、亿；用于法律文书和财务票据记数：3,504 元（叁仟伍佰零肆圆）。
- 「零」vs「〇」：**计量用「零」，编号用「〇」**：两千零五十二、一百点零六（不写〇）；二〇一九（不写二零一九）。
- 「二/2/两」：度量衡单位和百千万前「二」「两」通用；序数、分数、小数用「二」不用「两」；常用量词（个、本、件、回、种、天）前用「两」不用「二」；强调计量统计意义可用「2」。

## 单位符号

- 为避免指代不明，**建议用汉字名称代替单位符号**：毫米代替 mm、小时代替 h、分钟代替 min。
- **大多数情况下数值与单位符号之间空一个半角空格**：7 kg、8 MB、10 GB。
- 例外（不空格）：角度/摄氏度/百分号（60°、37°C、100%）；英尺英寸符号（4′5″，′ 为 U+2032 Prime，″ 为 U+2033 Double Prime）。
