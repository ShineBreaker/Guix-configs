# 标点符号（常用中文标点 / 中文标点使用 / 中英混排）

源：标点符号/ 三节。

## 常用中文标点符号

### 句号「。」

表示陈述语气、句末停顿，意思已完整。**应善用句号切分语意**，帮读者理清逻辑。上游反例即 DM binlog position 一逗到底长句；正确写法拆成三句。

### 逗号「，」

句子内部一般性停顿。使用最普遍但不能滥用：**不要「一逗到底」**（整段除结尾外全部停顿都用逗号）。

### 顿号「、」

中文句子内部**两个及以上**并列成分之间的短暂停顿，并列成分通常是**同类的单字、词语或短句**。英文无顿号（用逗号），英汉翻译者尤需注意。

误用场景（上游核对表）：

| 错误 | 正确 | 规则 |
| --- | --- | --- |
| TiDB，Pump，TiKV，PD 服务 | TiDB、Pump、TiKV 和 PD 服务 | 并列词语用顿号，不用逗号 |
| 全方位，透视性地进行报道 | 全方位、透视性地进行报道 | 并列词语间用逗号使语句松散 |
| 增强政府的危机意识、增强政府应对突发事件的透明度，提高…… | ……危机意识，增强……透明度，提高…… | **分句之间用逗号不用顿号** |
| 与时代同步、与人民同心 | 与时代同步，与人民同心 | 并列的**谓语、补语之间用逗号**，不用顿号 |
| 人口、资源、环境的承受力趋向极限、以及国际竞争力…… | ……趋向极限以及国际竞争力…… | **连词（和/跟/及/或者）前不能有顿号**，等于连用两个顿号 |
| 部署、启动、关闭、销毁、弹性扩缩容、升级 TiDB 集群、管理 TiDB 集群参数 | ……升级 TiDB 集群，以及管理 TiDB 集群参数 | **多层次并列不能全用顿号**，层次会混乱；内层并列已含顿号时外层改用逗号/连词 |
| 六、七十年代 | 六七十年代 | 相邻两个数字连用表概数必须用汉字且**之间不用顿号**（GB/T 15835-1995） |
| 产、学、研 | 产学研 | 简短并列词语联系紧密、已成不可分整体，内部不用顿号 |
| 3、行政文明建设…… | 3. 行政文明建设…… | 阿拉伯数字作序数词后用点号；汉字「一」后用顿号，「第一」后用逗号 |
| 「日」、「月」构成「明」字 | 「日」「月」构成「明」字 | **标有引号的并列成分之间、标有书名号的并列成分之间通常不用顿号**；若中间插有其他成分（如括注）宜用顿号 |
| 《红楼梦》、《三国演义》…… | 《红楼梦》《三国演义》…… | 同上（书名号并列） |

### 分号「；」

复句内部并列分句之间的停顿。**并列分句三句及以上时，建议使用分号**。

### 冒号「：」

用于需要解释的词语后，引出解释和说明；常用来引出列表。**一个句子内不要连续套用冒号**（错误：「计数系统：逻辑表示：1，……」。正确：「计数系统：1 表示计数器加一，0 表示计数器不变。」）。

### 引号

形式：直角引号「」『』与弯引号 '' ""（各分双单）。**可用直角或弯引号，但必须全文档统一，禁止混用**。GB/T 15834-2011 规定用弯引号，故上游只讨论弯引号。

- 引号内套引号：外层双引号，内层单引号。
- 建议加引号的场景：报错信息、特定操作或名称、缩略语提示、特殊名词、引用文档节选。
- 正文涉及特定参数名、字段名、界面字段时，建议用引号（也可用反引号）包裹。

### 括号

形式：圆括号（）、方括号［］、方头括号【】、尖括号 <>、花括号｛｝。技术文档常用圆括号、方括号、尖括号。

- 中文词语或句子后紧跟的注释性文字用圆括号。注释句中某些词语 → 括号放被注释词后；注释整个句子 → 括号放句末标点之后。
- 方括号表示窗口名、菜单名：「弹出［新建任务］窗口」「［显示/外观/全屏］多级菜单」。
- 尖括号表示按钮名、键名：「点击<取消>按钮」「<Tab> 表示制表键」。

### 书名号《》

- 书籍名、报刊名用书名号。
- **英文手册名称用中文双引号或斜体，不用书名号**。
- 书名号中的文档名**建议用全称不用简称**（错误《表库过滤》；正确《TiDB Lightning 表库过滤》）。

### 连接号

三种形式：一字线「—」（占一个汉字宽）、短横线「-」（半个汉字宽）、浪纹线「～」（一个汉字宽）。

| 符号 | 用法 |
| --- | --- |
| 一字线 — | 时间/空间起止或走向、序数起止：鲁迅（1881—1936）、2016—2020 年、1—3 月、13—15 号楼、第 50—100 条；标准编号连接顺序号与年号：GB/T 15835—2011 |
| 短横线 - | 电话/门牌号/图表编号/阿拉伯数字年月日等复合名词：15 号 2-1-201 室、图 2-1、表 3-4、2020-09-30；外来语内部：让-雅各·卢梭；产品型号：GC-50 |
| 浪纹线 ～ | 数值范围：1～3 g、2～4 米、3～7 年内 |

记忆方式：**起止用一字线，范围用浪纹线，复合名词用短横线**。

### 破折号「——」

占两个汉字宽，常用于引出注释和说明。**破折号前后不空格**（错误「概念 —— NewSQL」；正确「概念——NewSQL」）。

### 省略号

中文形式「……」或「⋯⋯」，六个小圆点，占两个汉字宽。**禁止使用英文省略号「…」**。场景：引文省略、列举省略。

### 感叹号

- 尽量用平静语气叙述，避免使用感叹号。
- **禁止多个感叹号连用**（「！！」）。

### 斜杠与反斜杠

斜杠「/」（半角）或「／」（全角）作分隔符；反斜杠作转义字符，一般只出现在代码中。

斜杠用法：除法（120/60 = 2）；单位（60 km/h）；表示「或」「和」（他/她）。

- **多个并列项不建议用「/」连接，应用顿号**（错误「TiDB/TiKV/PD」；正确「TiDB、TiKV 和 PD」）。
- **斜杠两旁不建议加空格**（错误「do / ignore」；正确「do/ignore」）。

### 反引号（Markdown）

| 用法 | 单个反引号 | 三个反引号 |
| --- | --- | --- |
| 作用 | 强调并与正文区分 | 展示多行代码、强调、可指定语法高亮 |
| 适用 | 变量名、变量的值、语法名称、命令或代码、配置项名、字段名，以及文件名、表名、列名、库名、数据类型名等需强调的名称 | 多行代码块（多行 SQL、多行 bash 等）、代码执行结果、配置文件中多行配置 |

## 中文标点使用

- **中文语境下标点一律用全角形式**（中文输入法下的标点），不得用半角形式。
- **中文全角标点两旁禁止空半角空格**（错误「限额 （从 K8S 指定的上限） ，则」；正确「限额（从 K8S 指定的上限），则」）。
- 不能出现在行首：句号、问号、叹号、逗号、顿号、分号、冒号、结束引号、结束括号。
- 不能出现在行尾：开始引号、开始括号、开始双书名号。

## 中英文混用时标点符号用法

**根本原则：以中文标点符号为主，英文标点符号为辅。**

两条基本规范：

1. 中文句子内夹用英文**单词或词组**时：可不加中文引号；**英文单词/词组本身自带的英文标点保留**；**中文句子句末一律以中文标点结尾**。
2. 中文句子内夹用英文**句子**时：用中文引号包裹；**英文句子本身的英文标点保留**；**句末一律以中文标点结尾**。

例句对照（节选）：

| 标点 | 夹用英文单词/词组 | 夹用英文句子 |
| --- | --- | --- |
| 句号 | change 和 transform 意义不同。 | “I like you.（我喜欢你。）”与“I love you.（我爱你。）”的份量不一样。 |
| 逗号 | 官方描述是“open-source, distributed SQL database”。 | 文档上写着“Try it out, and you will get a 10% discount.”。 |
| 问号 | distributed SQL 在这里是什么意思？ | 他伸出手说“Need a hand?”，这句话的意思是“Do you need help?”？ |
| 叹号 | 不要总是对女孩说“Pretty!”！ | 他感叹了句“What a beautiful scene!”。 |
| 顿号 | be 动词包括 is、are、were、was 等。 | “He is man.”、“He is a man.”和“He is the man”的区别是什么？ |
| 分号 | 如果想表示更礼貌的语气，用 might；反之，用 may。 | 文档上说“To deploy the database, use the TiUP tool; to migrate data, use the DM tool.”。 |
| 冒号 | 官网有个首页按钮失效了：Newsletter。 | 文档站右上角写着：Try it now。 |
| 引号 | 将来时态一般由“will + 动词原形”组成。 | 文章里有句话比较难理解：“The saint said, 'Follow your fear.'”。 |
| 破折号 | 这个符号表示禁止——stop。 | “Well—emm, I don't know how to say—but I hope you can understand my position.”他纠结地说。 |
| 省略号 | 使用 so...that... 句型，意思是“如此……以致……”。 | “I don't know how to say this...”的意思是“我不知道该怎么说了……”。 |

补充规范：

- **英文标题或引文中的结尾问号/叹号必须保留**：「这篇文档的标题“How to Migrate Data from MySQL?”可以改为……」。
- 括号：
  - **括号内全为英文 → 用半角括号，括号前后各空一个半角空格，括号与内部英文之间不空格**。正确：「数据定义语言 (DDL) 是一种……」；错误：全角括号「(DDL)」、半角括号前后不空格「语言(DDL)」、括号内加空格「( DDL )」。
  - **括号内含任何中文 → 用全角括号，前后不空格**。正确：「斜杠（slash 或 forward slash）和反斜杠 (backslash)」。
- 英文书籍、报刊、标题的引用：
  - 中文句子中夹用英文书籍/报刊名**不能用中文书名号《》**，应使用斜体；无法用斜体时用中文引号包裹。
  - 英文文章标题用中文引号包裹引用：标题是“Cloud is Eating the World”。
