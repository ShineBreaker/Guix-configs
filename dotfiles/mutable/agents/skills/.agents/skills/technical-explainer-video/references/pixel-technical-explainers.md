# 像素技术解释片配方

适用于神经网络、分类器、算法状态机和数据流的短片。目标是低分辨率下仍然一眼看懂，而不是堆满信息。

## 推荐画面

以 320×180 为内部画布，放大到 1920×1080：

```text
┌────────┬──────────┬──────────────┐
│ 输入   │ 过程     │ 输出         │
│ 样本   │ 网络/流程│ 概率/排名    │
├────────┴──────────┴──────────────┤
│ 指标：训练进度 / 误差 / 正确率   │
└───────────────────────────────────┘
```

- 外框与内容间至少留 3 个低分辨率像素。
- 像素字每行至少高 5 个内部像素。
- 单个面板最多承担一个主要结论。
- 数字、分类和预测框使用同一强调色；辅助连线降低对比度。

## 机器学习分类器

### 输入

用一个可辨认的具体样本，不只放“INPUT”标签。MNIST 可用 7×7 位图，缩小时仍应能认出数字。

### 网络

- 输入层可用规则矩阵表达，例如 16 个节点排成 4×4。
- 隐藏层与输出层按声明数量竖排。
- 若全连接边过密，可显示代表性边，并在标题或说明里明确这是网络结构示意。
- 信号脉冲从输入向输出移动；不要让脉冲方向与标签矛盾。

### 输出

- 类别数量必须与输出条数量一致。
- 获胜类别同时改变条长、标签颜色和最终预测框。
- 预测框与最后一条概率保持安全间距。

### 指标

- loss 曲线与 accuracy 使用同一个训练进度驱动。
- 最终值应与输出状态同时或稍后落定。
- 不要展示无法由数据推导的精确指标；未知训练结果时使用明确标注的示意数据。

## Canvas 语义诊断

在页面中加入 `?diag=1` 钩子或隐藏的 `<pre id="diag">`，从真实数组输出：

```js
const diag = {
  layerCounts: model.layers,
  drawnNodeCounts: model.layers.map((_, i) => nodes[i].length),
  outputBarCount: outputBars.length,
  classCount: model.classes,
  prediction: finalPrediction,
};
```

用无头浏览器读取诊断节点。数量不一致应直接失败，不要依靠肉眼从密集连线中计数。

## 视觉验收问题

每个代表帧只问五个问题：

1. 输入案例能独立辨认吗？
2. 图中节点数与标题一致吗？
3. 信号方向与数据流一致吗？
4. 输出获胜项与预测框一致吗？
5. 指标、标签和边框有无重叠、裁切或压边？

任一答案是否定，先修再渲染。
